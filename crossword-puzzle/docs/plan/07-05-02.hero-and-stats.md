## 작업

### 1. `hero_card.dart`

```dart
class HeroCard extends StatelessWidget {
  final LevelStatus status;
  final bool allCleared;   // 라벨만 바꾼다 — 규칙 추가 아님(N-04)
  final VoidCallback onStart;
```

| 요소 | 값 | 출처 |
|---|---|---|
| 배경 | `GameColors.of(context).surfaceAlt` | 2.2 |
| 반지름 | `GameRadius.panel` | 2.5 |
| 안쪽 여백 | `GameSpace.xl`(24) | 2.5 |
| 라벨 | `'이어하기'` / `allCleared`면 `'다시 도전'`, `GameType.label` + `inkMuted` | 2.4 |
| 레벨 이름 | `GameType.display` + `ink`, `FittedBox(fit: BoxFit.scaleDown, alignment: Alignment.centerLeft)` | 2.4 |
| 부제 | `GameType.caption` + `inkMuted` | 2.4 |
| 버튼 | `FilledButton`, 높이 52, 알약형(테마가 이미 준다 — 07-02 `filledButtonTheme`), 글자 `'시작'` | 2.5 |

부제 문구는 `'레벨 ${spec.id} · ${spec.width}×${spec.height} · 단어 ${spec.minWordCount}개 이상'`.
`LevelSpec`에는 생성 전 확정 단어 수가 없다 — `minWordCount`(= `coreCount + minFillCount`)가 유일하게 읽을 수 있는 값이라 `개 이상`으로 적는다. **elevation 0, 그림자 없음**(1절 "평면").

세로 순서는 라벨 → 이름 → 부제 → 버튼, 사이 간격은 `GameSpace.s` / `GameSpace.xs` / `GameSpace.l`.

### 2. `stats_row.dart`

`_SummaryHeader`의 계산을 **그대로** 옮긴다. 값 형식이 곧 테스트 계약이다(`'-'`, `'75%'`, `'1개'`).

```dart
final total = (s?.correct ?? 0) + (s?.wrong ?? 0);
final rateText = total == 0 ? '-' : '${(s!.correct / total * 100).round()}%';
```

한 줄 배치. 라벨과 값은 **따로 떨어진 `Text` 위젯**이어야 한다(`find.text('75%')`가 정확히 하나를 찾는다).

```
Row(center)
 └ [Text('누적 정답률', label+inkMuted)] [gap s] [Text(rateText, heading+ink)]
   [gap l] [Text('·', label+inkMuted)] [gap l]
   [Text('푼 단어', label+inkMuted)] [gap s] [Text('${s?.words ?? 0}개', heading+ink)]
```

`'누적 정답률'`·`'푼 단어'`는 INV-09 문구다 — 글자 하나도 바꾸지 않는다.

### 3. `home_page.dart` 재조립

`_SummaryHeader`·`_StatItem`을 지우고 아래로 바꾼다. `_LevelRow`·`_Trailing`은 07-05-03이 지울 때까지 그대로 둔다.

```
Scaffold
 └ AppBar  title 'J Crossword Puzzle' · actions [IconButton(Icons.settings, tooltip: '설정')]
 └ body → Center
          └ ConstrainedBox(maxWidth: _maxBodyWidth)        // 560, UI-GUIDE 4절
             └ ListView(padding: EdgeInsets.all(GameSpace.l))
                ├ HeroCard(status: model.nextLevel!, allCleared: model.allCleared,
                │          onStart: () => _openLevel(context, model.nextLevel!.spec))
                ├ SizedBox(height: GameSpace.xl)
                ├ StatsRow(summary: model.summary)
                ├ SizedBox(height: GameSpace.l)
                ├ Divider(height: 1)                        // 테마가 line 1px
                ├ SizedBox(height: GameSpace.l)
                └ ...model.statuses.map((s) => _LevelRow(status: s))
```

- `const double _maxBodyWidth = 560;` 는 이 파일 전용 상수로 두고 주석에 UI-GUIDE 4절을 적는다.
- `model.nextLevel`은 `statuses`가 비면 null이다 — 로딩/오류 분기를 통과한 뒤에도 방어적으로 `if (hero != null)`로 감싼다.
- AppBar 제목·설정 아이콘·tooltip `'설정'`, 로딩·오류 위젯은 **건드리지 않는다**.

### 4. 깨지는 기존 테스트 2종 (셀렉터만, 이름 유지 — INV-08)

히어로가 `nextLevel`의 이름을 표시하므로 `find.text(levels.first.name)`이 **2개**(히어로 + 목록 행)를 찾아 `tap`이 실패한다.

| 테스트(이름 그대로) | 바꿀 곳 |
|---|---|
| `레벨 1 항상 해제: 통계 없어도 탭 가능` | `find.text(levels.first.name)` → `find.widgetWithText(ListTile, levels.first.name)` |
| `해제 레벨 탭: 퍼즐 화면으로, 새 seed` | 같음 |

`잠긴 레벨 탭`은 레벨 2(`'갈림길'`)를 누르는데 히어로는 레벨 1을 가리키므로 그대로 둔다.

### 5. 테스트 `test/ui/home_screen_test.dart` (신규 4종)

`home_settings_test.dart`의 `openEmptyDb()`·`buildScope()`·`wrapHome()`·`useTallViewport()`를 복사하고 `setUp`에 `SharedPreferences.setMockInitialValues({tutorialSeenPrefsKey: true})`를 넣는다.

| 테스트 | 기대 |
|---|---|
| 히어로: 미클리어 첫 레벨 | 레벨 1 클리어 INSERT → `find.descendant(of: find.byType(HeroCard), matching: find.text('갈림길'))` 1개, `'이어하기'` 1개 |
| 히어로: 전부 클리어 | 10레벨 INSERT → 히어로에 `levels.last.name`, `'다시 도전'` 1개, `'이어하기'` 없음 |
| 히어로 시작 탭 | `'시작'` 탭 → `PuzzlePage.spec!.id == model.nextLevel!.spec.id` |
| 통계 | `word_stat('가나', 3, 1)` INSERT → `'누적 정답률'`·`'75%'`·`'푼 단어'`·`'1개'` 각 1개 |

이 파일은 07-05-03이 4종을 더 얹어 8종이 된다. 부모 문서 표 10종 중 나머지 2종은 `home_model_test.dart`(07-05-01)에 있다.

## 막히면

- **`display` 34pt가 좁은 기기에서 줄바꿈** → 레벨 이름은 최대 4자라 328dp에 들어간다. 그래도 넘치면 `FittedBox(fit: BoxFit.scaleDown)`가 잡는다 — 이미 감싸 뒀는지 확인.
- **`find.text('75%')`가 0개** → 라벨과 값을 한 `Text`에 합쳤다. 반드시 두 위젯으로 나눈다.
- **`'시작'` 탭이 히어로가 아닌 곳을 누름** → `find.widgetWithText(FilledButton, '시작')`으로 좁힌다.
- **`nextLevel`이 null이라 크래시** → 로딩 분기를 통과했는데 `statuses`가 비었다는 뜻이다. `HomeModel.load()`가 `catch`로 빠졌는지(=`error != null`) 먼저 본다.
- **`ListView`가 화면 밖 행을 안 만들어 개수 테스트 실패** → `useTallViewport(tester)`(800×3000)를 빠뜨렸다.
