- 표준 보충분은 대부분 최하위 티어라 채움용으로 못 쓴다 (DESIGN 5절).
  **3단계 실패율 측정 후 투입 여부를 결정**한다. 지금은 일단 파싱해 둔다.

## 핵심 리스크: 파일 크기

> 표준국어대사전 전체 XML은 수백 MB → `iterparse` 스트리밍 필수. 메모리에 한 번에 올리지 않는다.

02-03과 같은 `iterparse` + `el.clear()` 패턴. 여기서는 **반드시** 지켜야 한다.

메모리가 계속 증가하면 `lxml` 도입:

```powershell
# tools/requirements.txt 에 lxml 추가 후
tools\.venv\Scripts\python.exe -m pip install -r tools/requirements.txt
```

```python
from lxml import etree as ET   # API가 거의 호환

for ev, el in ET.iterparse(path, events=("end",), tag=ITEM):
    ...
    el.clear()
    while el.getprevious() is not None:
        del el.getparent()[0]      # 부모에 쌓인 빈 껍데기 제거
```

`lxml` 은 `tag=` 필터를 지원해 관심 없는 요소를 아예 건너뛴다. 속도도 2~3배 빠르다.
**도입하면 `tools/requirements.txt` 와 `tools/README.md` 에 이유를 기록한다.**

## 표준 고유 필터 (02-06에 넘기기 전)

표준에는 게임에 쓸 수 없는 항목이 대량으로 섞여 있다. **파싱 단계에서 미리 버리면** 뒤 단계가 가벼워진다.
02-01 조사에서 확인한 필드로 판단한다:

| 버릴 것 | 판단 근거 필드 (예시 — 실제는 02-01 결과) |
|---|---|
| 방언 | `dialect_info` 존재 또는 `word_type == "방언"` |
| 옛말·북한어 | `word_type in {"옛말", "북한어"}` |
| 전문어 | `cat_info` 가 있고 일반어가 아님 — **단, 과도하게 버리지 않도록 02-10 눈 검수에서 확인** |
| 구·속담·관용구 | `word_unit in {"구", "속담", "관용구"}` |

버린 개수를 단계 로그에 찍는다. 나중에 "채움 풀 부족"이면 이 필터를 완화하는 게 첫 번째 손잡이다.

```python
def run(use_fixtures: bool = False) -> int:
    stats = {"total": 0, "kept": 0, "drop_dialect": 0, "drop_old": 0,
             "drop_technical": 0, "drop_phrase": 0}
    ...
    print(f"    stdict: {stats}")
    return stats["kept"]
```

## 출력 스키마

02-03과 동일. `source` 만 `"stdict"`, `sense_id` 접두어는 `"stdict:"`.

```json
{
  "source": "stdict",
  "sense_id": "stdict:98765",
  "raw_headword": "가게^주인",
  "homonym": null,
  "pos": "명사",
  "word_type": "구",
  "definition": "...",
  "synonyms": []
}
```

**주의**: 표준 표제어에는 `^`(띄어쓰기 표시), `-`(접사), `ㆍ` 등이 섞인다.
**여기서 고치지 않는다.** `raw_headword` 에 원문 그대로 넣고 02-06이 판정한다.

## 라이선스

02-03과 동일. 예문·발음·음성·이미지 **파싱하지 않는다.** 같은 테스트를 표준 샘플로도 돌린다.

## 구현 골격

```python
# tools/parse_stdict.py
from pathlib import Path
from . import config, io_util

OUT = "entries.stdict.jsonl"

DROP_WORD_TYPES = {"방언", "옛말", "북한어"}
DROP_WORD_UNITS = {"구", "속담", "관용구"}

def run(use_fixtures: bool = False) -> int:
    files = _src_files(use_fixtures)
    if not files:
        # 표준은 선택 자료다. 없으면 빈 파일을 내고 경고만 남긴다.
        print("    stdict: 원본 없음 → 빈 파일 생성 (기초사전만으로 진행)")
        return io_util.write_jsonl(config.BUILD / OUT, [])
    ...
```

**기초사전과 달리 표준은 없어도 파이프라인이 돌아야 한다.** 승인이 늦거나 거부될 수 있고,
DESIGN상 보충 역할이기 때문이다 (00-01 "막히면" 절).

## 막히면

- **메모리가 계속 증가해 죽음** → `lxml` + `getprevious()` 정리 패턴으로 전환. 이게 표준 해법이다.
- **너무 오래 걸림 (5분+)** → `lxml` 의 `tag=` 필터 사용. 그래도 느리면 파일을 분할해 순차 처리.
- **필터를 얼마나 세게 걸지 모르겠음** → 일단 약하게(방언·옛말·북한어만) 걸고, 02-10 눈 검수와 03-05 실패율을 보고 조인다. **처음부터 세게 걸면 되돌리기 어렵다.**
- **표준 승인이 안 남** → 빈 파일로 진행. 02-07 merge가 기초사전만으로 동작해야 한다(그 문서의 DoD).
