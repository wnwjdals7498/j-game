### 2. `tool/check_invariants.dart`

규칙은 **데이터로 선언**하고 실행기는 그것을 순회한다. 다른 문서가 규칙을 추가할 때 실행기를 건드리지 않게 하기 위해서다.

```dart
// tool/check_invariants.dart
//
// UI-GUIDE.md 7절 불변 조건(INV-xx) 감시. `dart run tool/check_invariants.dart`
// 를 app/ 에서 실행한다. 위반이 하나라도 있으면 exit code 1.
//
//   --git-base <ref>   INV-07(domain/data 무수정)을 이 ref와의 diff로 검사한다.
//                      없으면 INV-07은 건너뛰고 SKIP으로 표시한다.
//
// 규칙 ID·설명은 docs/UI-GUIDE.md 7절 표와 1:1이다. 여기서 규칙을 바꾸면
// 그 표도 같은 커밋에서 고친다.
import 'dart:io';

enum Kind { mustContain, mustNotContain, testNamesExist, levelsMax, depsExact, gitClean }

class Rule {
  final String id;
  final String title;
  final Kind kind;
  final List<String> paths;     // 파일 또는 glob 접두(디렉터리면 재귀)
  final List<String> exclude;   // 제외 접두
  final List<String> needles;   // 찾을/없어야 할 문자열
  final int? max;
  const Rule(this.id, this.title, this.kind,
      {this.paths = const [], this.exclude = const [], this.needles = const [], this.max});
}

const protectedTests = <String>[
  '탭 → 셀 변환: (cell*2.5, cell*1.5) 탭 → (row 1, col 2)',
  '검은 칸 탭은 무시된다 (onCellTap 미호출)',
  // … UI-GUIDE 7절 INV-08 목록 전체를 그대로 옮긴다 (24개)
];

const protectedStrings = <String>[
  '제출', '다시 풀기', '다음 레벨', '홈으로', '설정', '출처 및 라이선스',
  '칸을 눌러 단어를 고르세요', '이전 레벨을 클리어해야 열립니다',
  '재제출이라 기록에 반영되지 않았습니다', '모든 칸을 채웠습니다', '이렇게 플레이해요',
  '누적 정답률', '푼 단어',
];

const allowedDeps = <String>{
  'flutter', 'cupertino_icons', 'drift', 'drift_flutter', 'sqlite3_flutter_libs',
  'path_provider', 'provider', 'shared_preferences', 'http', 'crypto',
  'connectivity_plus', 'package_info_plus', 'sqlite3',
};

const rules = <Rule>[
  Rule('INV-01', '세로 고정', Kind.mustContain,
      paths: ['lib/main.dart'], needles: ['DeviceOrientation.portraitUp']),
  Rule('INV-02a', 'IME 하단 필드', Kind.mustContain,
      paths: ['lib/ui/puzzle/word_input.dart'], needles: ['TextField', 'committedSyllables(']),
  Rule('INV-02b', '격자에 텍스트 입력 없음', Kind.mustNotContain,
      paths: ['lib/ui/puzzle/grid_painter.dart', 'lib/ui/puzzle/grid_view.dart'],
      needles: ['TextField', 'EditableText']),
  Rule('INV-03', '격자 정답 미노출', Kind.mustNotContain,
      paths: ['lib/ui/puzzle/grid_painter.dart'], needles: ['.headword']),
  Rule('INV-04a', '격자 정답/오답 모양 구분', Kind.mustContain,
      paths: ['lib/ui/puzzle/grid_painter.dart'], needles: ['drawCircle', 'drawLine']),
  Rule('INV-04b', '결과 정답/오답 아이콘 구분', Kind.mustContain,
      paths: ['lib/ui/result/result_page.dart'], needles: ['Icons.check_circle', 'Icons.cancel']),
  Rule('INV-05', '하드코딩 색 금지', Kind.mustNotContain,
      paths: ['lib/ui', 'lib/main.dart'], exclude: ['lib/ui/theme/'],
      needles: ['Color(0x', 'Colors.']),           // 'Colors.transparent'는 실행기가 허용
  Rule('INV-06a', '라이선스 화면', Kind.mustContain,
      paths: ['lib/ui/settings/license_page.dart'], needles: ['assets/LICENSES.md']),
  Rule('INV-06b', '라이선스 진입점', Kind.mustContain,
      paths: ['lib/ui/settings/settings_page.dart'], needles: ["'출처 및 라이선스'"]),
  Rule('INV-06c', '라이선스 에셋 등록', Kind.mustContain,
      paths: ['pubspec.yaml'], needles: ['assets/LICENSES.md']),
  Rule('INV-07', 'domain/data 무수정', Kind.gitClean, paths: ['lib/domain', 'lib/data']),
  Rule('INV-08', '보호 테스트 존재', Kind.testNamesExist, paths: ['test']),
  Rule('INV-09', '사용자 문구 유지', Kind.mustContain, paths: ['lib/ui']),   // needles = protectedStrings, 디렉터리 전체에서 각 문구 1회 이상
  Rule('INV-10', '격자 상한 8', Kind.levelsMax, paths: ['lib/domain/levels.dart'], max: 8),
  Rule('INV-11', '새 의존성 금지', Kind.depsExact, paths: ['pubspec.yaml']),
];
```

실행기 요구사항:

- 출력은 규칙마다 한 줄: `PASS INV-05 하드코딩 색 금지` / `FAIL INV-05 하드코딩 색 금지 — lib/ui/home/home_page.dart:200 "Colors.amber"` / `SKIP INV-07 (--git-base 없음)`.
- `mustNotContain`은 위반 **파일:줄** 전부를 나열한다(첫 번째만 보여주면 고치는 사람이 여러 번 돌린다).
- `mustContain`에서 `paths`가 디렉터리면 "디렉터리 안 어느 파일에든 1회 이상"으로 해석한다(INV-09).
- `Colors.transparent`는 INV-05에서 허용한다. 주석 줄(`//`로 시작)은 모든 검사에서 무시한다.
- `testNamesExist`는 `test/**/*.dart` 전체 텍스트에 `protectedTests` 각 항목이 부분 문자열로 존재하는지 본다.
- `levelsMax`는 `width:\s*(\d+)`·`height:\s*(\d+)` 정규식으로 전부 뽑아 `max`와 비교한다.
- `depsExact`는 `dependencies:` 블록부터 다음 최상위 키 전까지의 2칸 들여쓰기 키 이름을 모아 `allowedDeps`와 **집합 동일성**을 비교한다(빠진 것도 실패 — 의존성 제거는 의도적이어야 하므로).
- `gitClean`은 `Process.runSync('git', ['diff', '--name-only', base, '--', ...paths])` 결과가 비어야 PASS.
- 마지막 줄에 `N passed, M failed, K skipped`. 실패 있으면 `exit(1)`.

### 3. 자체 테스트 `test/tool/check_invariants_test.dart`

스크립트가 "위반을 실제로 잡는지" 증명한다. 규칙 함수를 `lib/`가 아니라 `tool/`에 두면 테스트에서 import가 안 되므로, 실행기 로직은 `tool/check_invariants.dart`가 `import '../test/tool/../..'`처럼 꼬지 않게 **`tool/invariants/rules.dart`와 `tool/invariants/runner.dart`로 분리**하고 `check_invariants.dart`는 `main`만 둔다. 테스트는 `import '../../tool/invariants/runner.dart';`로 접근한다(`tool/`은 패키지 밖이지만 상대 import는 허용된다. `measure_test.dart`가 같은 방식인지 확인하고 아니면 그 관례를 따른다).

| 테스트 | fixture | 기대 |
|---|---|---|
| 하드코딩 색 검출 | `fixtures/violations/hardcoded_color.dart`에 `Colors.red` | INV-05 FAIL, 파일:줄 포함 |
| `Colors.transparent` 허용 | 같은 fixture에 `Colors.transparent`만 | PASS |
| 주석은 무시 | `// Colors.red` 만 있는 파일 | PASS |
| 보호 테스트 누락 | 임시 디렉터리에 목록 중 하나가 빠진 test 파일 | INV-08 FAIL, 빠진 이름 출력 |
| 의존성 추가 검출 | `fixtures/violations/pubspec_extra_dep.yaml`에 `lottie:` 추가 | INV-11 FAIL |
| 의존성 제거 검출 | `provider` 빠진 pubspec | INV-11 FAIL |
| 격자 상한 | `width: 9` 포함 levels 사본 | INV-10 FAIL |
| 실제 저장소 | 현재 `app/` | 전부 PASS 또는 SKIP(INV-07) |

실행기는 **루트 경로를 인자로 받는 함수**(`runInvariants(Directory root, {String? gitBase})`)여야 fixture 디렉터리를 가리킬 수 있다.

## 막히면

- **`tool/` 코드를 테스트에서 import할 수 없음** → `dart run`은 패키지 밖 스크립트를 허용하지만 상대 import는 `lib/` 밖에서도 된다. 그래도 막히면 실행기만 `lib/tooling/invariants_runner.dart`로 옮기고(Flutter 의존 없음, `dart:io`만) `tool/check_invariants.dart`가 `package:jgame/tooling/...`을 import한다. 이 경우 INV-05의 `exclude`에 `lib/tooling/`을 넣는다.
- **INV-09 문구가 여러 파일에 흩어져 있음** → 정상. 디렉터리 단위 "1회 이상"이므로 통과한다. 문구 자체가 바뀌어 있으면 UI-GUIDE 7절 목록을 고치는 게 아니라 **코드를 원래 문구로 되돌린다.**
- **INV-11에서 `dev_dependencies`까지 잡힘** → 블록 경계 파싱 오류. `dependencies:` 다음 줄부터 들여쓰기 0인 줄을 만나면 멈춘다.
- **Windows에서 `git` 실행 실패** → `Process.runSync('git', ..., runInShell: true)`.
- **한글 문자열 비교가 안 맞음** → 파일을 `utf8`로 읽고 있는지 확인(`File.readAsStringSync()` 기본은 utf8이지만 BOM이 있으면 첫 문자열 매칭이 빗나갈 수 있다. `﻿` 제거).
