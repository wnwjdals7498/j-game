> (필드 이름)는 이 문서 그대로 바뀌지 않았다.

**주 사전**이다. 표제어·품사·뜻풀이·유의어가 전부 여기서 나온다. 표준(02-04)은 보충일 뿐이다.

## 출력 스키마 (고정 계약)

02-06(normalize) 이후 단계가 이 형식에 의존한다. 표준 파서(02-04)도 **같은 형식**을 낸다.

```json
{
  "source": "krdict",
  "sense_id": "krdict:12345",
  "raw_headword": "가다01",
  "homonym": "01",
  "pos": "동사",
  "word_type": "일반어",
  "definition": "한 곳에서 다른 곳으로 장소를 이동하다.",
  "synonyms": ["이동하다", "향하다"]
}
```

| 필드 | 필수 | 설명 |
|---|---|---|
| `source` | ✓ | `"krdict"` 고정 |
| `sense_id` | ✓ | 출처 접두어 + 사전 고유 ID. **전역 유일해야 함** |
| `raw_headword` | ✓ | 원문 그대로. 정규화는 02-06 |
| `homonym` | | 동형어 번호. 표제어에 붙어 있으면 여기로 분리 |
| `pos` | ✓ | 원문 값 그대로. 필터는 02-06 |
| `word_type` | | 어휘 유형(일반어/구/속담/관용구/고유명사 등). 없으면 `null` |
| `definition` | ✓ | 원문 그대로. 길이 컷은 02-09 |
| `synonyms` | | 유의어 리스트. 없으면 `[]` |

**한 항목에 뜻풀이가 여러 개면 여러 행을 낸다.** 단어당 1개로 줄이는 것은 02-07(merge).

## 버릴 것 (라이선스 — DESIGN 6절)

> 인용 예문·음성·이미지는 개방 대상 아님 → 추출 단계에서 제외

파싱 단계에서 **읽지도 저장하지도 않는다.** 02-01에서 확인한 경로:

- 예문 (`Example`, `example`, ...)
- 발음·음성 (`Pronunciation`, `sound`, `.mp3`)
- 이미지·영상 (`Multimedia`, `image`, `video`)

`tools/tests/test_parse_krdict.py` 에 **이 필드가 출력에 없음을 검증하는 테스트**를 반드시 넣는다.

## 구현

```python
# tools/parse_krdict.py
import xml.etree.ElementTree as ET
from pathlib import Path
from . import config, io_util

OUT = "entries.krdict.jsonl"

def _src_files(use_fixtures: bool) -> list[Path]:
    base = config.FIXTURES if use_fixtures else config.RAW
    d = base / "krdict"
    if not d.exists():
        d = base
    return sorted(d.glob("*.xml"))

def iter_entries(path: Path):
    """iterparse 스트리밍. 항목 태그는 02-01 조사 결과로 바꿀 것."""
    ITEM = "item"          # ← README의 실제 항목 태그
    for ev, el in ET.iterparse(path, events=("end",)):
        if el.tag != ITEM:
            continue
        yield from _parse_item(el)
        el.clear()          # 메모리 해제. 없으면 수백 MB 파일에서 터진다

def _parse_item(el) -> list[dict]:
    # ↓ 전부 02-01 조사 결과의 실제 경로로 교체
    raw = (el.findtext("word_info/word") or "").strip()
    if not raw:
        return []
    homonym = (el.findtext("word_info/homonym_num") or "").strip() or None
    pos = (el.findtext("word_info/pos") or "").strip()
    wtype = (el.findtext("word_info/word_unit") or "").strip() or None

    out = []
    for sense in el.findall("word_info/pos_info/comm_pattern_info/sense_info"):
        sid = (sense.findtext("sense_code") or "").strip()
        definition = (sense.findtext("definition") or "").strip()
        if not sid or not definition:
            continue
        syns = [
            (r.findtext("word") or "").strip()
            for r in sense.findall("rel_info")
            if (r.findtext("type") or "").strip() == "비슷한말"
        ]
        out.append({
            "source": "krdict",
            "sense_id": f"krdict:{sid}",
            "raw_headword": raw,
            "homonym": homonym,
            "pos": pos,
            "word_type": wtype,
            "definition": definition,
            "synonyms": [s for s in syns if s],
        })
    return out

def run(use_fixtures: bool = False) -> int:
    files = _src_files(use_fixtures)
    if not files:
        raise FileNotFoundError(
            f"기초사전 XML 없음. tools/raw/krdict/*.xml 확인 (00-01)")

    def rows():
        for f in files:
            yield from iter_entries(f)

    return io_util.write_jsonl(config.BUILD / OUT, rows())
```

### `el.clear()` 가 중요한 이유

`iterparse` 는 처리한 요소를 **자동으로 버리지 않는다.** `clear()` 를 빼면 트리가 메모리에 다 쌓여
수백 MB XML에서 프로세스가 죽는다. 02-04의 표준국어대사전에서 특히 치명적이다.

부모 요소까지 정리하려면:

```python
        el.clear()
        while el.getprevious() is not None:   # lxml 전용
            del el.getparent()[0]
```

`xml.etree` 에는 `getprevious()` 가 없다. 표준 라이브러리로 부족하면 02-04에서 `lxml` 도입을 검토한다.
기초사전은 표준보다 작으므로 `el.clear()` 로 충분할 가능성이 높다.

## 테스트

`tools/tests/test_parse_krdict.py` — `tools/fixtures/krdict/krdict_sample.xml` 로 검증
(XML 샘플은 하위 폴더에 있다. 이유는 02-01 "승인 대기 중이라면" 절)

| 테스트 | 기대 |
|---|---|
| 항목 파싱 | 샘플의 항목 수만큼 행 생성 |
| 필수 필드 | 모든 행에 `source`/`sense_id`/`raw_headword`/`pos`/`definition` |
| `sense_id` 유일 | 중복 없음 |
| `sense_id` 접두어 | 전부 `krdict:` 로 시작 |
| 다의어 | 뜻풀이 2개인 항목 → 행 2개 |
| 유의어 | 있으면 리스트, 없으면 `[]` |
| **예문 제외** | 출력 JSON 어디에도 예문 텍스트가 없음 |
| **음성/이미지 제외** | `.mp3`, `.jpg`, `http` 문자열이 출력에 없음 |
| 빈 표제어 스킵 | 표제어 없는 항목은 행을 내지 않음 |
| 파일 없음 | `FileNotFoundError` |

라이선스 테스트가 중요하다:

```python
def test_excludes_licensed_media(tmp_path, monkeypatch):
    monkeypatch.setattr(config, "BUILD", tmp_path)
    run(use_fixtures=True)
    text = (tmp_path / OUT).read_text(encoding="utf-8")
    for banned in [".mp3", ".wav", ".jpg", ".png", "http://", "https://"]:
        assert banned not in text, f"라이선스 비개방 자료가 섞임: {banned}"
```

샘플 XML에는 **일부러 예문·음성 필드를 넣어** 이 테스트가 실제로 뭔가를 막는지 확인한다.

## 막히면

- **필드 경로가 안 맞아 전부 빈 값** → 02-01로 돌아가 실제 경로를 다시 조사한다. 추측으로 경로를 바꿔가며 시도하지 않는다.
- **메모리가 계속 증가** → `el.clear()` 누락. 항목 태그가 아닌 요소에서도 `clear()` 가 필요할 수 있다.
- **인코딩 오류** → XML 선언부의 encoding 확인. 선언과 실제가 다르면 바이트로 열어 디코딩한 뒤 `ET.fromstring`.
- **항목 태그가 파일마다 다름** → 파일별 분기를 만들지 말고, 02-01에서 파일 그룹을 먼저 분류한 뒤 그룹당 파서 함수를 나눈다.
