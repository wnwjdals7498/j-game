## 작업

### 1. `SettingsModel.soundEnabled`

기존 `wifiOnlySync`와 **같은 모양**으로 더한다(필드 → `notifyListeners()` → `prefs.setBool`). 기본값 **false**(UI-GUIDE 3.4).

```dart
const _keySoundEnabled = 'soundEnabled';
bool soundEnabled = false;            // load(): prefs.getBool(_keySoundEnabled) ?? false
Future<void> setSoundEnabled(bool value) async { /* wifiOnlySync와 동일 */ }
```

`themeMode`·`setThemeMode`는 07-02-03이 이미 넣었다. 여기서 다시 만들지 않는다.

### 2. `lib/ui/common/section_header.dart`

`settings_page.dart`의 `_SectionHeader`를 옮기고 스타일만 UI-GUIDE 2.4 `label`로 바꾼다. `colorScheme.primary`(= `ink`)에서 `inkMuted`로 내린다 — 구획 제목이 본문보다 눈에 덜 띄어야 한다(UI-GUIDE 1절 "타이포가 장식").

```dart
class SectionHeader extends StatelessWidget {
  final String title;
  const SectionHeader(this.title, {super.key});
  @override
  Widget build(BuildContext context) => Padding(
        padding: const EdgeInsets.fromLTRB(GameSpace.l, GameSpace.xl, GameSpace.l, GameSpace.xs),
        child: Text(title, style: Theme.of(context).textTheme.labelLarge
            ?.copyWith(color: GameColors.of(context).inkMuted)));
}
```

### 3. 구획 4개

`ListView`의 children 순서를 이렇게 고정한다. 구획 사이는 `Divider`(07-02-03 `dividerTheme`: `line` 1px).

| 구획 | 항목 | 위젯 | 상태 |
|---|---|---|---|
| `'화면'` | 테마 | `SegmentedButton<ThemeMode>` 3택 → `setThemeMode` | **신규** |
| `'화면'` | `'효과음'` | `SwitchListTile`, subtitle `'기기의 터치음 설정을 따릅니다'` → `setSoundEnabled` | **신규** |
| `'힌트'` | `'뜻풀이'` / `'연상어 (유의어 없으면 뜻풀이)'` | 기존 `RadioGroup` + `RadioListTile` 2개 | 그대로 |
| `'단어 데이터'` | `'버전'`·`'단어 수'`·`'빌드 시각'`·`'마지막 갱신'` | 기존 `_DbInfoSection` | 그대로 |
| `'단어 데이터'` | `'지금 갱신'` | 기존 `_SyncNowButton` | 그대로 |
| `'단어 데이터'` | `'Wi-Fi에서만 갱신'` | 기존 `SwitchListTile` | 그대로 |
| `'정보'` | `'출처 및 라이선스'` → `LicenseNoticePage` | 기존 `ListTile` + `GameRoute`(07-07-01) | INV-06b |
| `'정보'` | `'오픈소스 라이선스'`·`'앱 버전'` | 기존 `_AppVersionSection` | 그대로 |

`ListTile`은 전부 유지하고 `dense: true`만 준다. 헤더는 전부 `SectionHeader`. 항목 문구는 위 표의 작은따옴표 안 글자 그대로다(INV-09 및 기존 테스트 셀렉터).

### 4. 테마 모드 3택과 그 테마

`SectionHeader('화면')` 바로 아래, 좌우 `GameSpace.l` 패딩 안에 폭 전체로 놓는다. 모양은 전부 테마가 준다 — 위젯에는 `style:`을 주지 않는다.

```dart
SegmentedButton<ThemeMode>(
  segments: const [                        // showSelectedIcon: false —
    ButtonSegment(value: ThemeMode.system, label: Text('시스템')),  // UI-GUIDE 1절
    ButtonSegment(value: ThemeMode.light,  label: Text('라이트')),  // "아이콘으로
    ButtonSegment(value: ThemeMode.dark,   label: Text('다크')),    //  빈 곳 채우기" 금지
  ],
  selected: {settings.themeMode}, showSelectedIcon: false,
  onSelectionChanged: (s) => context.read<SettingsModel>().setThemeMode(s.first),
)
```

`app_theme.dart` `_build()`에 UI-GUIDE 2.5 버튼 규격(알약형, 선택 = `ink` 배경 + `surface` 글자)을 옮긴다. 이 파일은 `lib/ui/theme/`라 `Colors.transparent`를 써도 INV-05 검사 대상 밖이다.

```dart
segmentedButtonTheme: SegmentedButtonThemeData(style: ButtonStyle(
  shape: const WidgetStatePropertyAll(StadiumBorder()),
  side: WidgetStatePropertyAll(BorderSide(color: c.line)),
  textStyle: WidgetStatePropertyAll(GameType.label),
  backgroundColor: WidgetStateProperty.resolveWith((s) =>
      s.contains(WidgetState.selected) ? c.ink : Colors.transparent),
  foregroundColor: WidgetStateProperty.resolveWith((s) =>
      s.contains(WidgetState.selected) ? c.surface : c.ink))),
```

### 5. 기존 테스트 셀렉터

`home_settings_test.dart`의 `wrapSettings()`가 `MaterialApp(home: const SettingsPage())`뿐이라 `SectionHeader`의 `GameColors.of(context)!`가 죽는다. 한 줄만 `MaterialApp(theme: buildLightTheme(), home: const SettingsPage())`로 고친다. `useTallViewport`(800×3000)는 그대로 두면 새 구획이 늘어도 전부 렌더된다.

테스트 이름 8개는 그대로 둔다(INV-08): `'힌트 모드 변경: SettingsModel 저장, 재시작 후 유지'`, `'DB 정보: meta 값 표시'`, `'오픈소스 라이선스: showLicensePage 진입'`, `'AppScope.syncService가 null이면(웹) 버튼이 안 보임'`, `'성공: 단어 수 표시 + 재시작 안내 스낵바'`, `'스키마 불일치: "재시도"가 아니라 "업데이트" 안내'`, `'Wi-Fi에서만 갱신 토글: SettingsModel 저장, 재시작 후 유지'`, `'4개 자료명이 전부 보임 + assets/LICENSES.md와 동일한 문구'`.

## 테스트 `test/ui/settings_screen_test.dart`

`wrapApp()` 헬퍼는 `main.dart`처럼 `Consumer<SettingsModel>`로 `MaterialApp(theme:, darkTheme:, themeMode: settings.themeMode, home: SettingsPage())`를 만든다. `SharedPreferences.setMockInitialValues({})`를 `setUp`에 둔다(기존 `'설정 화면'` 그룹과 같은 방식).

| 테스트 | 기대 |
|---|---|
| 테마 모드 선택 | `'다크'` 탭 → `themeMode == ThemeMode.dark`, `tester.widget<MaterialApp>(...).themeMode == dark`, 새 `SettingsModel().load()` 후에도 `dark` |
| 테마 모드 기본값 | prefs 비었을 때 `ThemeMode.system`, `SegmentedButton.selected`가 `{system}` |
| 효과음 토글 | 기본 `false`, `'효과음'` 탭 → `true`, 새 `SettingsModel().load()` 후 `true` |
| 효과음 안내 문구 | `find.text('기기의 터치음 설정을 따릅니다')` `findsOneWidget` |
| 구획 헤더 4개 | `'화면'`, `'힌트'`, `'단어 데이터'`, `'정보'` 각 `findsOneWidget` |
| 라이선스 진입 | `'출처 및 라이선스'` 탭 → `LicenseNoticePage` 1개, `SelectableText` 1개 (INV-06b) |

S-01 동작 테스트는 이 파일에 **07-07-04가 그룹 하나를 덧붙인다.**

## 막히면

- **`SegmentedButton`이 여전히 Material 기본 모양** → 위젯 쪽 `style:`이 테마를 이기고 있다. 위젯에는 `style`을 주지 않는다(값이 UI-GUIDE 밖으로 새는 자리다).
- **3택이 좁은 화면에서 잘림** → 라벨은 `label` 스케일(13)이라 보통 들어간다. 가로 스크롤로 감싸지 말고 구획 좌우 패딩(`GameSpace.l`)을 먼저 확인한다.
- **`'다크'` 탭 후 `themeMode`가 안 바뀜** → `watch`로 읽고 `read`로 쓰는지 확인. `MaterialApp`이 `Consumer` 아래 있어야 갱신된다(07-02-03 `main.dart` 스니펫과 같은 구조).
- **테스트에서 `GameColors.of(context)!` null** → 그 테스트의 `MaterialApp`에 `theme: buildLightTheme()`이 빠졌다. 5절대로 고친다.
- **`'단어 데이터'`가 2개로 잡힘** → `_DbInfoSection`의 DB 조회 실패 분기에도 `ListTile(title: Text('단어 데이터'))`가 있다. 그 제목은 건드리지 말고 헤더 테스트는 `find.byType(SectionHeader)` 안에서 찾는다.
