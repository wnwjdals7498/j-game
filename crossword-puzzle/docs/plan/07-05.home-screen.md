## 목표

레벨 목록을 **"지금 할 것 하나"가 먼저 보이는 화면**으로 바꾼다. 상단 히어로가 다음에 풀 레벨을 크게 보여주고, 그 아래 통계 한 줄, 그 아래 레벨 카드 격자가 온다. 잠금·해제·클리어 세 상태가 카드 모양으로 구분된다.

- 히어로 부제의 단어 수는 **생성 전에는 확정값이 없다**(`LevelSpec`에 단어 수 필드가 없다). `coreCount + fillQuotas` 최솟값으로 `단어 N개 이상` 형태로 적는다 — 정확한 문구는 07-05-02가 정한다.
- 히어로가 가리키는 레벨 = **해제됐지만 미클리어인 첫 레벨**. 전부 클리어면 마지막 레벨을 "다시 도전"으로 보여준다(라벨만 바뀜, 규칙 추가 아님).

## 작업

### 1. `HomeModel` 확장

```dart
/// 히어로가 가리키는 레벨. 해제·미클리어 첫 레벨, 없으면(전부 클리어) 마지막 레벨.
LevelStatus? get nextLevel => statuses.where((s) => s.unlocked && !s.cleared).firstOrNull ?? statuses.lastOrNull;
bool get allCleared => statuses.isNotEmpty && statuses.every((s) => s.cleared);

/// E-10: 이번 `load()`에서 처음으로 unlocked가 된 레벨 id. 직전 load 결과와 비교해 계산.
/// 첫 load(비교 대상 없음)에서는 null.
int? justUnlockedId;
```

`justUnlockedId`는 이전 `statuses`를 기억해 비교한다. 결과 화면에서 돌아오면 `HomePage`가 `load()`를 다시 부르는지 확인한다 — 현재는 `ChangeNotifierProvider(create: ...load())`라 홈 위젯이 살아 있으면 재로드가 없다. **`PuzzlePage` push의 `.then((_) => model.load())`를 추가**해 돌아올 때 갱신한다(이게 없으면 클리어 표시도 갱신되지 않는 기존 문제가 있다. 있으면 그대로).

### 2. `LevelCard` + E-10

상단 표시 영역을 `AnimatedSwitcher(duration: motion.base, transitionBuilder: 회전 플립)`로 감싼다. `status.spec.id == justUnlockedId`이고 첫 프레임이면 `Icons.lock` → 번호로 전환한다. 그 외 카드는 애니메이션 없이 최종 상태. 감소 모션이면 즉시 최종 상태.

### 3. 페이지 조립

`CustomScrollView` 또는 `ListView`: `HeroCard`, `StatsRow`, `Divider`, `GridView.count(crossAxisCount: 2, childAspectRatio: 1.15, shrinkWrap: true, physics: NeverScrollable)`. 로딩·오류 상태 문구는 현재 것 유지. 본문 최대 폭 560(UI-GUIDE 4절).

## 막히면

- **`GridView` 안에서 카드 높이가 넘침** → `childAspectRatio` 1.15 기준 카드 폭 ≈ 160dp, 높이 ≈ 140dp. 내용은 상단 표시(24) + 이름(heading 17×1.3) + 여백. 글자가 길면(`'첫걸음'` 등 최대 3~4자) 문제 없음. 넘치면 패딩을 16→12로.
- **히어로 `display` 34pt가 좁은 기기에서 줄바꿈** → 레벨 이름은 최대 4자라 328dp 폭에 들어간다. `FittedBox(fit: scaleDown)`로 감싼다.
- **`firstOrNull`이 없음** → Dart 3 `package:collection` 없이도 `Iterable.firstOrNull`은 SDK 3.0+에 있다(`dart:core` 확장). 없으면 SDK 버전 확인.
- **E-10 플립이 `Icons.lock`와 번호 크기가 달라 튐** → 두 자식을 같은 `SizedBox(24×24)`에 담는다.
- **기존 테스트가 `ListTile`·`CircleAvatar`를 찾음** → 셀렉터만 `LevelCard`/텍스트로. 테스트 이름은 그대로.
