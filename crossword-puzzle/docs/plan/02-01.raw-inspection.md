### 2. XML 구조 조사 — 통째로 열지 않는다

```powershell
Get-Content tools/raw/<파일>.xml -TotalCount 200
```

그리고 태그 통계를 낸다 (전체 로드 금지):

```python
# tools/inspect_xml.py  (조사 전용. 파이프라인에 포함되지 않는다)
import sys
from collections import Counter
import xml.etree.ElementTree as ET

path = sys.argv[1]
limit = int(sys.argv[2]) if len(sys.argv) > 2 else 200000

tags = Counter()
paths = Counter()
stack = []
first_item = []

for ev, el in ET.iterparse(path, events=("start", "end")):
    if ev == "start":
        stack.append(el.tag)
        tags[el.tag] += 1
        paths["/".join(stack)] += 1
    else:
        if len(first_item) < 1 and el.tag in ("item", "entry", "LexicalEntry"):
            first_item.append(ET.tostring(el, encoding="unicode")[:4000])
        stack.pop()
        el.clear()
    if sum(tags.values()) > limit:
        break

print("=== 태그 빈도 (상위 40) ===")
for t, n in tags.most_common(40):
    print(f"{n:>9}  {t}")
print("\n=== 경로 빈도 (상위 40) ===")
for p, n in paths.most_common(40):
    print(f"{n:>9}  {p}")
if first_item:
    print("\n=== 첫 항목 원문 ===")
    print(first_item[0])
```

```powershell
tools\.venv\Scripts\python.exe tools/inspect_xml.py tools/raw/<파일>.xml
```

### 3. 확인해야 할 항목 (전부 README에 기록)

| 질문 | 왜 필요한가 |
|---|---|
| 루트/항목 태그 이름 | iterparse 대상 (02-03, 02-04) |
| 표제어 필드 경로 | `normalize` 입력 (02-06) |
| 동형어 번호가 표제어에 붙어 있나, 별도 필드인가 | `가다01` → `가다` 처리 (02-06) |
| 품사 필드 경로와 **실제 값 목록** | 명사 필터 (02-06) |
| 뜻풀이 필드 경로 | `sense.definition` (02-03) |
| 유의어/관계 정보 경로와 관계 유형 값 | `sense.synonyms` (02-03) |
| 고유 ID 필드 | `sense.sense_id` (02-09) |
| **예문·발음·음성·이미지 필드 경로** | 라이선스상 **버려야 함** (02-03) |
| 어휘 유형(구·속담·관용구) 필드 | 제외 필터 (02-06) |
| 인코딩 | UTF-8 아니면 파서에 명시 |
| 항목 총 개수 | 진행률·sanity check |

품사 값 목록은 추측하지 말고 실제로 센다:

```python
# 품사 값 전수 조사 (경로는 2번 조사 결과로 바꿀 것)
from collections import Counter
import xml.etree.ElementTree as ET
c = Counter()
for ev, el in ET.iterparse(path, events=("end",)):
    if el.tag == "pos":
        c[(el.text or "").strip()] += 1
        el.clear()
print(c.most_common())
```

### 4. csv/xlsx 조사

```powershell
Get-Content tools/raw/<빈도>.csv -TotalCount 20
```

확인: 구분자, 인코딩(CP949/EUC-KR 가능성 높음), 헤더 유무, 컬럼 순서, 순위 컬럼이 있는지 아니면 빈도수만 있는지.

**hwp/xlsx면** 한글/엑셀로 열어 **UTF-8 csv로 저장**한 뒤 `tools/raw/` 에 둔다.
변환 절차(어떤 시트, 어떤 컬럼을 남겼는지)를 README에 기록한다 — 재현 가능해야 한다.

### 5. `tools/README.md` 에 기록

00-04에서 만든 "실제 파일 구조 조사 결과" 절을 채운다. 형식:

```markdown
## 실제 파일 구조 조사 결과

조사일: YYYY-MM-DD

### 한국어기초사전 (tools/raw/krdict/*.xml)
- 파일 수 / 총 용량: N개 / XXX MB
- 인코딩: UTF-8
- 루트 태그: `<LexicalResource>` / 항목 태그: `<LexicalEntry>`
- 표제어: `LexicalEntry/Lemma/feat[@att='writtenForm']/@val`
- 동형어 번호: 표제어에 미포함, `feat[@att='homonym_number']` 별도
- 품사: `feat[@att='partOfSpeech']` — 실제 값: 명사(N), 동사(N), ...
- 뜻풀이: `Sense/feat[@att='definition']/@val`
- 유의어: `SenseRelation[@targets][feat[@att='type'][@val='비슷한말']]`
- 고유 ID: `LexicalEntry/@val` (예: `krdict:12345`)
- **버릴 것**: `Example`, `Pronunciation`, `Multimedia` (라이선스 비개방)
- 항목 총 개수: 약 N만

### 표준국어대사전 ...
### 현대 국어 사용 빈도 조사 2 ...
### 한국어 학습용 어휘 목록 ...
```

## 막히면

- **XML이 너무 커서 조사 스크립트도 느림** → `limit` 인자를 줄인다. 구조 파악에는 앞부분 20만 이벤트로 충분하다.
- **인코딩 깨짐** → `Get-Content -Encoding UTF8` 또는 파이썬에서 `encoding='cp949'` 로 재시도. XML은 선언부(`<?xml encoding=...?>`)를 먼저 본다.
- **항목 구조가 항목마다 다름** → 정상이다. 필수 필드와 선택 필드를 구분해 README에 표시하고, 파서는 선택 필드 부재를 허용한다.
- **승인이 안 나옴** → 샘플로 02-02~02-09를 전부 만든다. 파이프라인 구조는 실데이터 없이도 완성 가능하다.
