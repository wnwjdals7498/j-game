## 작업

### 1. 먼저 확인: 공용 테스트 헬퍼는 없다

07-08 부모 문서가 말하는 `fakeScope`·`testApp`은 **04-07 문서의 스니펫에만 있는 이름이고 코드로 존재한 적이 없다.** `play_loop_test.dart` 머리말이 그 사실을 이미 적어 두었다. 실제는 파일마다 같은 코드가 복붙돼 있다.

| 파일 | 지금 있는 것 |
|---|---|
| `play_loop_test.dart`, `home_settings_test.dart`, `submit_test.dart`, `tutorial_test.dart` | 지역 `buildScope(...)` + 지역 `wrapApp`/`wrapHome`/`wrapSettings` |
| `shell_test.dart`, `selection_test.dart`, `word_input_test.dart` | `AppScope(...)` 직접 생성 |

그러므로 **이 문서가 골든용 공용 헬퍼를 새로 만든다.** 기존 7개 UI 테스트 파일은 손대지 않는다 — 거기 테스트 이름은 INV-08이 지킨다.

### 2. `app/dart_test.yaml` — 태그 선언

파일이 없으므로 새로 만든다. 위치는 `app/` 루트(`pubspec.yaml` 옆)여야 한다.


### 3. `app/test/flutter_test_config.dart` — Pretendard 로드

`flutter test`는 에셋 번들을 열지 않으므로 pubspec의 `fonts:` 등록이 소용없다. 폰트를 `File`로 읽어 `FontLoader`에 직접 넣는다. 이 파일은 `test/` 아래 **모든** 테스트 실행 전에 1회 돈다.

```dart
import 'dart:async';
import 'dart:io';
import 'dart:typed_data';

import 'package:flutter/services.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:jgame/ui/theme/tokens.dart';   // GameType.family = 'Pretendard'

/// 07-02-04가 번들한 3종. 파일명이 다르면 pubspec의 `fonts:`를 보고 맞춘다.
const _fonts = <String>[
  'assets/fonts/Pretendard-Regular.otf',
  'assets/fonts/Pretendard-SemiBold.otf',
  'assets/fonts/Pretendard-Bold.otf',
];

Future<void> testExecutable(FutureOr<void> Function() testMain) async {
  TestWidgetsFlutterBinding.ensureInitialized();
  final files = _fonts.map(File.new).toList();
  if (files.every((f) => f.existsSync())) {
    final loader = FontLoader(GameType.family);
    for (final f in files) {
      loader.addFont(f.readAsBytes().then((b) => ByteData.sublistView(b)));
    }
    await loader.load();
  }
  // 파일이 하나라도 없으면 조용히 시스템 폰트로 간다 — 07-02-04 전에도 기존
  // 테스트가 전부 돌아야 하기 때문이다. 이 폴백은 07-08-02의 "두부 글리프
  // 없음" 눈 검수에서 반드시 드러난다.
  await testMain();
}
```

- 상대 경로는 `flutter test`의 cwd(`app/`) 기준이다.
- 폰트 이름은 `'Pretendard'`를 다시 적지 말고 `GameType.family`(07-02-01)를 쓴다.
- 골든이 아닌 테스트에도 폰트가 실리지만 무해하다 — 글리프 폭만 바뀌고 `find.text` 셀렉터는 영향받지 않는다.

### 4. `app/test/golden/golden_helpers.dart` — 고정 조건 한 곳

```dart
/// 07-08 A절 "크기 고정". 폰 세로 한 종만 쓴다.
const goldenSize = Size(390, 844);

/// `../tools/schema.sql`로 임시 빈 DB를 연다 — `play_loop_test.dart`와 같은
/// 방식이고, cwd가 `app/`일 때 맞는 경로다.
AppDatabase openGoldenDb(Directory tmp, {int seq = 0}) { … }

/// 더미 사전 seed 1로 만든 가짜 의존성. `syncService`는 null(골든 3장과 무관).
AppScope goldenScope(AppDatabase db) {
  final words = InMemoryWordRepository(buildDummyDictionary(seed: 1));
  return AppScope(db: db, words: words, stats: StatRepository(db),
      generator: GridGenerator(words), hints: HintRepository(db));
}

Future<void> pumpGolden(
  WidgetTester tester,
  Widget child, {
  required AppScope scope,
  required ThemeMode themeMode,
  SettingsModel? settings,
}) async {
  tester.view.physicalSize = goldenSize;
  tester.view.devicePixelRatio = 1.0;
  addTearDown(tester.view.resetPhysicalSize);
  addTearDown(tester.view.resetDevicePixelRatio);

  await tester.pumpWidget(MultiProvider(
    providers: [
      Provider<AppScope>.value(value: scope),
      ChangeNotifierProvider<SettingsModel>.value(
          value: settings ?? SettingsModel()),
    ],
    child: MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: /* 07-02-03의 라이트 ThemeData */,
      darkTheme: /* 07-02-03의 다크 ThemeData */,
      themeMode: themeMode,
      // MaterialApp 바깥의 MediaQuery는 WidgetsApp의 MediaQuery.fromView가
      // 덮어쓴다. 반드시 builder 안에서 감싼다.
      builder: (context, inner) => MediaQuery(
        data: MediaQuery.of(context).copyWith(
            disableAnimations: true, textScaler: TextScaler.noScaling),
        child: inner!,
      ),
      home: child,
    ),
  ));
  await tester.pumpAndSettle();
}
```

| 고정값 | 값 | 출처 |
|---|---|---|
| 크기 / `devicePixelRatio` | `Size(390, 844)` / `1.0` | 07-08 A절 |
| `disableAnimations` | `true` | 07-08 A절 "모션" |
| `textScaler` | `noScaling` | 시스템 글꼴 배율이 골든을 흔들지 않게 |
| 사전 seed | `1` | 07-08 A절 "데이터 고정" |
| 테마 | 07-02-03의 두 `ThemeData` | UI-GUIDE 2.2 |

`disableAnimations: true`면 `GameMotion.of(context)`가 모든 시간을 `Duration.zero`로 돌려준다(UI-GUIDE 3.2). 골든은 이펙트의 **최종 상태**만 찍는다.

## 막히면

- **`FontLoader`에 파일을 못 넘김** → `ByteData.sublistView(bytes)`를 쓴다(`ByteData.view(b.buffer)`는 뷰 오프셋이 0이 아닐 때 어긋난다). cwd가 `app/`인지도 확인한다.
- **`flutter_test_config.dart`가 안 불림** → 위치가 `test/` 바로 아래여야 한다(`test/golden/`이 아니다). 함수 이름도 정확히 `testExecutable`.
- **폰트를 실은 뒤 기존 테스트가 오버플로로 깨짐** → 그 화면이 시스템 폰트 폭에 기대고 있었다는 뜻이다. 폰트 로드를 끄지 말고 해당 화면 문서(07-03~07-07)로 돌아가 레이아웃을 고친다.
- **`MediaQuery`가 안 먹어 애니메이션이 돈다** → `MaterialApp` **바깥**에 감쌌을 때 생긴다. `builder:` 안으로 옮긴다.
- **`dart_test.yaml`이 무시됨 / `openGoldenDb`가 `../tools/schema.sql`을 못 찾음** → 둘 다 cwd·위치 문제다. `dart_test.yaml`은 `app/` 루트, 테스트는 `cd app` 후 실행(기존 UI 테스트도 같은 제약이다).
