## 작업

### 1. `HomeModel` 확장

`statuses` 선언 아래에 붙인다. `firstOrNull`/`lastOrNull`은 Dart 3 `IterableExtensions`라 **import 없이** 쓸 수 있다(SDK 3.13.3에서 확인).

```dart
/// 히어로가 가리키는 레벨(07-05-02). 해제·미클리어 첫 레벨, 없으면 마지막 레벨.
LevelStatus? get nextLevel =>
    statuses.where((s) => s.unlocked && !s.cleared).firstOrNull ?? statuses.lastOrNull;

/// 전 레벨 클리어. 히어로 라벨을 '다시 도전'으로 바꾸는 조건(라벨만, 규칙 추가 아님 — N-04).
bool get allCleared => statuses.isNotEmpty && statuses.every((s) => s.cleared);

/// E-10 대상: 이번 [load]에서 처음 unlocked가 된 레벨 id. 첫 load는 null.
int? justUnlockedId;
```

`load()`의 `try` 블록 안, `out`을 다 만든 뒤 `statuses = out;` **앞에** 한 줄을 넣는다.

```dart
// 이전 statuses와 비교해 "이번에 열린" 레벨 1개를 찾는다. 첫 load는 비교 대상이
// 없으므로 null — 앱 진입 때마다 해제 연출이 나오면 안 된다(3.3 E-10 "해제된 직후").
final prevUnlocked = {for (final s in statuses) s.spec.id: s.unlocked};
justUnlockedId = prevUnlocked.isEmpty
    ? null
    : out.where((s) => s.unlocked && prevUnlocked[s.spec.id] == false).firstOrNull?.spec.id;
statuses = out;
```

`load()` 앞부분의 `loading = true; error = null;`은 그대로 둔다. `justUnlockedId`는 여기서 초기화하지 않는다 — 실패(`catch`)해도 직전 값이 남지만, 실패하면 `statuses`도 안 바뀌므로 해당 카드가 그대로 있다.

### 2. 퍼즐 진입을 한 곳으로 모으고 복귀 시 재로드

`home_page.dart`에 파일 전용 헬퍼를 만들고, `_LevelRow._onTap`의 `Navigator.push` 블록을 이 호출로 바꾼다. 07-05-02의 히어로 "시작" 버튼과 07-05-03의 `LevelCard`가 같은 함수를 쓴다.

```dart
/// 레벨 진입(04-05: 홈이 레벨과 새 seed를 정해 직접 push). 돌아오면 해제·통계가
/// 달라졌을 수 있어 다시 읽는다 — `ChangeNotifierProvider(create: ...load())`는
/// 홈 위젯이 살아 있는 동안 재로드하지 않는다.
void _openLevel(BuildContext context, LevelSpec spec) {
  final model = context.read<HomeModel>();
  Navigator.of(context)
      .push(MaterialPageRoute(
        builder: (_) => PuzzlePage(spec: spec, seed: newSeed()),
      ))
      .then((_) {
    if (context.mounted) model.load(); // 홈이 이미 사라졌으면 notifyListeners 금지
  });
}
```

결과 화면의 "다음 레벨"/"홈으로"는 `pushAndRemoveUntil`/`popUntil(isFirst)`로 이 라우트를 **제거**한다(`puzzle_page.dart` `_goToNextLevel`) — 제거도 `push`가 준 Future를 완료시키므로 `.then`이 똑같이 돈다.

### 3. 재로딩 중 스피너 억제

재로드가 생겼으므로 `_HomeBody`의 분기를 고친다. 안 고치면 퍼즐에서 돌아올 때마다 화면 전체가 스피너로 한 번 깜빡이고, 07-05-03의 E-10 플립이 "새로 그려짐"이 되어 애니메이션이 사라진다.

```dart
body: model.loading && model.statuses.isEmpty
    ? const Center(child: CircularProgressIndicator())
    : model.error != null
        ? /* 기존 안내 문구 그대로 */
        : /* 기존 Column 그대로 */
```

로딩·오류의 **문구와 위젯은 손대지 않는다**(부모 문서 "로딩·오류 상태 문구는 현재 것 유지"). 홈 로딩 표시를 E-11(`LinearProgressIndicator`)로 바꿀지는 07-07이 정한다.

### 4. 테스트 `test/ui/home_model_test.dart` (신규)

`home_settings_test.dart`의 `openEmptyDb()`·`buildScope()`·`wrapHome()`·`useTallViewport()`를 그대로 복사해 쓴다. `setUp`에 `SharedPreferences.setMockInitialValues({tutorialSeenPrefsKey: true})`를 넣는다 — 안 넣으면 퍼즐 진입 시 튜토리얼 시트(`'이렇게 플레이해요'`)가 떠서 pop이 막힌다.

호출 횟수를 세는 가짜는 실 `StatRepository`를 감싸 위임한다(6개 public 메서드 전부 `@override`).

```dart
class _CountingStats implements StatRepository {
  _CountingStats(this._inner);
  final StatRepository _inner;
  int bestScoresCalls = 0;

  @override
  Future<Map<int, int>> bestScores() {
    bestScoresCalls++;
    return _inner.bestScores();
  }
  // bestScore / isFirstSubmit / recordSubmit / summary / resetAll 는 그대로 위임
}
```

| 테스트 | 기대 |
|---|---|
| `nextLevel`: 해제·미클리어 첫 레벨 | 레벨 1 클리어 행 INSERT → `load()` → `nextLevel!.spec.id == 2`, `allCleared == false` |
| `nextLevel`: 전부 클리어면 마지막 레벨 | 10레벨 전부 `puzzle_log` INSERT → `nextLevel!.spec.id == levels.last.id`, `allCleared == true` |
| `justUnlockedId`: 첫 load는 null | 빈 DB `load()` 1회 → `justUnlockedId == null` |
| `justUnlockedId`: 두 번째 load에서 새로 열린 레벨 | 1회 load 후 레벨 1 클리어 INSERT → 2회 `load()` → `justUnlockedId == 2` |
| 돌아오면 재로드 | `wrapHome` → 레벨 1 탭 → `PuzzlePage` → `Navigator.pop` → `stats.bestScoresCalls == 2` |

마지막 2종("첫 로드 없음", "돌아오면 재로드")은 부모 문서 표 10종 중 2개다 — 07-05-03이 이 파일에 있음을 확인하는 것으로 10종을 확정한다.

## 막히면

- **`use_build_context_synchronously` 경고** → `.then` 안의 `if (context.mounted)` 가드가 린트를 만족시킨다. 가드를 지우지 말고 `await`+`if (!context.mounted) return;` 형태로 바꿔도 된다.
- **`ChangeNotifier was used after being disposed`** → `context.mounted` 가드가 빠졌다. `_openLevel`은 반드시 push **전에** `context.read<HomeModel>()`로 모델을 잡아 둔다(`.then` 안에서 read하면 트리가 이미 사라졌을 수 있다).
- **`bestScoresCalls`가 2가 아니라 3** → 재로드가 두 번 돈다. `_openLevel`을 히어로/카드 양쪽에서 중복 호출하고 있거나 `initState`에도 `load()`가 남았는지 본다.
- **"다음 레벨"을 연달아 타서 돌아오면 홈이 옛날 값** → 알려진 한계다. 홈이 push한 라우트는 첫 `pushAndRemoveUntil`에서 제거되고, 그 뒤 퍼즐 라우트는 홈이 push한 게 아니라 `.then`이 없다. 07-08 실기기 체크에서 문제가 되면 `RouteObserver`+`RouteAware`로 올린다(`main.dart`의 `navigatorObservers`) — 이 커밋에서는 하지 않는다.
- **`firstOrNull`을 못 찾음** → SDK가 3.0 미만이다. `pubspec.yaml` `environment: sdk: ^3.13.3` 확인. `package:collection`을 추가하지 않는다(INV-11).
