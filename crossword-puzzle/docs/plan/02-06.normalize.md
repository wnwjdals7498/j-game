# 02-06. 표제어 정규화 · 필터

담당: **AGENT**
선행: 02-03, 02-04, 02-05 · 다음: 02-07
상위: [02-tools-etl.md](02-tools-etl.md) "표제어 정규화·필터 규칙" · [../REVIEW.md](../REVIEW.md) 4.2 (b)(c)

## 목표

사전 표제어에서 **격자에 쓸 수 있는 형태만** 남긴다. DESIGN에 없던 규칙이라 여기서 확정한다.

> 사전 표제어에는 동형어 번호(`가다01`), 접사 하이픈(`-이다`), 띄어쓰기(`가게 주인`),
> 비한글(`PC방`)이 섞여 있다. 격자에 쓸 수 있는 형태는 "한글 완성형 음절 2~5개로만 구성"이다.

## 규칙 (확정)

입력: `entries.krdict.jsonl` + `entries.stdict.jsonl`
출력: `build/normalized.jsonl`

### 1. 정규화 (버리기 전에 고칠 수 있는 것만 고친다)

| 순서 | 처리 | 예 |
|---|---|---|
| 1 | 유니코드 NFC 정규화 | 조합형 → 완성형 |
| 2 | 앞뒤 공백 제거 | |
| 3 | 동형어 번호 제거 | `가다01` → `가다`, `사과02` → `사과` |
| 4 | 첨자·기호 제거 | `가다¹` → `가다` |

동형어 번호는 **표제어 끝의 숫자**다. 정규식 `r"\d+$"`.
단, `4H`, `3D` 같은 표제어가 있을 수 있으나 이런 건 5번(완성형 검사)에서 어차피 탈락한다.
`homonym` 필드가 따로 있으면 그걸 우선 믿고, 표제어에 붙어 있을 때만 잘라낸다.

**고치지 않는 것** — 이건 정규화가 아니라 다른 단어로 바꾸는 것이다:
- 띄어쓰기/`^` 제거 (`가게 주인` → `가게주인` ✗). 그냥 버린다.
- 하이픈 제거 (`-이다` → `이다` ✗). 접사는 단어가 아니다. 버린다.

### 2. 필터 (전부 만족해야 통과)

| # | 조건 | 탈락 예 |
|---|---|---|
| F1 | 모든 글자가 한글 완성형 (U+AC00~U+D7A3) | `PC방`, `MP3`, `가-`, `가 게`, `가·나` |
| F2 | 길이 2~5음절 | `달`(1), `가나다라마바`(6) |
| F3 | `pos` 가 `config.ALLOWED_POS` 에 있음 | 1차는 `명사`만 |
| F4 | `word_type` 이 `config.EXCLUDE_WORD_TYPES` 에 없음 | 구·속담·관용구 |
| F5 | 고유명사 제외 | `서울`(고유명사로 표기된 경우) |

F1이 F2보다 먼저다 — 비한글이 섞이면 길이 개념이 무의미하다.

### 3. 탈락 사유 집계

**각 필터가 몇 개를 걸렀는지 반드시 센다.** 나중에 "채움 풀이 부족하다"(03-05)가 되면
어느 필터를 완화할지 이 숫자로 판단한다.

```
    normalize: 입력 123,456 → 통과 45,678
      F1 비한글/기호      12,345
      F2 길이             23,456
      F3 품사             34,567
      F4 어휘유형          5,678
      F5 고유명사          1,732
```

## 출력 스키마

```json
{
  "source": "krdict",
  "sense_id": "krdict:12345",
  "headword": "사과",
  "raw_headword": "사과02",
  "len": 2,
  "syllables": ["사", "과"],
  "pos": "명사",
  "definition": "...",
  "synonyms": ["실과"]
}
```

`headword` 가 정규화 결과, `raw_headword` 는 추적용 원문.

## 구현

```python
# tools/normalize.py
import re
import unicodedata
from collections import Counter
from . import config, io_util

OUT = "normalized.jsonl"
IN = ["entries.krdict.jsonl", "entries.stdict.jsonl"]

_HOMONYM = re.compile(r"\d+$")
_SUPERSCRIPT = str.maketrans("", "", "¹²³⁴⁵⁶⁷⁸⁹⁰")

def normalize_headword(raw: str) -> str:
    s = unicodedata.normalize("NFC", raw).strip()
    s = s.translate(_SUPERSCRIPT)
    s = _HOMONYM.sub("", s)
    return s.strip()

def is_hangul_syllable(ch: str) -> bool:
    return config.HANGUL_START <= ord(ch) <= config.HANGUL_END

def is_all_hangul(s: str) -> bool:
    return bool(s) and all(is_hangul_syllable(c) for c in s)

def check(entry: dict) -> str | None:
    """통과하면 None, 탈락하면 사유 코드."""
    hw = entry["headword"]
    if not is_all_hangul(hw):
        return "F1"
    if not (config.MIN_LEN <= len(hw) <= config.MAX_LEN):
        return "F2"
    if entry.get("pos") not in config.ALLOWED_POS:
        return "F3"
    if entry.get("word_type") in config.EXCLUDE_WORD_TYPES:
        return "F4"
    if config.EXCLUDE_PROPER_NOUN and entry.get("pos") == "고유명사":
        return "F5"
    return None

def run(use_fixtures: bool = False) -> int:
    stats = Counter()

    def rows():
        for name in IN:
            p = config.BUILD / name
            if not p.exists():
                continue
            for e in io_util.read_jsonl(p):
                stats["in"] += 1
                hw = normalize_headword(e["raw_headword"])
                cand = {**e, "headword": hw}
                why = check(cand)
                if why:
                    stats[why] += 1
                    continue
                stats["out"] += 1
                yield {
                    "source": cand["source"],
                    "sense_id": cand["sense_id"],
                    "headword": hw,
                    "raw_headword": e["raw_headword"],
                    "len": len(hw),
                    "syllables": list(hw),
                    "pos": cand["pos"],
                    "definition": cand["definition"],
                    "synonyms": cand.get("synonyms", []),
                }

    n = io_util.write_jsonl(config.BUILD / OUT, rows())
    print(f"    normalize: 입력 {stats['in']:,} → 통과 {stats['out']:,}")
    for code in ("F1", "F2", "F3", "F4", "F5"):
        print(f"      {code}  {stats[code]:,}")
    return n
```

### `pos` 값 주의

`config.ALLOWED_POS = {"명사"}` 는 02-01 조사에서 확인한 **실제 값**이어야 한다.
사전이 `"명사 "`(공백), `"NNG"`, `"명사(名詞)"` 처럼 줄 수 있다. F3 탈락이 비정상적으로 많으면
이게 원인이다. 파서에서 `.strip()` 을 했는지, 값 목록이 맞는지 확인한다.

### 고유명사 판정

품사가 `고유명사` 로 따로 오는 사전도 있고, `명사` + 별도 플래그인 사전도 있다.
02-01 조사 결과에 맞춰 F5를 구현한다. 판정 근거가 없으면 F5를 건너뛰고
**그 사실을 로그와 README에 남긴다** (02-10 눈 검수에서 잡는다).

## 테스트

`tools/tests/test_normalize.py` — **표 기반 테스트**로 쓴다. 규칙이 많아 케이스별로 쓰면 놓친다.

```python
import pytest
from tools.normalize import normalize_headword, check

@pytest.mark.parametrize("raw,expected", [
    ("가다01", "가다"),
    ("사과02", "사과"),
    ("가다", "가다"),
    ("  사과  ", "사과"),
    ("가다¹", "가다"),
    ("-이다", "-이다"),        # 하이픈은 안 고친다 (F1에서 탈락)
    ("가게 주인", "가게 주인"),  # 공백도 안 고친다 (F1에서 탈락)
])
def test_normalize_headword(raw, expected):
    assert normalize_headword(raw) == expected

@pytest.mark.parametrize("hw,pos,wtype,why", [
    ("사과",     "명사", "일반어", None),
    ("사과나무", "명사", "일반어", None),
    ("가나다라마", "명사", "일반어", None),      # 5음절 통과
    ("달",       "명사", "일반어", "F2"),        # 1음절
    ("가나다라마바", "명사", "일반어", "F2"),    # 6음절
    ("PC방",     "명사", "일반어", "F1"),
    ("MP3",      "명사", "일반어", "F1"),
    ("-이다",    "명사", "일반어", "F1"),
    ("가게 주인", "명사", "일반어", "F1"),
    ("가게^주인", "명사", "일반어", "F1"),
    ("사과",     "동사", "일반어", "F3"),
    ("사과",     "명사", "속담",   "F4"),
    ("서울",     "고유명사", "일반어", "F5"),
])
def test_filter(hw, pos, wtype, why):
    e = {"headword": hw, "pos": pos, "word_type": wtype}
    assert check(e) == why
```

추가 테스트:

| 테스트 | 기대 |
|---|---|
| 조합형 NFC 정규화 | 분해된 `사` → 완성형 `사` |
| `syllables` 길이 | `len(syllables) == len` |
| 통계 집계 | 사유별 개수 합 + 통과 수 == 입력 수 |
| 입력 파일 없음 | 예외 없이 건너뜀 (표준 없을 때) |

마지막 테스트가 중요하다 — 02-04가 빈 파일을 낼 수 있다.

## 막히면

- **F3 탈락이 90%** → `pos` 실제 값이 `config.ALLOWED_POS` 와 다르다. `build/normalized.jsonl` 대신 `entries.krdict.jsonl` 의 `pos` 값을 `Counter` 로 세어 확인한다.
- **통과 단어가 너무 적음 (1만 미만)** → F1 탈락 내역을 샘플로 출력해 본다. 사전이 표제어에 항상 뭔가를 붙여 준다면 정규화 규칙을 하나 더 추가해야 한다.
- **품사 범위를 넓히고 싶음** → `config.ALLOWED_POS` 에 `"동사"`, `"형용사"` 추가. 단 기본형(`가다`, `예쁘다`)이 표제어로 들어오는지 확인하고, **결정을 `docs/DESIGN.md` 5절에 기록**한다. `pos` 컬럼은 DB에 남으므로 레벨 스펙에서 켜고 끌 수 있다 (REVIEW 4.2 (c)).
- **고유명사 판정 근거가 없음** → F5를 건너뛰고 README에 기록. 02-10 눈 검수에서 티어별 샘플에 고유명사가 보이면 그때 대응한다.
