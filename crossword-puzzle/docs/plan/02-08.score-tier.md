# 02-08. 난이도 점수 · 7티어 분할

## 목표

각 단어에 0(쉬움)~1(어려움) 점수를 매기고 **피라미드 비율**로 7티어로 자른다.

> 7등분할 때 **등분위 금지** — 상위 티어를 얇게 가져가는 피라미드 분포로 자른다.

## 산식 (초안, `config.py` 에서 조정)

```
base   = 빈도 순위 정규화 (0 = 최빈, 1 = 최저). 빈도 없음 → NO_FREQ_BASE (1.0)
adj    = ADJ_VOCAB[grade]           A: -0.15 / B: -0.10 / C: -0.05
adj   += ADJ_IN_KRDICT (-0.10)      기초사전 등재
adj   += ADJ_PER_EXTRA_SYLLABLE × (음절수 - 2)    (+0.03/음절)
adj   += ADJ_COMPLEX_JAMO (+0.05)   겹받침·이중모음 포함
score  = clamp(base + adj, 0, 1)
```

### `base` 정규화

```python
base = (rank - 1) / (max_rank - 1)
```

`rank` 1이 0.0, 최하위가 1.0. 빈도 정보가 없는 단어는 `NO_FREQ_BASE = 1.0`.

**주의**: 빈도 미매칭이 많으면(02-07 로그 참고) 1.0에 단어가 대량으로 몰려
상위 티어가 "빈도 없는 단어" 로 가득 찬다. 이게 나쁘지 않다 — 빈도 조사에 안 나오는 단어는
실제로 어렵다. 다만 02-10 눈 검수에서 7티어가 이상한 단어로만 채워졌는지 확인한다.

### 복잡 자모 판정

한글 완성형 음절을 초/중/종성으로 분해해 판정한다.

```python
# tools/hangul.py  (02-06/02-07이 쓰는 정규화 함수도 여기로 모은다)
CHO = ["ㄱ","ㄲ","ㄴ","ㄷ","ㄸ","ㄹ","ㅁ","ㅂ","ㅃ","ㅅ","ㅆ","ㅇ","ㅈ","ㅉ","ㅊ","ㅋ","ㅌ","ㅍ","ㅎ"]
JUNG = ["ㅏ","ㅐ","ㅑ","ㅒ","ㅓ","ㅔ","ㅕ","ㅖ","ㅗ","ㅘ","ㅙ","ㅚ","ㅛ","ㅜ","ㅝ","ㅞ","ㅟ","ㅠ","ㅡ","ㅢ","ㅣ"]
JONG = ["","ㄱ","ㄲ","ㄳ","ㄴ","ㄵ","ㄶ","ㄷ","ㄹ","ㄺ","ㄻ","ㄼ","ㄽ","ㄾ","ㄿ","ㅀ","ㅁ","ㅂ","ㅄ","ㅅ","ㅆ","ㅇ","ㅈ","ㅊ","ㅋ","ㅌ","ㅍ","ㅎ"]

COMPLEX_JONG = {"ㄳ","ㄵ","ㄶ","ㄺ","ㄻ","ㄼ","ㄽ","ㄾ","ㄿ","ㅀ","ㅄ"}   # 겹받침
COMPLEX_JUNG = {"ㅘ","ㅙ","ㅚ","ㅝ","ㅞ","ㅟ","ㅢ","ㅒ","ㅖ"}              # 이중모음

def decompose(ch: str) -> tuple[str, str, str]:
    code = ord(ch) - 0xAC00
    if not (0 <= code <= 11171):
        raise ValueError(f"완성형 아님: {ch}")
    return CHO[code // 588], JUNG[(code % 588) // 28], JONG[code % 28]

def has_complex_jamo(word: str) -> bool:
    for ch in word:
        _, jung, jong = decompose(ch)
        if jong in COMPLEX_JONG or jung in COMPLEX_JUNG:
            return True
    return False
```

## 티어 분할 — 피라미드

```
TIER_RATIO = [25, 22, 18, 14, 10, 7, 4]   # 합 100
```

점수 **오름차순 정렬** 후 누적 비율로 자른다. 티어 1이 가장 쉽고 가장 많다.

```python
def assign_tiers(scored: list[dict]) -> None:
    """scored를 score 오름차순으로 정렬한 뒤 tier를 부여한다."""
    # 동점은 headword로 안정 정렬 (재현성)
    scored.sort(key=lambda r: (r["score"], r["headword"]))
    n = len(scored)
    bounds, acc = [], 0
    for ratio in config.TIER_RATIO:
        acc += ratio
        bounds.append(round(n * acc / 100))
    bounds[-1] = n                     # 반올림 오차 흡수

    t, start = 1, 0
    for end in bounds:
        for i in range(start, end):
            scored[i]["tier"] = t
        start = end
        t += 1
```

**등분위 금지**: `TIER_RATIO` 가 전부 같은 값이 아닌지 02-02의 테스트가 강제한다.

## 구현

```python
# tools/score.py
from . import config, io_util, hangul

OUT = "scored.jsonl"

def compute_score(r: dict, max_rank: int) -> float:
    rank = r.get("freq_rank")
    base = (config.NO_FREQ_BASE if rank is None
            else (rank - 1) / max(max_rank - 1, 1))

    adj = 0.0
    g = r.get("vocab_grade")
    if g in config.ADJ_VOCAB:
        adj += config.ADJ_VOCAB[g]
    if r.get("in_krdict"):
        adj += config.ADJ_IN_KRDICT
    adj += config.ADJ_PER_EXTRA_SYLLABLE * (r["len"] - 2)
    if hangul.has_complex_jamo(r["headword"]):
        adj += config.ADJ_COMPLEX_JAMO

    return min(1.0, max(0.0, base + adj))

def run(use_fixtures: bool = False) -> int:
    rows = list(io_util.read_jsonl(config.BUILD / "merged.jsonl"))
    ranks = [r["freq_rank"] for r in rows if r.get("freq_rank")]
    max_rank = max(ranks) if ranks else 1

    for r in rows:
        r["score"] = round(compute_score(r, max_rank), 6)
    assign_tiers(rows)

    counts = {}
    for r in rows:
        counts[r["tier"]] = counts.get(r["tier"], 0) + 1
    print(f"    score: {len(rows):,} words")
    for t in range(1, config.TIER_COUNT + 1):
        n = counts.get(t, 0)
        print(f"      tier {t}  {n:>7,}  {n / max(len(rows), 1) * 100:5.1f}%")

    return io_util.write_jsonl(config.BUILD / OUT, rows)
```

`round(score, 6)` — 부동소수 꼬리 때문에 파일이 실행마다 달라지는 걸 막는다 (재현성).

## 테스트

`tools/tests/test_score.py`, `tools/tests/test_hangul.py`

| 테스트 | 기대 |
|---|---|
| 빈도 1위 → base 0 | `compute_score` 의 base 부분이 0 |
| 빈도 없음 → base 1.0 | `NO_FREQ_BASE` 적용 |
| 등급 A 보정 | A가 B보다 점수 낮음 |
| 기초 등재 보정 | 등재 쪽이 점수 낮음 |
| 음절 패널티 | 5음절이 2음절보다 점수 높음 (다른 조건 동일) |
| 복잡 자모 패널티 | `닭고기`(겹받침)가 `다고기`보다 높음 |
| clamp | 결과가 항상 [0, 1] |
| 티어 비율 | 각 티어 개수가 `TIER_RATIO` ±1% |
| **피라미드** | `count[1] > count[2] > ... > count[7]` |
| 티어 범위 | 모든 tier가 1..7 |
| 동점 안정 정렬 | 두 번 실행 → 같은 티어 배정 |
| 자모 분해 | `강` → (ㄱ, ㅏ, ㅇ), `읽` → (ㅇ, ㅣ, ㄺ) |
| 겹받침 판정 | `읽다`의 `읽` → True |
| 이중모음 판정 | `과일`의 `과` → True |
| 단순 음절 | `사과`의 `사` → False... `과`는 True (ㅘ) |

마지막 케이스 주의: `사과` 는 `과` 때문에 복잡 자모로 판정된다. 의도한 동작이다.
이중모음이 너무 흔해 패널티가 무의미하면 `COMPLEX_JUNG` 를 `{"ㅙ","ㅚ","ㅞ","ㅟ","ㅢ"}` 정도로 좁힌다.
**바꾸면 `config` 가 아니라 `hangul.py` 이므로, 결정을 주석으로 남긴다.**

## 막히면

- **7티어가 빈도 없는 단어로만 채워짐** → 정상일 수 있다. 02-10 눈 검수에서 "7티어에 쉬운 단어가 있는가" 를 본다. 문제면 `NO_FREQ_BASE` 를 0.85 정도로 낮춰 다른 신호와 섞이게 한다.
- **1티어에 어려운 단어가 있음** → 빈도 조사가 구어/신문 기준이라 생기는 현상. `ADJ_VOCAB` 보정을 키운다(A: -0.25).
- **티어 분포가 비율과 안 맞음** → `bounds` 계산의 반올림. `bounds[-1] = n` 을 빠뜨렸는지 확인.
- **`decompose` 가 ValueError** → 완성형 아닌 글자가 들어왔다. 02-06 F1 필터가 안 먹은 것이다. 여기서 try/except로 덮지 말고 02-06을 고친다.
- **산식을 바꾸고 싶음** → `config.py` 값만 바꾸고 `python -m tools build --only score` 로 빠르게 재실행한다. merge까지 다시 돌릴 필요 없다. 이게 파이프라인을 쪼갠 이유다.
