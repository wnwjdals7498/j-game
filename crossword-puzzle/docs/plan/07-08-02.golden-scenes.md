## 작업

### 1. 장면 데이터 고정

seed는 **1000**을 쓴다. 새로 고른 값이 아니라 `submit_test.dart`·`play_loop_test.dart`·`levels_test.dart`가 이미 결정성 확인에 쓰는 값이다.

| 장면 | DB 선행 상태 | 화면 조작 |
|---|---|---|
| 홈 | `puzzle_log`에 `(1, 1000, 12)` 1행 + `word_stat` 6행(정답 5·오답 1) | `HomePage`를 `pumpGolden` |
| 퍼즐 | 빈 DB | 레벨 1·seed 1000 로드 → 첫 가로 단어 선택 → 앞 2음절 입력 → 두 번째 단어 선택 → 1음절 입력 |
| 결과 | 빈 DB(첫 제출이어야 한다) | 레벨 1·seed 1000 로드 → 정답·오답·빈칸 각 1개 이상 만든 뒤 제출 → `ResultPage` |

홈의 선행 상태는 `recordSubmit`으로 만들지 말고 SQL로 직접 넣는다. `SubmitResult`를 손으로 조립하는 것보다 짧고 점수가 그대로 고정된다.

```dart
await db.customStatement(
  'INSERT INTO puzzle_log (level_id, seed, first_score, submitted_at) VALUES (1, 1000, 12, 0)');
// 홈 통계 한 줄("누적 정답률", "푼 단어")이 0/0이 아니게 word_stat도 채운다.
for (final (hw, c, w) in [('가나', 1, 0), ('나라', 1, 0), ('다리', 1, 0),
                          ('라면', 1, 0), ('마루', 1, 0), ('바다', 0, 1)]) {
  await db.customStatement(
    'INSERT INTO word_stat (headword, correct, wrong, last_seen) VALUES (?, ?, ?, 0)',
    [hw, c, w]);
}
```

레벨 1의 `clearScore`가 0이므로 `first_score 12`면 **클리어**다. `HomeModel.load`가 레벨 1 클리어 → 레벨 2 해제 → 3부터 잠금으로 채운다. 부모 문서가 요구한 "카드 3상태 모두 보임"이 첫 두 줄에서 만족된다.
`submitted_at`·`last_seen`은 0으로 둔다. `DateTime.now()`가 들어가면 화면에 안 나오더라도 골든이 흔들릴 여지가 남는다.

### 2. 퍼즐·결과 장면은 단어를 **골라내고 확인한다**

생성기가 어떤 단어를 어디 놓을지 이 문서가 알 수 없다. 문자열을 하드코딩하지 말고 퍼즐에서 조건에 맞는 단어를 고른 뒤 **고른 결과를 `expect`로 못 박는다.** 생성기가 바뀌면 골든이 조용히 달라지는 대신 테스트가 먼저 깨진다.

```dart
final across = model.puzzle.words.where((w) => w.isAcross).toList()
  ..sort((a, b) => a.number.compareTo(b.number));
expect(across.length, greaterThanOrEqualTo(2),
    reason: '골든 장면은 가로 단어 2개 이상을 전제한다(레벨 1·seed 1000)');
expect(across[0].length, 2, reason: '진행 배지 `1 / N`을 만들려면 첫 단어가 2음절이어야 한다');
```

| 장면 요소 | 만드는 법 |
|---|---|
| 가로 1 선택 | `across[0]` 선택 → 하늘색 `accentSoft` 띠 |
| 커서 = 첫 셀 | 선택 직후 기본 커서 위치. 노랑 `accent` |
| 첫 단어 입력 완료 | `across[0].headword` 2글자 입력 |
| 두 번째 단어 부분 입력 | `across[1]` 선택 후 `headword` 앞 1글자 |
| 진행 배지 `1 / N` | 위 두 입력의 결과 |
| 결과: 정답 / 오답 / 빈칸 | headword 그대로 / 같은 길이의 다른 음절(`expect`로 다름 확인) / 입력 없음 |

전제가 깨지면 seed를 흔들지 말고(나머지 두 장면까지 같이 흔들린다) **조건을 만족하는 단어를 고르도록 선택식을 고친다.**
결과는 빈 DB로 시작하므로 `isFirstSubmit == true`가 자동으로 만족된다 — 그래야 해제 배지가 뜨고 "재제출이라 기록에 반영되지 않았습니다"가 안 나온다.

### 3. 테스트 파일 모양

```dart
@Tags(['golden'])
library;

void main() {
  for (final (name, mode) in [('light', ThemeMode.light), ('dark', ThemeMode.dark)]) {
    testWidgets('홈 골든 — $name', (tester) async {
      final db = openGoldenDb(tmp);
      addTearDown(db.close);
      await seedClearedLevel1(db);                 // 1절
      await pumpGolden(tester, const HomePage(),
          scope: goldenScope(db), themeMode: mode);
      await expectLater(find.byType(MaterialApp),
          matchesGoldenFile('goldens/home_$name.png'));
    });
  }
}
```

- `@Tags(['golden'])`는 파일 **맨 위**, `library;` 앞에 온다. 07-08-01의 `dart_test.yaml`이 이 태그를 선언해 둔다.
- `matchesGoldenFile` 경로는 테스트 파일 기준 상대 경로 → `test/golden/goldens/`에 떨어진다.
- 결과 화면은 E-08(해제 연출) 때문에 `pumpAndSettle()` 뒤에 찍어야 한다. `pumpGolden`이 이미 그걸로 끝나므로 추가 pump를 넣지 않는다.

### 6. CI 결정을 06-06에 반영

`.github/workflows/`는 **현재 저장소에 없다.** 06-06은 "선택"으로 남아 아직 실행되지 않았다. 워크플로 파일을 새로 만들지 않고 06-06 문서의 YAML 스니펫만 고친다.

```diff
-      - run: flutter test
+      # 골든(07-08)은 기록한 OS에서만 비교한다. Linux 러너에서는 제외한다.
+      - run: flutter test --exclude-tags golden
```

같은 절 아래에 한 줄을 덧붙인다: *골든 테스트는 로컬 DoD다 — `flutter test --tags golden`을 릴리스 전에 사람이 돌린다(07-08-02).*

## 막히면

- **골든이 매번 1px 다름** → 텍스트 안티앨리어싱 차이다. 같은 OS·같은 Flutter 버전에서만 비교한다는 결정을 먼저 지킨다(`flutter --version`이 기록 시점과 같은지).
- **그래도 흔들림 (최후 수단)** → `flutter_test_config.dart`에 픽셀 차이 0.1% 이하만 통과시키는 `LocalFileComparator` 파생 클래스를 등록한다. **마지막 카드다** — 먼저 (1) 폰트가 실렸는지, (2) `disableAnimations`가 걸렸는지, (3) `pumpAndSettle()` 뒤인지 셋을 다 확인한다. 도입하면 허용치와 이유를 이 문서에 한 줄 추가한다.
- **E-08 조각이 찍힘** → `pumpAndSettle()`을 안 했거나 `disableAnimations`가 안 걸렸다. `pumpGolden`을 우회해 직접 `pumpWidget`한 곳이 없는지 본다.
- **레벨 1·seed 1000이 2절 전제를 못 맞춤** → `expect`가 먼저 실패한다. seed를 바꾸지 말고 선택식을 고친다. 그래도 안 되면 seed를 2000으로 올리고(`levels_test.dart`가 확인해 둔 값) 6장을 전부 다시 기록한다.
- **390×844에 화면이 안 들어가 오버플로** → 골든 크기를 키우지 않는다. 그 화면 문서(07-04·07-05·07-06)로 돌아가 레이아웃을 고친다. 골든 크기는 실기기 대표값이다.
- **`--update-goldens`가 PNG를 안 만듦** → `--tags golden`이 빠졌거나 `@Tags`가 `library;` 뒤에 있다.
