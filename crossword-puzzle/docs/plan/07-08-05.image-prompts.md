담당: **REFERENCE** (작업 문서가 아니다. 이미지가 필요할 때 여기서 프롬프트를 가져간다)
상위: [07-08.golden-and-device-check.md](07-08.golden-and-device-check.md) · 계약: [../UI-GUIDE.md](../UI-GUIDE.md) 2.2(색 토큰), 5절(이미지 에셋 표)
쓰는 곳: [07-08-04.store-assets-and-icon.md](07-08-04.store-assets-and-icon.md), [06-01.app-identity.md](06-01.app-identity.md), [06-04.store-assets.md](06-04.store-assets.md)

## 이 문서의 규칙

1. **생성형 모델에 넘길 프롬프트는 저장소에서 여기 한 곳에만 있다.** 07-01~07-08 어느 세부 문서에도 프롬프트 원문을 적지 않는다. 필요하면 이 문서를 링크한다.
2. **색은 UI-GUIDE 2.2 라이트 열의 hex 그대로.** 프롬프트에서 색 이름을 쓰지 말고 hex를 박는다. 결과물 색이 어긋나면 이미지를 보정하지 말고 **재생성**한다(UI-GUIDE 5절).
3. **앱 안 UI는 이미지로 만들지 않는다.** 코드로 그린다(UI-GUIDE 4절, 5절). 여기 있는 건 앱 아이콘·스토어 에셋·참고 스케치뿐이다.
4. 프롬프트를 고치면 **이 문서만** 고친다. 값(색·크기)이 바뀌어야 하면 UI-GUIDE 2.2를 먼저 고치고 여기를 따라 고친다.

## 팔레트 (프롬프트에 그대로 붙여넣는 블록)

UI-GUIDE 2.2 라이트 열. 모든 프롬프트가 이 6개 안에서만 쓴다.

```
#FFFFFF  surface     흰 바탕
#F5F5F3  surfaceAlt  아이콘 배경 / 한 톤 낮은 면
#121212  ink         선·글자·검은 칸
#6E6E6E  inkMuted    보조(거의 안 씀)
#FFDA00  accent      커서 셀 노랑
#A7D8FF  accentSoft  선택 단어 하늘색
```

금지어(프롬프트에 부정으로 명시한다): gradient, shadow, glow, bevel, 3D, glass, texture, photo, mockup device, person, drop shadow, rounded grid cells.

## A. 묶음 프롬프트 (한 번에 시안 전부 — 검토용)

컨셉을 한 장으로 보고 고를 때 쓴다. **여기서 나온 이미지를 그대로 납품하지 않는다.** 방향이 정해지면 아래 B의 개별 프롬프트로 실제 에셋을 다시 만든다.

```

Korean crossword puzzle mobile game in New York Times Games editorial style.
Strictly flat: no gradients, no shadows, no glow, no bevel, no 3D, no texture,
no photographs, no device mockups, no people. Geometric sans-serif only.
Palette limited to exactly these colors: #FFFFFF, #F5F5F3, #121212, #FFDA00, #A7D8FF.

Top-left quadrant - APP ICON: a square tile with #F5F5F3 background, a 3x3 crossword
grid drawn in thick #121212 lines, two cells filled solid #121212, one cell filled
#FFDA00, one cell filled #A7D8FF, and a single bold black Korean syllable "자"
centered in the yellow cell. Generous margin, perfectly square, no border.

Top-right quadrant - ICON MARK ONLY: the same crossword grid mark alone on #FFFFFF,
centered, about 60% of the quadrant, no background tile.

stroke on #FFFFFF, no fill: an empty 4x4 crossword grid with one cell marked by a
small circle.

No labels, no captions, no watermarks, no text other than the Korean characters
described above.
```

### IMG-01S · 스플래시 이미지 (1024×1024, 알파 포함) — 선택

**기본은 이 에셋을 만들지 않는다.** 06-01 E절이 `icon_foreground.png`(= IMG-01F)를 스플래시 이미지로 재사용하기로 이미 정했고, 그 결정이 유효하면 아래 프롬프트는 건너뛴다. 여백·크기가 어색할 때만 전용 이미지를 만든다 — 판단은 [07-08-04.store-assets-and-icon.md](07-08-04.store-assets-and-icon.md).

`flutter_native_splash`의 `image`에 쓴다. 배경색은 YAML이 준다(`#FFFFFF` / dark `#121212`) — **이미지에 배경을 그리면 안 된다**(06-01 E절: 아이콘 원본을 그대로 쓰면 모서리가 배경 위에 보인다).

```
Same crossword grid mark, isolated on a fully transparent background, centered,
occupying about 50% of the canvas. Flat #121212 lines, #FFDA00 and #A7D8FF filled
cells, one bold black Korean syllable "자" in the yellow cell. The mark must read
correctly on both a white (#FFFFFF) and a near-black (#121212) backdrop, so keep the
yellow and light-blue cells as the only bright areas and do not rely on white fills.
No background, no shadow, no text. 1024x1024 PNG with alpha.
```

> 다크 스플래시에서 `#121212` 선이 `#121212` 배경에 묻힌다. 채택한다면 다크용으로 선을 `#F2F2F2`로 바꾼 변형을 한 장 더 만들고 `flutter_native_splash`의 `image_dark`에 건다. 판단은 07-08-04.

## D. 생성 후 가공

06-01의 관례를 따른다. 원본은 `crossword-puzzle/asset/icon/`, 가공본은 `crossword-puzzle/app/assets/icon/`.

| 산출 | 파일 | 가공 |
|---|---|---|
| IMG-01 | `app/assets/icon/icon.png` | 1024×1024로 리사이즈, **알파 채널 제거**(Play 조건) |
| IMG-01F | `app/assets/icon/icon_foreground.png` | 투명 1024×1024 캔버스 중앙, 내용이 중앙 66% 안에 |
| IMG-01S | `app/assets/icon/splash.png` | 선택. 기본은 IMG-01F 재사용(06-01 E절) |
| IMG-02 | 스토어 업로드용 (저장소에 커밋하지 않아도 된다) | 1024×500, 1MB 이하 |

```powershell
cd app
dart run flutter_launcher_icons
dart run flutter_native_splash:create
flutter build apk --debug
# aapt dump badging 으로 application-icon 이 mipmap-anydpi-v26/ic_launcher.xml 을 가리키는지 확인
```

`pubspec.yaml`에서 같이 바꾸는 값(07-08-04에서 IMG-01 채택 시):

```yaml
flutter_launcher_icons:
  adaptive_icon_background: "#F5F5F3"   # 기존 "#08A2FB"
```

`assets/icon/`은 `flutter: assets:`에 **넣지 않는다**(06-01 D절 — 생성 시점에만 읽힌다).

## E. 검수 체크리스트 (생성 결과를 받아들이기 전)

- [ ] 쓰인 색이 팔레트 6개뿐이다. 스포이드로 찍어 hex가 정확히 일치한다(근사치면 재생성)
- [ ] 그라데이션·그림자·입체감이 없다
- [ ] 격자 셀 모서리가 **직각**이다(둥근 셀은 UI-GUIDE 1절 위반)
- [ ] 한글 음절이 "자" 하나뿐이고, 획이 뭉개지지 않았다
- [ ] 아이콘: 48dp로 축소해도 격자와 음절이 구분된다
- [ ] 아이콘 foreground: 원형 마스크로 잘라도 내용이 안 잘린다
- [ ] 피처 그래픽: 썸네일 크기(약 250×122)에서 제목이 읽힌다
- [ ] 라이선스·저작권 문제가 없다(생성물 사용 조건 확인)
