# 01-08. 채점 (scorer)

## 목표

유저가 격자에 넣은 음절을 받아 **단어 단위**로 채점한다. 규모는 작지만 규칙이 명확해야 한다.

## 규칙 (DESIGN 5절)

1. **빈칸은 오답.** 한 칸이라도 비면 그 단어는 `blank` → 오답 취급. 부분 정답 없음.
2. **재제출 허용.** 채점 결과는 같지만 통계는 첫 제출만 반영 → `isFirstSubmit` 플래그.
   실제 판단은 3단계 `stat_repository`(03-04)가 하고, 여기는 받아서 담기만 한다.
3. 점수 = 맞은 단어 수 − 틀린 단어 수 (`SubmitResult.score`, 01-01에서 정의됨).
4. **교차 셀은 두 단어 모두에 영향.** 한 칸이 틀리면 그 칸을 지나는 두 단어가 다 틀린다. 의도된 동작이다.

## 산출물

```
app/lib/domain/scoring/
└─ scorer.dart
```

```dart
import '../model/puzzle.dart';
import '../model/submit_result.dart';

/// 유저 입력. 키는 (row, col), 값은 입력된 음절 1글자.
/// 비어 있는 칸은 맵에 없거나 빈 문자열.
typedef Answers = Map<(int, int), String>;

class Scorer {
  /// 규칙: 빈칸 = 오답, 부분 정답 없음.
  static SubmitResult score(
    Puzzle puzzle,
    Answers answers, {
    required bool isFirstSubmit,
  }) {
    final results = <WordResult>[];

    for (final w in puzzle.words) {
      final buf = StringBuffer();
      var hasBlank = false;
      var allMatch = true;
      var i = 0;

      for (final (r, c) in w.cells) {
        final entered = answers[(r, c)];
        final expected = w.syllableAt(i++);

        if (entered == null || entered.isEmpty) {
          hasBlank = true;
          allMatch = false;
          buf.write(' ');
        } else {
          buf.write(entered);
          if (entered != expected) allMatch = false;
        }
      }

      final outcome = hasBlank
          ? WordOutcome.blank
          : (allMatch ? WordOutcome.correct : WordOutcome.wrong);

      results.add(WordResult(w, buf.toString(), outcome));
    }

    return SubmitResult(results, isFirstSubmit: isFirstSubmit);
  }

  /// 제출 확인 다이얼로그용 (04-05). 비어 있는 칸 수.
  static int blankCellCount(Puzzle puzzle, Answers answers) {
    var n = 0;
    for (var r = 0; r < puzzle.height; r++) {
      for (var c = 0; c < puzzle.width; c++) {
        if (puzzle.cellAt(r, c).blocked) continue;
        final v = answers[(r, c)];
        if (v == null || v.isEmpty) n++;
      }
    }
    return n;
  }

  /// 정답으로 채운 Answers. 테스트·디버그용.
  static Answers solutionOf(Puzzle puzzle) {
    final a = <(int, int), String>{};
    for (var r = 0; r < puzzle.height; r++) {
      for (var c = 0; c < puzzle.width; c++) {
        final s = puzzle.cellAt(r, c).solution;
        if (s != null) a[(r, c)] = s;
      }
    }
    return a;
  }
}
```

### `Answers` 를 좌표 맵으로 두는 이유

UI(04-04)는 단어 단위로 입력을 받지만, 교차 셀은 마지막 입력이 이긴다(DESIGN/04-ui 결정).
따라서 **격자 셀이 단일 진실**이고, 단어별 입력 상태를 따로 들고 있으면 교차에서 불일치가 난다.

## 테스트

`app/test/domain/scorer_test.dart`

| 테스트 | 기대 |
|---|---|
| 전부 정답 | 모든 `outcome == correct`, `score == words.length` |
| 전부 빈칸 | 모든 `outcome == blank`, `score == -words.length` |
| 한 칸 틀림 | 그 칸을 지나는 단어만 `wrong`, 나머지 `correct` |
| 교차 셀 틀림 | 그 셀을 지나는 **두 단어 모두** `wrong` |
| 한 칸 비움 | 그 단어 `blank` (`wrong` 아님) |
| 빈 문자열 = 빈칸 | `answers[(r,c)] = ''` → `blank` |
| 재제출 동일 결과 | 같은 answers 두 번 → `results` 동일 |
| `isFirstSubmit` 전달 | 넘긴 값 그대로 |
| `blankCellCount` | 검은 칸 제외, 빈 칸만 셈 |
| `solutionOf` 로 만점 | `score == words.length` |

```dart
test('교차 셀이 틀리면 두 단어 모두 오답', () async {
  final gen = GridGenerator(InMemoryWordRepository(buildDummyDictionary(seed: 1)));
  final p = await gen.generate(levels[0], 3);

  // 교차 셀 찾기
  final cross = [
    for (var r = 0; r < p.height; r++)
      for (var c = 0; c < p.width; c++)
        if (p.wordsAt(r, c).length == 2) (r, c)
  ].first;

  final a = Scorer.solutionOf(p);
  a[cross] = '뷁';   // 사전에 없을 음절로 오염

  final res = Scorer.score(p, a, isFirstSubmit: true);
  final affected = p.wordsAt(cross.$1, cross.$2);
  for (final w in affected) {
    final r = res.results.firstWhere((x) => x.word.headword == w.headword);
    expect(r.outcome, WordOutcome.wrong);
  }
  expect(res.wrongCount, greaterThanOrEqualTo(2));
});
```

### 실제 구현 시 문서와 달라진 점 (공개 시그니처 변경 없음)

- 위 스니펫의 `levels[0]` 은 01-09 산출물이라 아직 없다. 01-04·01-06·01-07 테스트와 같이
  테스트 파일 로컬 `testSpec()` (7×7, 코어 티어3 2개, 채움 `[TierQuota(1,2,4), TierQuota(2,1,3)]`)
  으로 대체하고 `gen.generate(spec, 7)` 로 퍼즐 1개를 만들어 전 테스트가 공유한다.
- 결과를 찾을 때는 "막히면" 절 권고대로 `headword` 대신 `row/col/dir` 로 찾는다
  (테스트 로컬 헬퍼 `resultOf`). `Scorer` 코드는 문서 그대로다.
- 교차 셀/비교차 셀은 단어별 `cells` 를 세어 만든 로컬 `ownerCounts` 로 고른다
  (`p.wordsAt` 는 결과 확인 쪽에서 쓴다).
