## 작업

### 1. `GameColors` — ThemeExtension 15색

필드 순서는 UI-GUIDE 2.2 표 순서 그대로 둔다(표와 코드를 눈으로 대조할 수 있게).

```dart
// lib/ui/theme/tokens.dart
//
// UI-GUIDE.md 2.2·2.4·2.5의 값을 코드로 옮긴 유일한 자리.
// `Color(0x…)` 리터럴은 이 디렉터리 밖에 있으면 INV-05 위반이다.
import 'package:flutter/material.dart';

@immutable
class GameColors extends ThemeExtension<GameColors> {
  final Color surface, surfaceAlt, ink, inkMuted, line, accent, accentSoft,
      success, danger, gridLine, cellFill, cellBlocked, cellCoreMark,
      cellInk, cellInkOnAccent;

  const GameColors({
    required this.surface, required this.surfaceAlt, required this.ink,
    /* … 15개 전부 required */
  });

  static GameColors of(BuildContext context) =>
      Theme.of(context).extension<GameColors>()!;

  @override
  GameColors copyWith({Color? surface, /* … 15개 전부 nullable */}) =>
      GameColors(surface: surface ?? this.surface, /* … */);

  @override
  GameColors lerp(GameColors? other, double t) => other == null
      ? this
      : GameColors(surface: Color.lerp(surface, other.surface, t)!, /* … 15개 전부 */);
}
```

`lerp`는 테마 모드가 바뀔 때 Material이 확장을 보간하는 데 쓴다. 15개 필드를 빠짐없이 넣는다 — 하나라도 `this.x`로 두면 그 색만 튄다.

### 3. `GameSpace` · `GameRadius` — UI-GUIDE 2.5

```dart
/// 화면 좌우 여백은 `GameSpace.l`(16). UI-GUIDE 2.5.
abstract final class GameSpace {
  static const xs = 4.0, s = 8.0, m = 12.0, l = 16.0, xl = 24.0, xxl = 32.0;
}

abstract final class GameRadius {
  static const cell = 0.0, panel = 12.0, pill = 999.0;
  static const hairline = 1.0;        // 구분선·셀 테두리 두께
  static const gridOuter = 2.0;       // 격자 외곽 두께
  static const outlineButton = 1.5;   // 보조 버튼 테두리
  static const buttonHeight = 52.0;   // UI-GUIDE 2.5 버튼 규격

```

두께·높이는 반지름이 아니지만 UI-GUIDE 2.5 한 표에서 온 값이라 같은 클래스에 둔다. 표의 "구분선 두께 1 / 격자 테두리 1·외곽 2 / 보조 버튼 테두리 1.5 / 버튼 높이 52"에 이름을 붙인 것뿐이고 새 값은 없다.

## 막히면

- **INV-05가 `tokens.dart`를 잡는다** → 07-01의 `Rule('INV-05', …)`에 `exclude: ['lib/ui/theme/']`가 빠진 것이다. `tool/invariants/rules.dart`에서 그 한 줄을 확인·추가한다(UI-GUIDE 7절 INV-05 설명과 일치).
- **`lerp` 시그니처 오류(`covariant`)** → `ThemeExtension<T>.lerp`는 `covariant ThemeExtension<T>?`를 받는다. `GameColors lerp(GameColors? other, double t)`로 좁혀 쓰는 것이 정상이고 `@override`가 붙어야 한다.
- **'Pretendard' 폰트가 아직 없다** → 정상. 이 커밋에서는 아무도 `GameType`을 쓰지 않는다. 07-02-03이 테마에 연결한 뒤 07-02-04가 파일을 넣기 전까지는 시스템 폰트로 조용히 폴백한다(오류 아님).
