# 00-03. Flutter SDK

담당: **HUMAN** (설치·PATH·라이선스 동의)
선행: 00-02 · 다음: 00-04
상위: [00-env-setup.md](00-env-setup.md) C절

## 작업

### 1. Windows 개발자 모드 켜기

설정 → 시스템 → 개발자용 → **개발자 모드 켜기**.
플러그인 빌드가 심볼릭 링크를 쓰므로 꺼져 있으면 `flutter doctor` 가 경고를 낸다.

### 2. Flutter SDK 설치

권장: zip 직접 설치 (winget 설치는 PATH·업데이트가 꼬이기 쉽다)

1. https://docs.flutter.dev/get-started/install/windows 에서 **stable** zip 다운로드
2. `C:\src\flutter` 에 압축 해제 (**공백·한글 없는 경로**. `C:\Program Files` 금지 — 권한 문제)
3. 사용자 환경변수 `PATH` 에 `C:\src\flutter\bin` 추가
4. 새 터미널 열기

### 3. JDK 지정

JRE 21은 쓸 수 없다. Android Studio 동봉 JDK를 지정한다.

```powershell
flutter config --jdk-dir="C:\Program Files\Android\Android Studio\jbr"
```

경로는 00-02에서 기록한 실제 Android Studio 경로로 바꾼다.

### 4. 라이선스 동의

```powershell
flutter doctor --android-licenses
```
전부 `y`.

### 5. VS Code 확장

VS Code → 확장 → `Flutter` 설치 (Dart 확장이 함께 설치됨).

## 검증

```powershell
flutter --version
flutter doctor -v
```

기대: `flutter doctor` 에서 아래 항목이 **모두 초록 체크**

- `[√] Flutter`
- `[√] Windows Version`
- `[√] Android toolchain - develop for Android devices`
- `[√] Chrome - develop for the web`
- `[√] Visual Studio Code`
- `[√] Connected device` (00-02의 기기 + Chrome)

`[!]` 가 하나라도 있으면 해당 줄의 안내대로 처리한 뒤 다시 실행한다.

## 산출물

- `flutter`, `dart` 명령이 PATH에서 동작
- `flutter doctor` 경고 0

## DoD

- [ ] `flutter doctor` 출력에 `[!]`, `[X]` 없음 — 잔존 2건은 무해함(아래 비고)
- [x] `flutter --version` 이 stable 채널 표시 (3.47.4)
- [x] `dart --version` 동작 (3.13.3)
- [x] VS Code에 Flutter/Dart 확장 설치됨

비고: 남은 `[!] Flutter` PATH 경고는 이번 설치 세션(에이전트가 연 셸)이 레지스트리 PATH 갱신 전에 시작돼서 나는 잔상이며, 새 터미널에서는 안 뜬다. `[✗] Visual Studio`는 Windows 데스크톱 빌드용 경고인데 00-05 계획상 타깃이 `android,web`뿐이라 무관.

## 막히면

- **`Android toolchain` 에 `cmdline-tools component is missing`** → 00-02의 SDK Manager에서 `Android SDK Command-line Tools (latest)` 체크 누락. 설치 후 재실행.
- **`Unable to find bundled Java version`** → 3번의 `--jdk-dir` 경로 오타. `<경로>\jbr\bin\java.exe` 가 실제로 있는지 확인.
- **`flutter` 명령 없음** → PATH 반영 안 됨. 터미널 재시작. 사용자 PATH vs 시스템 PATH 확인.
- **다운로드가 매우 느림/실패** → 회사망 프록시. `HTTP_PROXY`/`HTTPS_PROXY` 환경변수 설정 후 재시도.
