## 목표

`GridPainter`의 색 출처를 `ColorScheme` → `GameColors`로 바꾸고, 층 구조를 상위 문서 8층으로 재정의한다.
커서 셀(`focusedCell`)과 코어 원 마크가 이 커밋에서 처음 그려진다.
모션 인자 3개(`selectionRect`·`cursorOpacity`·`pop`)는 **받기만 하고 정지 기본값**으로 둔다 — 애니메이션은 07-03-02다.
이 문서가 끝났을 때 `flutter analyze` 0, `flutter test` 전체 초록이어야 한다.

## 작업

### 1. 시그니처

```dart
class GridPainter extends CustomPainter {
  final Puzzle puzzle;
  final Map<(int, int), String> answers;
  final PlacedWord? selected;
  final (int, int)? focusedCell;   // 신규
  final SubmitResult? result;
  final GameColors colors;         // ColorScheme → GameColors
  final double cell;
  final Rect? selectionRect;       // E-02, 이 커밋에선 항상 null
  final double cursorOpacity;      // E-03, 기본 1.0
  final Map<(int, int), double> pop; // E-01, 기본 const {}
}
```

생성자는 `selectionRect`·`cursorOpacity = 1.0`·`pop = const {}`만 선택 인자이고 나머지는 전부 `required`다.
`focusedCell`을 `required`(nullable)로 둔다 — `selected`·`result`와 같은 결. 호출부에서 빠뜨리면 커서가 조용히 사라진다.

### 2. 층 (아래→위)

| 층 | 그리기 | Paint |
|---|---|---|
| 1 | 모든 셀 배경 | `blocked ? colors.cellBlocked : colors.cellFill`, fill |
| 2 | 선택 단어 배경 | `colors.accentSoft`, fill. `selectionRect == null`이면 `selected!.cells`만, non-null이면 **`rect.overlaps(cellRect) && !blocked`인 셀** |
| 3 | 커서 셀 | `colors.accent.withValues(alpha: cursorOpacity.clamp(0, 1))`, fill. `focusedCell == null`이거나 그 칸이 blocked면 건너뛴다 |
| 4 | 격자선 | `colors.gridLine`, stroke 1 — 비검은 셀 테두리. 이어서 외곽 `gridRect.deflate(1)`에 stroke 2 |
| 5 | 코어 원 | `colors.cellCoreMark`, stroke 1, `drawCircle(cellRect.center, cell * 0.82 / 2)` — `puzzle.cores`의 모든 셀 |
| 6 | 번호 | `GameType.cellNumber(cell).copyWith(color: colors.inkMuted)`, 좌상단 여백 `cell * 0.05` |
| 7 | 음절 | `GameType.cellSyllable(cell).copyWith(color: ...)`, 중앙. `focusedCell == (r, c)`면 `cellInkOnAccent`, 아니면 `cellInk`. 스케일 `0.7 + 0.3 * (pop[(r, c)] ?? 1.0)` |
| 8 | 결과 마크 | `correct` → `drawCircle`·`colors.success`, `wrong`/`blank` → `drawLine`·`colors.danger`. 기존 `_drawOutcomeMark` 비율(`0.18`/`0.12`/`0.05`) 유지 |

`_outcomeByCell()`, `_cellRect()`, `_drawNumber()`, `_drawOutcomeMark()`의 구조와 주석은 그대로 두고 **색 출처만** 바꾼다.

### 3. 격자 외곽 2px가 잘리지 않게

`Padding(1)`을 **두지 않는다.** `PuzzleGridView`의 렌더 크기가 2px 커지면
`play_loop_test.dart`의 `cellCenter`(`size.width / puzzle.width`)와 `cellForOffset`의 좌표계가 어긋난다.
대신 페인터가 안쪽으로 들여 그린다:

```dart
final gridRect = Rect.fromLTWH(0, 0, cell * puzzle.width, cell * puzzle.height);
canvas.drawRect(gridRect.deflate(1),
    Paint()..color = colors.gridLine..style = PaintingStyle.stroke..strokeWidth = 2);
```

stroke는 경로 중심 기준 양쪽 1px이므로 정확히 `[0, 2]` 구간을 채운다. 위젯 크기는 `cell * width`로 유지된다.

### 4. E-01 스케일 적용

`_drawSyllable`에 `double p`를 더한다. `p >= 1.0`이면 지금처럼 `tp.paint(canvas, at)` 한 줄로 끝내고,
아니면 중심 기준으로 감싼다.

```dart
canvas.save();
canvas.translate(rect.center.dx, rect.center.dy);
canvas.scale(0.7 + 0.3 * p);
canvas.translate(-rect.center.dx, -rect.center.dy);
tp.paint(canvas, at);   // at = rect.center - Offset(tp.width / 2, tp.height / 2)
canvas.restore();
```

곡선은 위젯이 이미 적용해 넣는다(상위 문서). 페인터는 시간도 곡선도 모른다.

### 5. `shouldRepaint`

```dart
@override
bool shouldRepaint(GridPainter old) =>
    old.puzzle != puzzle || old.selected != selected ||
    old.focusedCell != focusedCell || old.result != result ||
    old.selectionRect != selectionRect || old.cursorOpacity != cursorOpacity ||
    old.cell != cell || old.colors != colors ||
    !mapEquals(old.answers, answers) || !mapEquals(old.pop, pop);
```

`old.cell`과 `old.colors`는 상위 문서 시그니처 목록에 없지만 넣는다 — 근거는 "막히면" 마지막 항목.
`(int, int)`와 `Rect`는 구조적 `==`를 가지므로 그대로 비교된다.

### 6. 호출부·기존 테스트 셀렉터

| 파일 | 고치는 것 |
|---|---|
| `grid_view.dart` | `PuzzleGridView`에 `final (int, int)? focusedCell;`(required) 추가, `Theme.of(context).colorScheme` → `GameColors.of(context)`, `GridPainter(... focusedCell: focusedCell ...)` |
| `puzzle_page.dart` | `PuzzleGridView(..., focusedCell: model.focusedCell, ...)` |
| `grid_view_test.dart` | `_painter` 헬퍼에 `focusedCell` 인자 추가 + `colors: const ColorScheme.light()` → `colors: GameColors.light`, `PuzzleGridView(...)` 2곳에 `focusedCell: null` 추가 |

**테스트 이름은 한 글자도 바꾸지 않는다**(INV-08). 위 3줄은 전부 생성자 인자 = 셀렉터 수정이다.
`play_loop_test.dart:253`의 `expect(gridView.answers, same(model.answers))`는 `widget.answers`를 읽으므로 그대로 통과한다.

## 막히면

- **`focusedCell`을 required로 만들었더니 호출부가 컴파일 실패** → 정상. `puzzle_page.dart` 1곳, `grid_view_test.dart` 2곳이 전부다. `grep -rn "PuzzleGridView(" lib test`로 확인한다.
- **커서 칸이 선택 단어 배경을 덮어 하늘색이 안 보임** → 의도다(층 3 > 층 2). 커서는 항상 선택 단어 안에 있으므로 "하늘색 줄 안의 노랑 한 칸"이 정상 모습이다.
- **코어 원이 번호·음절을 가림** → 층 순서를 확인한다. 원은 5층, 번호 6층, 음절 7층이다. 상위 문서 "코어 원은 번호·음절 뒤에 있으므로 겹쳐도 읽힌다".
- **다크에서 코어 원이 안 보임** → 상위 문서대로 stroke만 1.5로 올린다. `cellCoreMark` 값은 바꾸지 않는다(UI-GUIDE 2.2).
- **`withValues(alpha:)`가 없다고 나옴** → 이 저장소는 Flutter 3.47이다. `withOpacity`는 쓰지 않는다.
- **상위 문서의 `shouldRepaint`에 `colors`·`cell`이 없는데 왜 넣나** → 테마 모드를 바꾸면 `GameColors` 인스턴스만 바뀌고 나머지 인자는 그대로다. `colors`를 비교하지 않으면 `CustomPaint`가 재그리기를 건너뛰어 **격자만 이전 테마 색으로 남는다.** `cell`도 같은 이유(창 크기 변경)로 상위 문서 시그니처에 이미 들어 있다. 이 추가는 상위 문서의 목록을 넓히는 것이지 뒤집는 것이 아니다.
