## 작업

### 1. 하드코딩 색 3곳 정리

INV-05의 `paths`는 `['lib/ui', 'lib/main.dart']`다. 이 둘 아래 `Colors.`·`Color(0x`는 **정확히 3건**이다(`grep -rn "Colors\." lib/main.dart lib/ui | grep -v Colors.transparent`).

| 파일:줄 | 지금 | 바꿀 값 |
|---|---|---|
| `lib/main.dart:132` | `colorSchemeSeed: Colors.indigo,` | **줄 삭제** — `ThemeData(useMaterial3: true)`만 남긴다 |
| `lib/ui/home/home_page.dart:200` | `const Icon(Icons.star, color: Colors.amber)` | `Icon(Icons.star, color: Theme.of(context).colorScheme.tertiary)` |
| `lib/ui/debug/benchmark_page.dart:177` | `style: const TextStyle(color: Colors.red)` | `style: TextStyle(color: Theme.of(context).colorScheme.error)` |

아래 두 줄은 **`const`를 뗀다.** `Theme.of(context)`는 컴파일 타임 상수가 아니다. 둘 다 `build(BuildContext context)` 안이라 `context`는 이미 있고, 바깥 `Row`/`Text`가 `const`가 아니라 파장은 그 줄에서 끝난다. 07-02가 토큰을 도입하면 `GameColors.accent`·`GameColors.danger`로 다시 바뀐다.

### 2. `main.dart`는 왜 시드를 "지우는가"

`colorSchemeSeed`는 **테마를 만드는 지점 자체**라 다른 두 곳처럼 `Theme.of(context).colorScheme.*`로 바꿀 수 없고(자기 자신을 참조하게 된다), `Color(0xFF3F51B5)`로 풀어 써도 INV-05에 다시 걸린다. 남는 선택지는 줄을 지워 **Material 3 기본 시드 테마로 잠깐 떨어지는 것**뿐이다. 색을 단정하는 테스트가 없어 `flutter test`는 초록이고, 07-02-03이 `buildLightTheme()`/`buildDarkTheme()`로 이 자리를 채우면서 사라진다. **되돌리지 말 것** — 시드를 되살리면 INV-05가 즉시 FAIL한다.

## 검증

`tool/check_invariants.dart`는 **아직 없다.** 다음 문서(07-01-02)가 만든다. 지금은 선언 파일이 컴파일되고 기존 테스트가 그대로 도는지만 본다.

```powershell
cd app
flutter analyze
flutter test
$hard = 'Colors\.|Color\(0x'
Get-ChildItem -Recurse lib/ui -Filter *.dart | Select-String -Pattern $hard   # 출력 없음
Select-String -Path lib/main.dart -Pattern $hard                             # 출력 없음
```

`analysis_options.yaml`이 `build/`·`android/`·`web/`만 제외하므로 `flutter analyze`는 `tool/`도 본다. `rules.dart`는 아직 어디서도 import되지 않지만 최상위 선언은 미사용 경고 대상이 아니다.

## 막히면

- **시드를 지우니 앱 색이 달라짐** → 의도된 것이다. 작업 2의 근거대로 07-02-03까지의 임시 상태다. 되돌리면 INV-05가 FAIL한다.
- **`pubspec.yaml` 151~152줄 주석이 `colorSchemeSeed: Colors.indigo`를 가리킴** → `flutter_native_splash` 설명 주석이다. 동작에 영향 없으니 이 커밋에서는 두고, 07-02-03이 테마를 확정할 때 함께 고친다.
- **INV-08 목록이 실제 테스트 이름과 안 맞음** → 2026-09-18 기준 24개 전부 `test/ui/*.dart`에 실재함을 확인했다. 그래도 어긋나면 **UI-GUIDE를 고치지 말고 테스트 이름을 원래대로 되돌린다**(07-ui-v2 단계 공통 규칙 3).
