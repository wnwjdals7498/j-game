## A. 골든 테스트 (AGENT)

### 결정

- **크기 고정** `Size(390, 844)`, `devicePixelRatio 1.0`. 폰 세로 기준 한 종만.
- **폰트**: 골든에 실제 Pretendard를 쓴다. `flutter_test_config.dart`에서 `FontLoader('Pretendard')`로 `assets/fonts/*.otf` 3종을 `rootBundle` 대신 `File`로 읽어 로드한다(테스트는 에셋 번들이 없다). 이렇게 하면 다른 테스트에도 폰트가 실리지만 무해하다.
- **플랫폼 편차**: 골든은 기록한 OS에서만 비교한다. `dart_test.yaml`에 `golden` 태그를 선언하고, CI(있다면)는 `flutter test --exclude-tags golden`. 로컬 DoD는 `flutter test --tags golden`. 이 결정을 06-06 문서에 한 줄로 남긴다.
- **데이터 고정**: 가짜 `AppScope` + 더미 사전 `seed: 1`로 5×5 퍼즐. 홈은 레벨 1 클리어(+12)·2 해제·나머지 잠금. 결과는 5/7 정답·+12·첫 제출·해제됨(E-08 조각이 보이지 않게 **`pumpAndSettle()` 후** 캡처 — 조각은 종료 후 shrink).
- **모션**: 골든은 항상 `MediaQueryData(disableAnimations: true)`로 pump한다. 애니메이션 중간 프레임을 찍지 않는다.

### 장면

| 파일 | 장면 | 상태 |
|---|---|---|
| `home_light.png` / `home_dark.png` | 홈 | 히어로 = 레벨 2, 카드 3상태 모두 보임 |
| `puzzle_light.png` / `puzzle_dark.png` | 퍼즐 | 가로 1 선택, 커서 = 첫 셀, 첫 단어 2음절 입력 완료, 두 번째 단어 부분 입력, 진행 배지 `1 / N` |
| `result_light.png` / `result_dark.png` | 결과 | 정답·오답·빈칸 각 1개 이상, 해제 배지 표시, 재제출 안내 없음 |

### 명령

```powershell
cd app
flutter test --tags golden --update-goldens   # 최초 기록·의도한 변경 후
flutter test --tags golden                    # 비교
```

`--update-goldens`는 **눈으로 PNG를 확인한 뒤** 커밋한다. 기록 전 확인 항목: 폰트가 Pretendard인가(사각형 글리프 없음), 다크에서 격자선·코어 원이 보이는가, 텍스트 잘림 없음.

## B. 실기기 검증 (HUMAN) — `docs/reports/07-device-check.md`

기기 2대: 6인치대 주력 1대 + 저가형(RAM 3~4GB, 2020년 이전 SoC) 1대. `flutter run --profile`.

### B-1. 가독성·레이아웃

| # | 확인 | 기대 |
|---|---|---|
| 1 | 레벨 10(8×8) 격자 음절 | 두 기기 모두 읽힘, 셀 ≥ 36dp(디바이스 인스펙터 또는 `debugPrint(cell)`) |
| 2 | 키보드 올라온 상태의 8×8 | 격자가 잘리지 않음, ClueBar와 겹치지 않음 |

## 막히면

- **골든이 매번 1px 다름** → 텍스트 안티앨리어싱 차이. 같은 OS·같은 Flutter 버전에서만 비교한다는 결정을 지킨다. 그래도 흔들리면 `matchesGoldenFile` 대신 허용 오차를 주는 커스텀 `GoldenFileComparator`(픽셀 0.1% 이하 차이 허용)를 `flutter_test_config.dart`에 등록한다.
- **`FontLoader`에 파일 경로 로드가 안 됨** → `FontLoader.addFont(Future<ByteData>)`에 `File('assets/fonts/…').readAsBytes().then((b) => ByteData.view(b.buffer))`. 테스트 실행 cwd가 `app/`인지 확인.
- **골든에서 E-08 조각이 찍힘** → `pumpAndSettle()`을 안 했거나 `disableAnimations`가 안 걸렸다. 둘 다 확인.
- **저가형에서 E-01 드랍** → 07-03 "막히면": 애니메이션 프레임마다 전체 격자 재그리기가 원인. 팝 중인 셀만 다시 그리도록 `RepaintBoundary`로 격자를 감싸고, 페인터가 `pop` 셀 외 층을 `Picture`로 캐시한다(정지 상태 그림을 `PictureRecorder`로 한 번 녹화, 팝 층만 덧그림). 그래도 안 되면 저가형에서만 E-01을 끄는 대신 UI-GUIDE E-01 지속을 `instant`로 낮추고 표를 고친다.
- **시스템 글꼴 최대에서 히어로 `display`가 넘침** → 07-05 "막히면" `FittedBox`. 그 외 화면은 `MediaQuery.textScaler` 1.3 상한을 `MaterialApp.builder`에서 두는 것을 **8단계 후보**로 기록만 한다(N-04 범위 밖 판단은 사람이).
