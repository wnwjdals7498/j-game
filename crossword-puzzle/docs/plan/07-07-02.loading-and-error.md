## 작업

### 1. 공용 위젯 두 개 — `ColorScheme`·`TextTheme`만 읽는다

`GameColors.of(context)!`를 쓰면 안 된다. 위 컨텍스트의 두 테스트가 **테마 없는 `MaterialApp`**으로 이 화면들을 띄우므로 확장이 없어 null 역참조로 죽는다. UI-GUIDE 2.2 매핑(`onSurface = ink`, `onSurfaceVariant = inkMuted`)과 2.4 매핑(`titleMedium = heading`, `bodyLarge = body`, `bodySmall = caption`)이 같은 값을 주므로 손해가 없다.

```dart
// lib/ui/common/loading_view.dart — E-11
class GameLoadingView extends StatelessWidget {
  final String? message;
  const GameLoadingView({super.key, this.message});

  @override
  Widget build(BuildContext context) {
    final t = Theme.of(context);
    return Column(children: [
      const LinearProgressIndicator(minHeight: 2),   // UI-GUIDE 3.3 E-11
      Expanded(child: Center(
        child: message == null ? const SizedBox.shrink() : Padding(
          padding: const EdgeInsets.all(GameSpace.l),
          child: Text(message!, textAlign: TextAlign.center,
              style: t.textTheme.bodyLarge?.copyWith(color: t.colorScheme.onSurfaceVariant)),
        ),
      )),
    ]);
  }
}
```

```dart
// lib/ui/common/empty_state.dart — UI-GUIDE 4절. 아이콘 없음.
class GameEmptyState extends StatelessWidget {
  final String title;        // heading 1줄
  final String? message;     // body 1줄
  final String? hint;        // caption 1줄
  const GameEmptyState({super.key, required this.title, this.message, this.hint});
  // Center > Padding(GameSpace.xl) > Column(mainAxisSize.min, 간격 GameSpace.s)
  // title  → textTheme.titleMedium,  color onSurface
  // message→ textTheme.bodyLarge,    color onSurfaceVariant
  // hint   → textTheme.bodySmall,    color onSurfaceVariant
  // 전부 textAlign: TextAlign.center, 본문 최대 폭 560 (UI-GUIDE 4절)
}
```

### 2. `bootstrap_pages.dart`

| 화면 | 구성 | 문구 |
|---|---|---|
| `BootstrapLoadingPage` | `Scaffold(body: SafeArea(child: GameLoadingView(...)))`. 중앙에 앱 이름(`titleLarge`) + 안내(`bodyLarge`, `onSurfaceVariant`) | `'J Crossword Puzzle'` / `'사전 데이터를 준비하는 중입니다…'` — 기존 문구 그대로 |
| `BootstrapErrorPage` | `Scaffold(body: SafeArea(child: GameEmptyState(...)))`, `Icons.error_outline` 삭제 | title `'앱을 시작할 수 없습니다.'`, message `'$error'`, hint `'앱을 삭제 후 재설치해 주세요.'` — 셋 다 기존 문구 |

앱 이름 + 두 줄이 필요하므로 `GameLoadingView`에 `message`만 넘기지 말고 로딩 화면 안에서 `Column`을 직접 구성해도 된다. 상단 선형 표시는 `GameLoadingView`를 통해서만 만든다(E-11 정의가 한 곳에 있어야 한다).

배경은 `scaffoldBackgroundColor = surface`(07-02-03)라 스플래시(`#FFFFFF`/`#121212`)와 그대로 이어진다.

### 3. `main.dart` — 로딩·오류 분기에도 테마

지금 두 분기는 `MaterialApp(title: _title, home: …)`뿐이라 Material 기본 보라 테마가 뜬다. 부트스트랩 중에는 `SettingsModel`이 아직 없으므로 `themeMode`는 기본(`system`)이다.

```dart
MaterialApp(
  title: _title,
  theme: buildLightTheme(), darkTheme: buildDarkTheme(),
  home: BootstrapErrorPage(error: snapshot.error!),   // 로딩 분기도 같은 두 줄 추가
)
```

문구를 **나누기만** 한다. `'퍼즐을 만들지 못했습니다'`를 `textContaining`으로 찾는 기존 테스트는 여전히 정확히 1개를 찾는다(제목 `Text` 하나). 마침표·줄바꿈을 지우거나 합치지 않는다.

`license_page.dart`·`settings_page.dart`는 이 커밋에서 **표시 위젯만** 바꾼다. 타이포·색 토큰 적용은 07-07-04다.

## 막히면

- **테마 없는 `MaterialApp`에서 null 역참조** → 공용 위젯이 `GameColors.of(context)!`를 쓴 것이다. `Theme.of(context).colorScheme`로 되돌린다. 테스트 쪽 `MaterialApp`에 `theme:`를 넣어 덮는 방법도 있지만, 부트스트랩 화면은 테마가 아직 없는 상황에서도 떠야 하는 화면이라 위젯 쪽을 안전하게 만드는 편이 맞다.
- **`play_loop_test` 생성 실패 테스트가 `findsNWidgets(2)`로 실패** → 제목과 메시지 양쪽에 `'퍼즐을 만들지 못했습니다'`가 들어갔다. 제목에만 둔다.
- **선형 표시가 안 보임** → `progressIndicatorTheme.color`가 `ink`인데 배경도 `ink`인 자리에 뒀을 수 있다. 트랙 색은 `ColorScheme.surfaceContainerHighest`(= `surfaceAlt`)로 보이므로 `surface` 위에 둔다.
- **`'지금 갱신'` 버튼 폭이 흔들림** → 선형 표시에 고정 `width`를 준다. 버튼 라벨과 폭이 달라 레이아웃이 튀면 `SizedBox(width: 64)`를 유지한다.
