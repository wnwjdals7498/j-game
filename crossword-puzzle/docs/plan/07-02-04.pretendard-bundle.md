## 목표

07-02-03이 이미 `fontFamily: 'Pretendard'`를 쓰고 있지만 파일이 없어 시스템 폰트로 폴백 중이다.
폰트 파일 3종을 번들하고 `pubspec.yaml`에 등록해 실제로 Pretendard가 렌더되게 한다.
같은 커밋에서 OFL 표기 의무를 이행한다(`docs/LICENSES.md` + `app/assets/LICENSES.md` 동시 수정).

## 컨텍스트 (시작 전 읽기)

- `docs/UI-GUIDE.md` 2.4 첫 문단 — 굵기 3종(400/600/700)과 대안(Noto Sans KR)
- `app/pubspec.yaml` `flutter:` 절 — `assets:`는 파일을 **개별 나열**한다(`assets/LICENSES.md`, `assets/words.sqlite`). 폰트는 `assets:`가 아니라 `fonts:`로 등록한다
- `docs/LICENSES.md` — `## N. 제목` + `- 제공:` / `- 라이선스:` 형식. 현재 4개 자료 + `## 파생물 라이선스`
- `tools/build_sqlite.py` `_sync_licenses()`(138행) — `docs/LICENSES.md` → `app/assets/LICENSES.md` `shutil.copy`. `build_sqlite.run()`(35행) 첫 줄에서 불린다
- `tools/build_sqlite.py` `_license_notice()`(154행) — `## ` 제목과 `- 라이선스:` 줄만 모아 DB meta `license_notice`를 만든다
- `app/test/ui/home_settings_test.dart:394` 테스트 `'4개 자료명이 전부 보임 + assets/LICENSES.md와 동일한 문구'` — **디스크의 `assets/LICENSES.md`와 화면이 로드한 같은 에셋을 비교한다**(`docs/`와 비교하지 않는다)

## 작업

### 1. 폰트 파일 확보·배치

1. Pretendard 공식 릴리스(https://github.com/orioncactus/pretendard)의 static 배포본에서 `Pretendard-Regular.otf`, `Pretendard-SemiBold.otf`, `Pretendard-Bold.otf` 3개와 `OFL.txt`를 받는다.
2. 3개를 `app/assets/fonts/`에 둔다. `OFL.txt`는 번들하지 않는다(표기는 `LICENSES.md`가 한다).
3. 합계 용량을 잰다.

```powershell
Get-ChildItem app\assets\fonts | Select-Object Name, @{n='MB';e={[math]::Round($_.Length/1MB,2)}}
```

합계가 **5MB를 넘으면 작업 5의 대체 절차**로 간다(07-ui-v2 "리스크: 폰트 용량").

### 2. `pubspec.yaml` 등록

`flutter:` 절의 `assets:` 목록 바로 아래(주석 예시 `# fonts:` 자리)에 넣는다.

```yaml
  assets:
    - assets/LICENSES.md
    - assets/words.sqlite

  # 7단계(07-02): UI-GUIDE 2.4 타이포. SIL Open Font License 1.1 —
  # 표기는 docs/LICENSES.md "글꼴" 절. 패키지가 아니라 에셋이므로 INV-11과 무관하다.
  fonts:
    - family: Pretendard
      fonts:
        - asset: assets/fonts/Pretendard-Regular.otf
          weight: 400
        - asset: assets/fonts/Pretendard-SemiBold.otf
          weight: 600
        - asset: assets/fonts/Pretendard-Bold.otf
          weight: 700
```

`family` 문자열은 `GameType.family`와 글자 하나까지 같아야 한다.

### 3. `docs/LICENSES.md`에 글꼴 절 추가

기존 4개 자료 절 뒤, `## 파생물 라이선스` 앞에 넣는다. 형식은 기존 절과 같게 맞춘다(`_license_notice()`가 `## ` 제목과 `- 라이선스:` 줄을 파싱한다).

```markdown
## 5. 글꼴 — Pretendard
- 제공: Kil Hyung-jin (https://github.com/orioncactus/pretendard)
- 라이선스: SIL Open Font License 1.1 (https://scripts.sil.org/OFL)
- 표기: <받은 배포본 OFL.txt의 저작권 고지 줄을 그대로 옮긴다>
- 변형 여부: 없음 (static OTF 3종을 그대로 번들)
```

`- 표기:` 값은 **추측하지 말고** 1단계에서 받은 `OFL.txt` 첫 줄을 복사한다.

### 4. `app/assets/LICENSES.md` 동기화

두 파일이 갈라지면 표기 의무 위반이다(04-06). 정식 경로는 `_sync_licenses()`지만, 그 함수는 `python -m tools build`의 `build_sqlite` 단계 안에서만 불리고 **그 단계는 git이 추적하는 9.8MB `app/assets/words.sqlite`를 함께 다시 만든다.** 폰트 커밋에 DB 바이너리 diff를 끌고 들어오지 않도록 이 문서에서는 복사만 한다(`_sync_licenses()`가 하는 일과 동일).

```powershell
Copy-Item docs\LICENSES.md app\assets\LICENSES.md -Force
Compare-Object (Get-Content docs\LICENSES.md) (Get-Content app\assets\LICENSES.md)   # 출력 없음 = 동일
git diff --stat -- docs/LICENSES.md app/assets/LICENSES.md                            # 두 파일 다 변경
```

DB meta의 `license_notice`(`_license_notice()` 결과)는 다음 정식 DB 빌드·릴리스(06-05) 때 새 글꼴 절을 포함해 갱신된다. 이 커밋에서는 갱신하지 않는다.

> 부모 문서의 `python -m tools build --licenses-only`는 **존재하지 않는 플래그**다(`tools/__main__.py`의 `build`는 `--only`와 `--fixtures`만 받는다). 위 복사가 그 자리를 대신한다.

### 5. 용량 초과 시 대체 (Noto Sans KR)

| 단계 | 할 일 |
|---|---|
| 1 | `NotoSansKR-Regular.otf`(400), `NotoSansKR-Bold.otf`(700) 2종만 받는다. 둘 다 OFL |
| 2 | `pubspec.yaml` `family: Noto Sans KR`, asset 2줄 |
| 3 | `tokens.dart`의 `GameType.family`만 `'Noto Sans KR'`로 바꾼다(스케일 표는 UI-GUIDE 2.4대로 유지) |
| 4 | 600 굵기가 없으므로 Flutter가 700로 합성 폴백한다. `heading`·`label`·셀 음절이 더 굵어 보이는 것은 허용 범위 |
| 5 | `docs/LICENSES.md` 글꼴 절의 제공자·표기를 Noto 배포본 `OFL.txt` 기준으로 쓰고 4단계 복사를 다시 한다 |
| 6 | UI-GUIDE 2.4는 이미 이 대안을 허용하므로 계약 문서는 고치지 않는다 |

## 막히면

- **위젯 테스트에서 글자가 사각형으로 보인다** → 정상. 테스트 환경은 Ahem 폰트를 쓴다. 골든이 필요한 07-08에서 `FontLoader`로 해결한다.
- **`Unable to load asset: assets/fonts/...`** → 파일명 대소문자 불일치이거나 `flutter clean` 후 재빌드가 필요한 경우다. `pubspec.yaml`의 경로는 `app/`을 기준으로 한 상대 경로임을 확인한다.
- **`4개 자료명…` 테스트 실패** → `app/assets/LICENSES.md` 복사를 빠뜨렸다. 작업 4의 `Compare-Object`가 아무것도 출력하지 않아야 한다.
- **AAB 용량이 걱정된다** → 06-03의 크기 점검 항목에 폰트 증가분을 기록만 하고, 임계 판단은 06-03이 한다. 여기서 임의로 굵기를 빼지 않는다.
- **`.ttf`만 구했다** → 확장자를 바꿔 등록해도 무방하다. 산출물 목록의 파일명도 같이 고친다.
