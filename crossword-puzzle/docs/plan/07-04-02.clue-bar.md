## 목표

`HintPanel` + 그 아래 떠 있던 `WordInput`을 **하나의 ClueBar**로 합친다. 배지·힌트 본문·◀▶·입력 필드가 한 덩어리로 보이는 NYT Crossword 모바일 레이아웃이다. 힌트 교체는 E-04 크로스페이드로 움직인다.

`WordInput` **위젯 내부는 건드리지 않는다**(07-04 결정, INV-02a). ClueBar는 그걸 `child`로 받아 감싸기만 한다.

## 컨텍스트 (시작 전 읽기)

## 작업

### 1. `ClueBar`

props: `PlacedWord? selected`, `int? number`, `String hintText`, `VoidCallback onPrev`, `VoidCallback onNext`, `Widget child`(WordInput), `int hintMaxLines = 3`(07-04-05가 1로 접는다).

```dart
/// 기존 `HintPanel._header`와 **같은 형식**을 유지한다: "가로 3   3글자"(공백 3칸).
/// 화면에는 배지와 길이를 따로 그리므로, 이 문자열은 헤더 행의 `Semantics(label:)`로
/// 남겨 형식과 접근성 레이블을 동시에 지킨다.
static String headerOf(PlacedWord w, int? number) {
  final dirLabel = w.dir == Direction.across ? '가로' : '세로';
  return number == null
      ? '$dirLabel   ${w.length}글자'
      : '$dirLabel $number   ${w.length}글자';
}
```

레이아웃 — `Container(color: surfaceAlt, radius: GameRadius.panel, padding: GameSpace.m)` 안의 `Column(crossAxisAlignment: start)`:

| 순서 | 내용 |
|---|---|
| 1 | `Semantics(label: headerOf(...))` → `Row`: `IconButton(Icons.chevron_left, onPressed: selected == null ? null : onPrev)` · 배지 `Container(accentSoft, GameRadius.pill, padding h:s v:xs)`에 `Text('가로 3', GameType.label, color: cellInk)` · `SizedBox(GameSpace.s)` · `Expanded(Text('3글자', GameType.label, color: inkMuted))` · `IconButton(Icons.chevron_right, …onNext)` |
| 2 | `SizedBox(height: GameSpace.xs)` |
| 3 | `AnimatedSwitcher`(힌트 본문, 아래 2절) |
| 4 | `SizedBox(height: GameSpace.s)` |
| 5 | `child` — `WordInput` 그대로 |

미선택(`selected == null`)이면 1행 대신 `Text('칸을 눌러 단어를 고르세요', GameType.body, color: inkMuted)` 한 줄, 화살표 둘은 `onPressed: null`. `child`는 그대로 둔다 — `WordInput`이 스스로 비활성화한다.

색·간격·반지름은 전부 UI-GUIDE 2.2/2.5 토큰이다. 리터럴 색·`Duration` 금지(INV-05, INV-12).

### 2. E-04 — 힌트 크로스페이드

UI-GUIDE 3.3 E-04: `base` / `curveStandard`, 페이드 + 4dp 상승.

```dart
final m = GameMotion.of(context);
AnimatedSwitcher(
  duration: m.base,
  switchInCurve: m.curveStandard,
  switchOutCurve: m.curveStandard,
  // 페이드 + 4dp 상승: FadeTransition(opacity: anim) 안에 SlideTransition
  // (position: Tween(begin: Offset(0, 0.1), end: Offset.zero).animate(anim))
  transitionBuilder: (child, anim) => …,
  // 자식 Key가 같으면 교체를 인식하지 못한다(07-04 "막히면").
  // PlacedWord는 ==를 재정의하지 않으므로(01-01) 위치+방향 문자열로 만든다.
  child: Text(hintText,
      key: ValueKey(selected == null
          ? '' : '${selected!.row},${selected!.col},${selected!.dir}'),
      maxLines: hintMaxLines,
      overflow: TextOverflow.ellipsis,
      style: GameType.body.copyWith(color: GameColors.of(context).ink)),
)
```

감소 모션에서 `m.base == Duration.zero`이므로 전환이 즉시 끝난다(07-02-02).

### 4. 기존 테스트 셀렉터 수정 (`play_loop_test.dart`)

테스트 이름은 **하나도 바꾸지 않는다**(INV-08). 고치는 곳은 4군데뿐이다.

| 줄 | 현재 | 수정 후 |
|---|---|---|
| 52 | `import '.../hint_panel.dart';` | `import 'package:jgame/ui/puzzle/clue_bar.dart';` |
| 156 | `find.byType(HintPanel)` | `find.byType(ClueBar)` |
| 216 | `tester.widget<HintPanel>(find.byType(HintPanel))` | `tester.widget<ClueBar>(find.byType(ClueBar))` |
| 376 | `HintPanel(selected:, number:, hintText:)` | `ClueBar(…같은 3개…, onPrev: () {}, onNext: () {}, child: const SizedBox.shrink())` |

216줄이 읽는 `panel.selected`·`panel.hintText`는 `ClueBar`에도 같은 이름·타입으로 있으므로 단언문은 그대로다.

## 테스트 `test/ui/puzzle_screen_test.dart` (신규 — 3/13)

`play_loop_test.dart`의 `openEmptyDb`/`buildScope`/`wrapApp`/`cellCenter` 헬퍼를 같은 모양으로 옮겨 온다. seed는 결정성을 위해 1000.

| 테스트 이름 | 기대 |
|---|---|
| `ClueBar 미선택: 안내 문구와 비활성 화살표` | `find.descendant(of: find.byType(ClueBar), matching: find.text('칸을 눌러 단어를 고르세요'))`가 **`findsNWidgets(2)`** — ClueBar 본문 1 + `WordInput`의 `TextField` 힌트 1(둘 다 의도된 INV-09 문구다). `IconButton` 둘의 `onPressed`가 null |

## 막히면

- **`find.text('칸을 눌러 단어를 고르세요')`가 2개 잡힘** → 정상이다. `WordInput`이 미선택일 때 같은 문구를 `TextField.hintText`로 쓰고, 빈 필드에서는 그게 실제 `Text`로 그려진다. 테스트 표대로 `findsNWidgets(2)`로 단언한다.
- **`AnimatedSwitcher`가 텍스트를 교체하지 않음** → 자식 `Key`가 같아서다. `ValueKey`에 위치+방향을 넣었는지 확인한다.
- **키보드가 올라오면 격자가 눌림** → 이 문서 범위 밖이다. 07-04-05가 `hintMaxLines`와 여백으로 처리한다. 지금은 기본값 3만 둔다.
- **`ClueBar`가 `WordInput`의 포커스를 잃게 함** → `child`에 `Key`를 주지 않는다. 키가 바뀌면 위젯이 재생성돼 포커스가 끊긴다.
- **배지 글자가 `accentSoft` 위에서 안 읽힘** → UI-GUIDE 2.3이 `cellInk / accentSoft` 4.5를 보장한다. 배지 글자색이 `cellInk`인지 확인한다.
