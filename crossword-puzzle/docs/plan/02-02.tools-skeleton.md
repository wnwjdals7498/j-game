## 목표

`python -m tools build | report | check` 가 돌아가는 **빈 파이프라인**을 먼저 세운다.
각 단계는 아직 아무것도 안 하지만, 파일 흐름·중간 산출물 경로·설정값이 확정된다.
데이터 승인 전에도 만들 수 있다 (PLAN.md 2절).

## 설계 원칙

1. **중간 산출물은 JSONL.** 각 단계가 파일을 남기므로 눈으로 확인 가능하고, 파서만 갈아끼울 수 있다.
2. **전체 재실행이 1~2분 안에** 끝나야 한다. 각 단계는 앞 단계 출력만 읽는다.
3. **설정값은 `config.py` 한 곳.** 티어 비율·길이 컷·품사 목록을 코드에 흩뿌리지 않는다.

## 파일 흐름

```
tools/raw/*.xml, *.csv
  ├─ parse_krdict  → build/entries.krdict.jsonl
  ├─ parse_stdict  → build/entries.stdict.jsonl
  ├─ parse_freq    → build/freq.jsonl
  └─ parse_vocab   → build/vocab.jsonl
                          ↓
      normalize     → build/normalized.jsonl     (표제어 필터·정규화)
                          ↓
      merge         → build/merged.jsonl         (표제어 기준 결합)
                          ↓
      score         → build/scored.jsonl         (복합 점수 + 티어)
                          ↓
      build_sqlite  → build/words.sqlite
                          ↓
      (수동 복사)    → app/assets/words.sqlite
```

## `io_util.py`

```python
import json
from pathlib import Path
from typing import Iterable, Iterator

def write_jsonl(path: Path, rows: Iterable[dict]) -> int:
    path.parent.mkdir(parents=True, exist_ok=True)
    n = 0
    with path.open("w", encoding="utf-8") as f:
        for r in rows:
            f.write(json.dumps(r, ensure_ascii=False))
            f.write("\n")
            n += 1
    return n

def read_jsonl(path: Path) -> Iterator[dict]:
    with path.open("r", encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                yield json.loads(line)

def count_jsonl(path: Path) -> int:
    return sum(1 for _ in read_jsonl(path))
```

`ensure_ascii=False` — 한글이 이스케이프되면 파일이 3배로 커지고 눈으로 못 읽는다.

## `pipeline.py`

```python
import time
from . import config, io_util
from . import parse_krdict, parse_stdict, parse_freq, parse_vocab
from . import normalize, merge, score, build_sqlite

STEPS = [
    ("parse_krdict", parse_krdict.run),
    ("parse_stdict", parse_stdict.run),
    ("parse_freq",   parse_freq.run),
    ("parse_vocab",  parse_vocab.run),
    ("normalize",    normalize.run),
    ("merge",        merge.run),
    ("score",        score.run),
    ("build_sqlite", build_sqlite.run),
]

def build(only: str | None = None, use_fixtures: bool = False) -> None:
    config.BUILD.mkdir(parents=True, exist_ok=True)
    for name, fn in STEPS:
        if only and name != only:
            continue
        t0 = time.perf_counter()
        n = fn(use_fixtures=use_fixtures)
        dt = time.perf_counter() - t0
        print(f"  {name:<14} {n:>8,} rows  {dt:6.1f}s")
```

각 모듈의 `run(use_fixtures: bool) -> int` 시그니처를 고정한다. 반환은 처리한 행 수.
`use_fixtures=True` 면 `config.RAW` 대신 `config.FIXTURES` 를 읽는다 — 데이터 승인 전 개발용.

## `__main__.py`

```python
import argparse
import sys
from . import pipeline, report, config

def main(argv=None) -> int:
    p = argparse.ArgumentParser(prog="python -m tools")
    sub = p.add_subparsers(dest="cmd", required=True)

    b = sub.add_parser("build", help="raw -> words.sqlite")
    b.add_argument("--only", help="한 단계만 실행 (parse_krdict 등)")
    b.add_argument("--fixtures", action="store_true",
                   help="tools/raw 대신 tools/fixtures 사용 (승인 전 개발)")

    sub.add_parser("report", help="docs/reports/02-db-report.md 생성")
    sub.add_parser("check", help="산출물 검증")

    a = p.parse_args(argv)
    if a.cmd == "build":
        pipeline.build(only=a.only, use_fixtures=a.fixtures)
    elif a.cmd == "report":
        report.render()
    elif a.cmd == "check":
        return 0 if report.check() else 1
    return 0

if __name__ == "__main__":
    sys.exit(main())
```

def test_jsonl_roundtrip(tmp_path):
    from tools.io_util import write_jsonl, read_jsonl
    rows = [{"headword": "사과", "tier": 1}, {"headword": "나무", "tier": 2}]

## 막히면

- **`python -m tools` 가 모듈을 못 찾음** → 저장소 루트에서 실행해야 한다. `tools/__init__.py` 존재 확인.
- **순환 import** → `config` 는 아무것도 import하지 않는다. `pipeline` 만 각 단계를 import한다.
- **`str | None` 문법 오류** → Python 3.10+ 필요. 3.13이므로 정상. 3.6 인터프리터로 실행했는지 확인(`python3` 금지).
