## 출력 스키마

`freq.jsonl`
```json
{"headword": "사람", "rank": 1, "count": 12345}
```

| 필드 | 필수 | 설명 |
|---|---|---|
| `headword` | ✓ | 표제어. 원문 그대로 (정규화는 02-06) |
| `rank` | ✓ | 빈도 순위. 1이 가장 빈번 |
| `count` | | 출현 횟수. 원본에 있으면 |

**순위 컬럼이 없고 빈도수만 있으면** 빈도 내림차순으로 정렬해 `rank` 를 직접 부여한다.
동률은 같은 순위를 준다 (`rank` 가 건너뛰어도 무방 — 02-08은 정규화만 한다).

`vocab.jsonl`
```json
{"headword": "사람", "grade": "A"}
```

| 필드 | 필수 | 설명 |
|---|---|---|
| `headword` | ✓ | 표제어 |
| `grade` | ✓ | `A`(초급) / `B`(중급) / `C`(고급). 원본 표기가 다르면 매핑 |

원본이 "초급/중급/고급" 이나 "1급/2급/..." 이면 **명시적 매핑 표**를 코드에 둔다:

```python
GRADE_MAP = {
    "초급": "A", "중급": "B", "고급": "C",
    "A": "A", "B": "B", "C": "C",
}
```

매핑에 없는 값이 나오면 **조용히 버리지 말고 로그에 찍고 개수를 센다.**

## 인코딩

국립국어원 csv는 **CP949(EUC-KR)** 인 경우가 많다. UTF-8로 열면 `UnicodeDecodeError` 가 난다.

```python
def _open_csv(path: Path):
    """UTF-8(BOM 포함) → CP949 순으로 시도."""
    for enc in ("utf-8-sig", "cp949", "euc-kr"):
        try:
            with path.open("r", encoding=enc, newline="") as f:
                f.read(4096)
            return path.open("r", encoding=enc, newline="")
        except UnicodeDecodeError:
            continue
    raise UnicodeDecodeError(
        "csv", b"", 0, 1, f"인코딩 판별 실패: {path}")
```

성공한 인코딩을 로그에 찍고 `tools/README.md` 에 기록한다 — 다음 갱신 때 시간을 아낀다.

## 컬럼 매핑

헤더 이름은 원본마다 다르다. **02-01 조사 결과를 보고** 상수로 고정한다:

```python
# 02-01 조사 결과에 맞춰 수정
FREQ_COL_WORD = "어휘"
FREQ_COL_RANK = "순위"      # 없으면 None
FREQ_COL_COUNT = "빈도"
VOCAB_COL_WORD = "어휘"
VOCAB_COL_GRADE = "등급"
```

## 구현 골격

```python
# tools/parse_freq.py
import csv
from pathlib import Path
from . import config, io_util

OUT = "freq.jsonl"

def run(use_fixtures: bool = False) -> int:
    base = config.FIXTURES if use_fixtures else config.RAW
    files = sorted(base.glob("*freq*.csv")) or sorted((base / "freq").glob("*.csv"))
    if not files:
        raise FileNotFoundError("빈도 csv 없음. tools/raw/ 확인 (00-01)")

    rows = []
    for p in files:
        with _open_csv(p) as f:
            for r in csv.DictReader(f):
                w = (r.get(FREQ_COL_WORD) or "").strip()
                if not w:
                    continue
                cnt = _to_int(r.get(FREQ_COL_COUNT))
                rk = _to_int(r.get(FREQ_COL_RANK)) if FREQ_COL_RANK else None
                rows.append({"headword": w, "rank": rk, "count": cnt})

    if any(r["rank"] is None for r in rows):
        # 순위 없음 → count 내림차순으로 직접 부여
        rows.sort(key=lambda r: -(r["count"] or 0))
        prev, rank = None, 0
        for i, r in enumerate(rows, 1):
            if r["count"] != prev:
                rank = i
                prev = r["count"]
            r["rank"] = rank

    # 같은 표제어가 여러 번 나오면 가장 높은 순위(작은 값)만 남긴다
    best = {}
    for r in rows:
        cur = best.get(r["headword"])
        if cur is None or r["rank"] < cur["rank"]:
            best[r["headword"]] = r

    return io_util.write_jsonl(config.BUILD / OUT, best.values())
```

`_to_int` 는 `"1,234"` 같은 천단위 구분자를 처리한다:

```python
def _to_int(v):
    if v is None:
        return None
    s = str(v).replace(",", "").strip()
    return int(s) if s.isdigit() else None
```

`parse_vocab.py` 도 같은 구조. `GRADE_MAP` 미매칭 개수를 로그에 찍는다.

## 중복 표제어 처리

빈도 조사에는 품사별로 같은 표제어가 여러 번 나온다(`사람/명사`, `사람/의존명사`).
게임의 `word` 는 표제어 문자열이 PK이므로 (DESIGN 4절) **가장 높은 순위만 남긴다.**
이게 난이도상 보수적인(= 쉽게 보는) 선택이다. 결정을 주석으로 남긴다.

## 테스트

`tools/tests/test_parse_freq.py`, `test_parse_vocab.py`

| 테스트 | 기대 |
|---|---|
| 기본 파싱 | 샘플 행 수만큼 생성 |
| 순위 없는 원본 | count 내림차순으로 rank 부여, 1부터 시작 |
| 동률 처리 | 같은 count → 같은 rank |
| 중복 표제어 | 가장 작은 rank만 남음 |
| 천단위 구분자 | `"1,234"` → `1234` |
| CP949 파일 | 정상 디코딩 |
| UTF-8 BOM 파일 | 정상 디코딩 (첫 컬럼에 BOM 잔류 없음) |
| 등급 매핑 | `초급` → `A` |
| 미매칭 등급 | 버려지고 개수가 로그에 찍힘 |
| 파일 없음 | `FileNotFoundError` |
