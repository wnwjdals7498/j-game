- 현대 국어 사용 빈도 조사 2 (`일반어휘통계.xlsx`) → `build/freq.jsonl` (주 지표)

**품사별 중복 표제어**에서 막힌다.

## 출력 스키마

`freq.jsonl`
```json
{"headword": "사람", "rank": 1, "count": 12345}
```

| 필드 | 필수 | 설명 |
|---|---|---|
| `headword` | ✓ | 표제어. **`hangul.normalize_headword` 적용 후**(동형어 번호 제거, NFC) 저장한다 |
| `rank` | ✓ | 빈도 순위. 1이 가장 빈번 |
| `count` | | 출현 횟수. 원본에 있으면 |

**순위 컬럼이 없고 빈도수만 있으면** 빈도 내림차순으로 정렬해 `rank` 를 직접 부여한다.
동률은 같은 순위를 준다 (`rank` 가 건너뛰어도 무방 — 02-08은 정규화만 한다). 실제
`일반어휘통계.xlsx` 는 순위 컬럼이 이미 있어 이 폴백은 타지 않는다(아래 "실제 파일
구조" 참조).

`vocab.jsonl`
```json
{"headword": "사람", "grade": "A"}
```

| 필드 | 필수 | 설명 |
|---|---|---|
| `headword` | ✓ | 표제어. freq 와 동일하게 정규화 후 저장 |
| `grade` | ✓ | `A`(초급) / `B`(중급) / `C`(고급). 원본 표기가 다르면 매핑 |

원본이 "초급/중급/고급" 이나 "1급/2급/..." 이면 **명시적 매핑 표**를 코드에 둔다:

```python
GRADE_MAP = {
    "초급": "A", "중급": "B", "고급": "C",
    "A": "A", "B": "B", "C": "C",
}
```

매핑에 없는 값이 나오면 **조용히 버리지 말고 로그에 찍고 개수를 센다.**

> **정정**: 실데이터는 이미 `A`/`B`/`C` 이므로 항등 매핑(`"A": "A"` 등)만 실제로
> 쓰인다. "초급/중급/고급" 매핑은 과거(00-01 승인 전 샘플 기준) 가정이 남긴 것으로,
> 향후 원본이 텍스트 표기로 바뀌어도 깨지지 않도록 그대로 둔다.

## 실제 파일 구조 (02-01 재조사)

인코딩 판별 대신, 두 파일 모두 **openpyxl/xlrd 로 첫 시트를 읽고 헤더로 컬럼을
찾는** 방식이다. `csv.DictReader` 를 흉내 내는 헬퍼(`_rows_from_workbook`/
`_rows_from_sheet`)가 `{컬럼명: 값}` dict 이터레이터를 돌려준다.

| | 빈도 (`일반어휘통계.xlsx`) | 학습용 어휘 (`한국어 학습용 어휘 목록.xls`) |
|---|---|---|
| 라이브러리 | `openpyxl.load_workbook(path, read_only=True, data_only=True)` | `xlrd.open_workbook(str(path))` (2.x — `.xlsx` 못 읽음) |
| 시트 | 1개 (`일반어휘통계+`) | 1개 (`한국어학습용어휘등급표 원어 정보 정리 쿼리`) |
| 헤더 | `순위, 빈도, 어휘, 풀이, 품사` (+이름 없는 빈 6번째 컬럼 — falsy 헤더는 무시) | `순위, 단어, 품사, 풀이, 등급` |
| 행 수 | **82,501행**(헤더 제외, 00-01 예상 82,502와 거의 일치) | **5,965행**(00-01 예상과 정확히 일치) |
| 셀 타입 | 숫자 컬럼이 이미 int/float — csv 식 `"1,234"` 콤마 파싱은 방어 코드일 뿐 실제로 안 탐 | 숫자 셀은 전부 **float**(순위가 `1195.0`처럼) — vocab.jsonl 엔 순위가 없어 무관 |
| 동형어 번호 | **어휘 컬럼에 붙음**(`가01`, `가02`, `ㄱ01`) — 82,501행 중 23,912행(29%) | **단어 컬럼에 붙음**(`가격03`, `가다01`) — 5,965행 중 2,778행(47%) |
| 무시할 파일 | 같은 폴더의 구통계·음절통계·자모통계·조사통계·어미통계(.xlsx/.xlt) — 단어 빈도가 아님. `_src_files` 가 `일반어휘통계*.xlsx` 로 정확히 이 파일만 찾는다 | 없음(파일 하나뿐) |

## 동형어 번호 정규화 (02-07.merge.md "막히면" 지시)

두 원본 모두 표제어에 동형어 번호가 붙어 있어서, 정규화 없이 그대로 저장하면
`merge.py` 가 기대하는 (`entries.*.jsonl` 이 이미 정규화를 거친) 표제어와 매칭되지
않는다. 그래서 **파서 단계에서** `hangul.normalize_headword` 를 적용한 뒤 rank/grade
를 결합한다:

```python
from .hangul import normalize_headword
...
w = normalize_headword(w_raw)   # "가01" -> "가", "가격03" -> "가격"
```

정규화 함수는 `normalize.py` 가 아니라 **`hangul.py`** 에서 가져온다. `normalize.py`
는 `entries.krdict.jsonl`/`entries.stdict.jsonl` (02-03/02-04 출력)을 읽는 02-06
단계용이라, `parse_freq.py`/`parse_vocab.py` 가 그걸 import 하면 실행 순서상 아직
없는 파일에 의존하는 순환 참조가 생긴다. 02-08 문서가 이미 "`tools/hangul.py`
(02-06/02-07이 쓰는 정규화 함수도 여기로 모은다)"라고 정해 두었으므로, 이 결정은
그 정본을 그대로 따른 것이다. `normalize.py` 는 `hangul.py` 에서 같은 이름을
다시 내보내기만 한다(02-06의 공개 이름은 그대로 유지).

정규화는 표제어를 합치기도 한다 — 예를 들어 `가01`(빈도표 순위 2)와 `가02`(순위 3)는
둘 다 `가` 로 정규화되고, "중복 표제어 처리" 규칙에 따라 더 좋은 순위(2)만 남는다.

## 컬럼 매핑

헤더 이름은 원본마다 다르다. **02-01 조사 결과를 보고** 상수로 고정한다:

```python
# 02-01 조사 결과(위 "실제 파일 구조" 표)에 맞춰 고정
FREQ_COL_WORD = "어휘"
FREQ_COL_RANK = "순위"      # 실데이터엔 있음. 없는 원본이 오면 None 으로
FREQ_COL_COUNT = "빈도"
VOCAB_COL_WORD = "단어"     # "어휘" 아님 — 00-01 예상과 다름
VOCAB_COL_GRADE = "등급"
```

헤더가 없으면 인덱스로 접근한다. **어느 쪽인지 코드에 하드코딩하기 전에 README를 확인한다.**

## 구현 골격

```python
# tools/parse_freq.py
from pathlib import Path
import openpyxl
from . import config, io_util
from .hangul import normalize_headword

OUT = "freq.jsonl"

def _src_files(use_fixtures: bool) -> list[Path]:
    base = config.FIXTURES if use_fixtures else config.RAW
    if use_fixtures:
        return sorted(base.glob("*freq*.xlsx"))
    # 폴더 안에 무관한 통계 파일이 여러 개 있으므로 파일명을 정확히 찾는다
    return sorted(base.rglob("일반어휘통계*.xlsx"))

def _rows_from_workbook(path: Path):
    """xlsx 첫 시트를 `{컬럼명: 값}` dict 의 이터레이터로 돌려준다 (csv.DictReader 대응)."""
    wb = openpyxl.load_workbook(path, read_only=True, data_only=True)
    try:
        ws = wb[wb.sheetnames[0]]
        rows = ws.iter_rows(values_only=True)
        header = next(rows)
        idx = {name: i for i, name in enumerate(header) if name}
        for row in rows:
            yield {name: row[i] if i < len(row) else None for name, i in idx.items()}
    finally:
        wb.close()

def run(use_fixtures: bool = False) -> int:
    files = _src_files(use_fixtures)
    if not files:
        raise FileNotFoundError("빈도 xlsx 없음. tools/raw/ 확인 (00-01)")

    rows = []
    for p in files:
        for r in _rows_from_workbook(p):
            w_raw = str(r.get(FREQ_COL_WORD) or "").strip()
            if not w_raw:
                continue
            w = normalize_headword(w_raw)   # 동형어 번호 제거 후 결합
            if not w:
                continue
            cnt = _to_int(r.get(FREQ_COL_COUNT))
            rk = _to_int(r.get(FREQ_COL_RANK)) if FREQ_COL_RANK else None
            rows.append({"headword": w, "rank": rk, "count": cnt})

    if any(r["rank"] is None for r in rows):
        _assign_ranks(rows)   # count 내림차순, 동률은 같은 순위

    best = _best_by_headword(rows)   # 정규화 후 중복이면 최고 순위(작은 rank)만
    return io_util.write_jsonl(config.BUILD / OUT, best.values())
```

`_to_int` 는 `"1,234"` 같은 천단위 구분자 문자열, `float`, `bool` 을 방어적으로
처리한다(xlsx 숫자 셀은 이미 int/float 라 실제로는 거의 타지 않는 경로다):

```python
def _to_int(v):
    if v is None or isinstance(v, bool):
        return None
    if isinstance(v, int):
        return v
    if isinstance(v, float):
        return int(v)
    s = str(v).replace(",", "").strip()
    return int(s) if s.lstrip("-").isdigit() else None
```

`parse_vocab.py` 는 `xlrd.open_workbook(str(path)).sheet_by_index(0)` 으로 같은
구조를 만든다(`_rows_from_sheet`). `GRADE_MAP` 미매칭 개수와 실제 값을 로그에 찍는다.

## 중복 표제어 처리

빈도 조사에는 품사별로 같은 표제어가 여러 번 나온다(`사람/명사`, `사람/의존명사`).
게임의 `word` 는 표제어 문자열이 PK이므로 (DESIGN 4절) **가장 높은 순위만 남긴다.**
이게 난이도상 보수적인(= 쉽게 보는) 선택이다. 학습용 어휘는 같은 이유로 **가장 쉬운
등급(A < B < C)만** 남긴다. 결정을 주석으로 남긴다.

**정규화가 중복을 늘린다**는 점에 주의: 동형어 번호를 떼기 전에는 서로 다른 표제어
(`가01`, `가02`)였던 것이 정규화 후 같은 표제어(`가`)가 되므로, 이 dedup은 **정규화
이후에** 수행해야 한다. 실데이터 기준 빈도는 82,501행 → 73,770행(중복 8,731건 제거),
학습용 어휘는 5,965행 → 5,543행(중복 422건 제거, 등급 미매칭 0건)이다.

## 테스트

`tools/tests/test_parse_freq.py`, `test_parse_vocab.py`. 픽스처는
`tools/fixtures/freq_sample.xlsx`/`vocab_sample.xls` (손수 만든 xlsx/xls, 실데이터
아님) — 과거 csv 픽스처는 새 포맷으로 교체됐다.

| 테스트 | 기대 |
|---|---|
| 기본 파싱 | 샘플 행 수만큼 생성 |
| xlsx 숫자 셀 | 이미 int — `"62,384"` 같은 콤마 문자열 파싱이 필요 없음(방어 코드만 별도 검증) |
| 순위 없는 원본 | count 내림차순으로 rank 부여, 1부터 시작 |
| 동률 처리 | 같은 count → 같은 rank |
| **동형어 번호 정규화** | `가01`/`가02` → `가` 로 합쳐지고 더 좋은 순위만 남음 |
| 중복 표제어(정규화 후) | 가장 작은 rank(빈도)/가장 쉬운 등급(vocab)만 남음 |
| 등급 매핑 | 실데이터는 이미 `A`/`B`/`C` — 항등 매핑만 실제로 쓰임(`GRADE_MAP["초급"]` 매핑 자체는 유지) |
| 미매칭 등급 | 버려지고 개수와 실제 값이 로그에 찍힘 |
| 표제어 빈 행 | 스킵 |
| 파일 없음 | `FileNotFoundError` |
| 산출물이 유효한 UTF-8 JSONL | 한글이 이스케이프되지 않음 |

csv 시절의 CP949/UTF-8 BOM 인코딩 테스트는 **해당 없음이라 뺐다**(xlsx/xls는
바이너리 컨테이너라 그 문제 자체가 없다).

## 막히면

- **시트 이름/헤더 순서가 바뀜** → `_rows_from_workbook`/`_rows_from_sheet` 는 헤더
  텍스트로 컬럼을 찾으므로 순서 변경엔 안전하다. 헤더 **문구 자체**가 바뀌면
  `FREQ_COL_*`/`VOCAB_COL_*` 상수만 고치면 된다(02-01로 돌아가 실제 헤더를 다시 확인).
- **동형어 정규화 후 매칭률이 오히려 나빠짐** → 정규화가 서로 다른 원어(`가01` 사람
  이름 vs `가02` 조사)를 한 표제어로 뭉갤 수 있다. 이건 게임의 `word` PK가 표제어
  문자열 하나뿐이라는 DESIGN 4절의 근본 한계이지 이 파서의 버그가 아니다 — 02-07/02-08
  결과를 보고 완화 여부를 판단한다.
- **`GRADE_MAP` 미매칭 값이 실제로 나타남** → 로그에 찍힌 실제 문자열을 보고 매핑을
  추가한다. 지금은 항등 매핑만 실제로 쓰이는 상태라(전수 확인) 발생 가능성은 낮다.
- **행 수가 예상(82,501/5,965)과 크게 다름** → 시트를 잘못 골랐거나 필터가 걸린
  상태로 저장했다. 02-01로 돌아간다.
