## 목표

`GameColors`·`GameMotion`을 실제 `ThemeData` 두 개로 묶고 `main.dart`의 `colorSchemeSeed: Colors.indigo` 한 줄을 대체한다.
이 커밋부터 앱의 색·타이포가 UI-GUIDE 톤으로 바뀐다(Material 위젯이 새 `ColorScheme`을 따르는 수준).
화면 레이아웃 개편은 07-03부터다.

## 컨텍스트 (시작 전 읽기)

- `docs/UI-GUIDE.md` 2.2 마지막 줄(`ColorScheme` 매핑) · 2.4 마지막 줄(`TextTheme` 매핑) · 2.5 버튼 규격 · 4절 화면 공통 규칙
- `app/lib/main.dart` — `JGameApp.build`에 `MaterialApp`이 **3개**(에러·로딩·정상) 있다. `theme`는 세 곳 모두에 넣는다
- `app/lib/ui/puzzle/grid_view.dart:57` — `Theme.of(context).colorScheme`를 `GridPainter`에 넘긴다. 이 커밋의 `ColorScheme` 변경이 격자에 곧바로 보인다
- `app/lib/ui/puzzle/grid_painter.dart` — 검은 칸에 `surfaceContainerHighest`, 선택 하이라이트에 `primaryContainer`, 테두리에 `outlineVariant`를 쓴다. 매핑값을 고를 때 이 세 이름을 반드시 확인한다

## 작업

### 1. `ColorScheme` 매핑

UI-GUIDE 2.2 마지막 줄이 정한 10개는 그대로, 나머지 필수·준필수 필드는 아래 표대로 채운다.

| 필드 | 값 | 근거 |
|---|---|---|
| `primary` / `onPrimary` | `ink` / `surface` | UI-GUIDE 2.2 |
| `surface` / `onSurface` | `surface` / `ink` | UI-GUIDE 2.2 |
| `onSurfaceVariant` | `inkMuted` | UI-GUIDE 2.2 |
| `outline` / `outlineVariant` | `line` / `line` | UI-GUIDE 2.2 |
| `error` | `danger` | UI-GUIDE 2.2 |
| `secondaryContainer` | `accentSoft` | UI-GUIDE 2.2 |
| `tertiary` | `accent` | UI-GUIDE 2.2 |
| `secondary` / `onSecondary` | `accentSoft` / `cellInk` | 필수 필드. 2.2가 비워 둔 칸을 가장 가까운 토큰으로 |
| `onSecondaryContainer` | `cellInk` | 선택 단어 위 글자(2.3 대비 쌍) |
| `onTertiary` | `cellInkOnAccent` | 커서 셀 위 글자(2.3 대비 쌍) |
| `onError` | `surface` | 오류 배경 위 글자 |
| `primaryContainer` / `onPrimaryContainer` | `accentSoft` / `cellInk` | **`grid_painter.dart`가 선택 하이라이트로 읽는다.** 비워 두면 M3 기본 보라가 격자에 뜬다 |
| `surfaceContainerHighest` / `surfaceContainerHigh` | `surfaceAlt` | 힌트 바·구획 배경 |

```dart
ThemeData buildLightTheme() => _build(GameColors.light, Brightness.light);
ThemeData buildDarkTheme()  => _build(GameColors.dark,  Brightness.dark);
```

### 2. `TextTheme` 매핑 — UI-GUIDE 2.4 마지막 줄

`displaySmall = display`, `titleLarge = title`, `titleMedium = heading`, `bodyLarge = body`, `bodyMedium = body`, `labelLarge = label`, `bodySmall = caption`.
`.apply(bodyColor: c.ink, displayColor: c.ink)`로 색만 덧입힌다(크기·굵기는 `GameType`이 이미 갖고 있다).

`pageTransitionsTheme`(E-09)는 **넣지 않는다 — 07-07 몫이다.**

### 4. `main.dart` 연결

```dart
return MultiProvider(
  providers: [...],
  child: MaterialApp(
    title: _title,
    theme: buildLightTheme(),
    darkTheme: buildDarkTheme(),
    initialRoute: '/',
    routes: buildRoutes(),
  ),
);
```

- `themeMode`는 07-02-05가 `SettingsModel`과 함께 넣는다. 지금은 `MaterialApp` 기본값(`ThemeMode.system`)이라 시스템 다크에서 다크가 뜬다 — 의도한 중간 상태다.
- 부트스트랩 에러·로딩 분기의 `MaterialApp` 2개에도 같은 `theme`/`darkTheme`를 넣는다. `!snapshot.hasData` 분기는 `const MaterialApp(...)`이므로 **`const`를 떼야 컴파일된다.**
- `colorSchemeSeed` 줄은 **07-01-01이 이미 지웠다**(INV-05 때문에 그 커밋에서 지워야 했다). 지금 `ThemeData(useMaterial3: true)`만 남아 M3 기본 시드 테마로 떨어져 있고, 이 문서가 그 자리를 `buildLightTheme()`/`buildDarkTheme()`로 채운다. `main.dart`에 `Colors.` 리터럴은 이미 0건이다.
- `app/pubspec.yaml` 151~152줄의 `flutter_native_splash` 주석이 `colorSchemeSeed: Colors.indigo`를 근거로 스플래시 색을 설명한다. 이제 근거가 `GameColors.light.surface`(`#FFFFFF`)·`dark.surface`(`#121212`)이므로 주석 문장을 그렇게 고친다(설정값 자체는 이미 같아서 바꿀 필요 없다).

### 5. 기존 테스트 확인

셀렉터는 전부 `find.text`/`find.byType`이라 색·폰트 변경으로 깨지지 않는다. 실제로 돌려 확인하고, 깨지는 게 있으면 **셀렉터만** 고친다(07-ui-v2 공통 규칙 3).

## 막히면

- **격자 검은 칸이 밝은 회색으로 보인다** → 정상이자 예상된 중간 상태다. `grid_painter.dart`가 검은 칸에 `surfaceContainerHighest`(= `surfaceAlt`)를 쓰기 때문이다. 이 커밋에서 painter를 고치지 않는다 — 07-03이 `cellBlocked` 토큰으로 바꾼다.
- **격자 선택 하이라이트가 보라색** → `primaryContainer`를 안 채운 것이다. 위 표대로 `accentSoft`를 넣는다.
- **`ColorScheme` 필수 인자 누락** → 필수는 `brightness, primary, onPrimary, secondary, onSecondary, error, onError, surface, onSurface` 9개다. 나머지는 옵션이지만 위 표의 항목은 전부 명시한다(M3 기본 파생값이 보라 계열로 새어 나온다).
- **`background`/`onBackground`/`surfaceVariant`를 쓰라는 예제를 봤다** → 전부 deprecated다. `surface`/`onSurface`/`surfaceContainerHighest`를 쓴다.
- **스낵바가 테스트 뷰포트에서 잘린다** → `behavior: floating`의 여백 때문이다. 기존 테스트가 쓰는 `useTallViewport`를 그대로 두고, 그래도 안 되면 `SnackBarThemeData.insetPadding`이 아니라 테스트 뷰포트를 키운다.
- **글자가 시스템 폰트로 보인다** → 정상. 폰트 파일은 07-02-04가 넣는다.
