## 단계 공통 규칙

1. **문서에 없는 값은 만들지 않는다.** 색·시간·크기가 필요하면 UI-GUIDE의 토큰을 쓴다. 토큰이 없으면 UI-GUIDE에 추가하는 커밋을 먼저 만든다.
2. **매 세부 문서의 검증은 반드시 다음 세 줄을 포함한다.**
   ```powershell
   cd app
   dart run tool/check_invariants.dart
   flutter analyze
   flutter test
   ```
   하나라도 실패하면 그 문서는 끝나지 않았다.
3. **기존 테스트를 지우지 않는다.** 표현 변경으로 셀렉터가 깨지면 셀렉터만 고친다. INV-08 목록의 테스트 이름은 그대로 둔다.
4. **`lib/domain/**`, `lib/data/**`는 읽기 전용이다.** 필요한 값이 없으면 `lib/ui/state/*Model`에서 계산한다.
5. **새 패키지를 추가하지 않는다.** INV-11이 막는다. 폰트 파일은 에셋이므로 해당 없음.
6. 커밋은 세부 문서 1개 = 커밋 1~2개. 메시지 규칙은 저장소 루트 `AGNETS.md`.

## 완료 기준 (DoD)

1. 홈·퍼즐·결과·설정·라이선스·부트스트랩 6화면이 모두 UI-GUIDE 토큰만으로 그려진다(INV-05, INV-12 통과).
2. 라이트·다크 두 테마가 설정에서 전환되고 시스템 따라가기가 기본이다.
3. E-01~E-12 중 문서가 지정한 이펙트가 전부 구현되고, 시스템 "애니메이션 제거" 설정에서 전부 꺼진다.
4. `dart run tool/check_invariants.dart`, `flutter analyze`, `flutter test`가 깨끗하다.
5. 골든 6장이 저장소에 있고 `flutter test --tags golden`이 통과한다.
6. 실기기(6인치대 1대 + 저가형 1대)에서 8×8 격자 가독성과 60fps 체감을 확인했다(07-08 리포트).
7. 두 IME 재검증 15항목 통과(07-08).

## 리스크

- **IME 회귀**: 입력 필드를 힌트 바 안으로 옮기면서 포커스·키보드 동작이 바뀔 수 있다. `WordInput` 위젯 자체는 건드리지 않고 **감싸는 레이아웃만** 바꾼다. 07-08의 15항목이 최종 판정.
- **골든 테스트 플랫폼 편차**: Windows에서 기록한 골든이 Linux CI에서 1px 차이로 실패할 수 있다. 골든은 `golden` 태그로 분리해 로컬 DoD로 두고 CI는 `--exclude-tags golden`(07-08 결정).
- **격자 애니메이션 비용**: `CustomPaint` 전체 재그리기가 매 프레임 일어난다. 07-03이 애니메이션 중에만 `shouldRepaint` true가 되도록 진행값 맵을 비교해야 한다. 저가 기기 확인은 07-08.
- **폰트 용량**: Pretendard static 3종 ≈ 4~5MB. AAB 크기 점검(06-03)에 반영. 문제가 되면 Noto Sans KR 2종(400/700)으로 줄인다.
- **아이콘 불일치**: 파랑 아이콘과 흑백 UI가 어긋난다. IMG-01은 HUMAN 결정 사항으로 [07-08-04.store-assets-and-icon.md](07-08-04.store-assets-and-icon.md)에 남기고, 생성 프롬프트는 [07-08-05.image-prompts.md](07-08-05.image-prompts.md)에 있다.
