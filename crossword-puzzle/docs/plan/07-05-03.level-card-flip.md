## 작업

### 1. `level_card.dart` — 3상태

`LevelCard`는 `StatefulWidget`이고 필드는 셋이다: `LevelStatus status`, `bool justUnlocked`(E-10 대상 1장만 true), `VoidCallback onTap`(잠금 카드도 받는다).

부모 문서 표 그대로. 값은 전부 토큰(2.2·2.5)이다.

| 상태 | 배경 | 테두리 | 상단 표시 | 이름 글자 |
|---|---|---|---|---|
| 잠금 | `surface` | `line` 1px | `Icon(Icons.lock, semanticLabel: '잠김')`, `inkMuted` | `inkMuted` |
| 해제·미클리어 | `surface` | `ink` 1.5px | 번호(`GameType.heading`, `ink`) | `ink` |
| 클리어 | `surfaceAlt` | 없음 | 번호 + `Icon(Icons.star, color: accent)` + 점수 | `ink` |

구조는 `InkWell(borderRadius: GameRadius.panel)` → `Container(padding: GameSpace.l)` → `Column(start)` 안에 `Row`(상단 표시 24×24, 클리어면 `GameSpace.s` 뒤에 ★와 점수) · `Spacer()` · `Text(spec.name)`. `border`는 클리어면 `null`, 아니면 `Border.all(color: unlocked ? ink : line, width: unlocked ? 1.5 : 1)`. elevation·그림자 없음(UI-GUIDE 1절 "평면").
점수 문구는 `_Trailing`의 형식을 그대로 옮긴다 — 0 이상이면 앞에 `+`(`'+3'`). 별 색은 `GameColors.of(context).accent`이며 기존 `Colors.amber`(`home_page.dart:200`)는 이 커밋에서 사라진다(INV-05).

### 2. E-10 플립

플립하는 것은 **상단 24×24 영역 하나**다 — 자물쇠와 번호를 같은 `SizedBox`에 담아야 크기가 안 튄다.

```dart
late bool _showLock = widget.justUnlocked;
@override
void initState() { super.initState(); if (_showLock) _scheduleFlip(); }
@override
void didUpdateWidget(covariant LevelCard old) {   // 재로드로 같은 Element가 갱신된 경우
  super.didUpdateWidget(old);
  if (widget.justUnlocked && !old.justUnlocked) { _showLock = true; _scheduleFlip(); }
}
void _scheduleFlip() => WidgetsBinding.instance
    .addPostFrameCallback((_) { if (mounted) setState(() => _showLock = false); });
```

`build`에서 감소 모션을 먼저 걸러 낸다 — 시간이 0이면 자물쇠 단계를 아예 건너뛴다(3.2). 그래야 테스트가 첫 프레임에서 확정된다.

```dart
final motion = GameMotion.of(context);
final showLock = !widget.status.unlocked || (_showLock && motion.base != Duration.zero);

AnimatedSwitcher(
  duration: motion.base,
  // 세로축 회전(pi는 dart:math). 나가는 자식도 같은 빌더를 거꾸로 탄다.
  transitionBuilder: (child, anim) => AnimatedBuilder(
    animation: anim, child: child,
    builder: (_, c) => Transform(
      alignment: Alignment.center,
      transform: Matrix4.identity()..setEntry(3, 2, 0.001)
        ..rotateY((1 - motion.curveStandard.transform(anim.value)) * pi / 2),
      child: c)),
  child: SizedBox(key: ValueKey(showLock), width: 24, height: 24, child: /* 자물쇠 or 번호 */),
)
```

`justUnlocked`가 false인 카드는 키가 안 바뀌므로 애니메이션이 없다. `Duration` 리터럴은 쓰지 않는다(INV-12).

### 3. `home_page.dart` 배치

`_LevelRow`·`_Trailing`을 지우고 `ListView`의 마지막 자리를 격자로 바꾼다. `_openLevel`(07-05-01)은 그대로 쓴다.

```dart
GridView.count(
  crossAxisCount: 2, childAspectRatio: 1.15,
  mainAxisSpacing: GameSpace.m, crossAxisSpacing: GameSpace.m,
  shrinkWrap: true,
  physics: const NeverScrollableScrollPhysics(),   // 바깥 ListView가 스크롤한다
  children: [
    for (final s in model.statuses)
      LevelCard(status: s, justUnlocked: s.spec.id == model.justUnlockedId,
          onTap: () => _onCardTap(context, s)),
  ],
)
void _onCardTap(BuildContext context, LevelStatus s) {
  if (!s.unlocked) {
    ScaffoldMessenger.of(context).showSnackBar(
      const SnackBar(content: Text('이전 레벨을 클리어해야 열립니다')),  // INV-09, 글자 무변경
    );
    return;
  }
  _openLevel(context, s.spec);
}
```

### 4. 깨지는 기존 테스트 3곳 (셀렉터만, 이름 유지 — INV-08)

| 테스트(이름 그대로) | 바꿀 곳 |
|---|---|
| `레벨 목록 렌더: levels.length개 행` | `find.byType(ListTile)` → `find.byType(LevelCard)` |
| `클리어 표시: bestScore >= clearScore → ★ + 점수` | `find.text('─')` 줄을 아래 단언으로 교체 |
| `레벨 1 항상 해제` · `해제 레벨 탭` | 07-05-02가 `find.widgetWithText(ListTile, …)`로 고친 것을 `LevelCard`로 |

```dart
final card2 = tester.widget<LevelCard>(find.widgetWithText(LevelCard, levels[1].name));
expect(card2.status.unlocked && !card2.status.cleared, isTrue, reason: '레벨 2: 해제됐으나 미클리어');
```

## 막히면

- **카드 높이가 넘침(RenderFlex overflow)** → 폭 ≈ 160dp, 높이 ≈ 140dp 기준이다. 패딩을 `GameSpace.l`(16) → `GameSpace.m`(12)로 줄이고, 그래도 넘치면 이름 `Text`에 `maxLines: 1, overflow: TextOverflow.ellipsis`.
- **플립이 튀거나 크기가 변함** → 자물쇠와 번호를 각각 `SizedBox(24×24)`에 담았는지, `AnimatedSwitcher`의 `child`에 `ValueKey`가 붙었는지 확인.
- **E-10이 아예 안 보임** → 재로드 중 스피너가 격자를 갈아치우고 있다. 07-05-01의 `model.loading && model.statuses.isEmpty` 분기가 들어갔는지 본다.
- **E-10이 앱 진입마다 재생** → `justUnlockedId`가 첫 `load()`에서 null이어야 한다(07-05-01). `home_model_test.dart`의 "첫 로드는 null"부터 확인. **`GridView`가 스크롤을 뺏으면** `shrinkWrap: true` + `NeverScrollableScrollPhysics` 둘 다 있는지 본다.
- **카드 색 테스트가 `Container`를 못 찾음** → `find.descendant(of: find.byType(LevelCard), matching: find.byType(Container)).first`로 좁히고 `decoration as BoxDecoration`의 `color`를 읽는다.
