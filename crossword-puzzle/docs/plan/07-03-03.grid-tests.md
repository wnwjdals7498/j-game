코어는 `나비야` 하나뿐이고 코어 셀은 3개다 — 코어 원 개수 기대값이 3으로 고정된다.
뷰포트 800×600에서 `side = 600`, `cell = 600 / max(5, 3) = 120`.

모션 테스트는 같은 트리를 두 번 `pumpWidget` 해서 `didUpdateWidget`을 일으킨다:

```dart
Future<PuzzleGridViewState> mount(WidgetTester tester, {
  required Map<(int, int), String> answers,
  PlacedWord? selected, (int, int)? focusedCell, bool reduceMotion = false,
}) async {
  await tester.pumpWidget(MaterialApp(
    theme: buildLightTheme(),
    home: MediaQuery(
      data: MediaQueryData(disableAnimations: reduceMotion),
      child: Scaffold(body: Center(child: PuzzleGridView(
        puzzle: puzzle, answers: answers, selected: selected,
        focusedCell: focusedCell, result: null, onCellTap: (_, _) {},
      ))),
    ),
  ));
  return tester.state<PuzzleGridViewState>(find.byType(PuzzleGridView));

```

`GameColors.of(context)`가 필요하므로 `theme: buildLightTheme()`를 반드시 넘긴다.

11번의 `fast`·13번의 `fast ~/ 2`는 `GameMotion.standard.fast`에서 읽는다(테스트 파일이 시간 상수를 새로 쓰지 않는다).

`cursorOpacity`는 `instant`(80ms)로 훨씬 짧아 중간 프레임을 단정하기 어려우므로 시작·종료 두 점만 본다.

**상위 문서 표는 9행이지만 DoD는 "추가 8종"이라고 적혀 있다.** 같은 `pumpWidget` 시나리오를 이어서 보는
"E-01 시작"과 "E-01 종료"를 11번 하나로 합쳐 8종으로 맞췄다. 검증 범위는 줄지 않는다.

### 4. 코어 원 카운트: 간이 Canvas 래퍼로 한다

| 기준 | 간이 래퍼 | 07-08 골든 위임 |
|---|---|---|
| 프로덕션 코드 추가 | **0줄** — `GridPainter` 시그니처를 건드리지 않는다 | 0줄 |
| 테스트 코드 분량 | 약 12줄 | 0줄 (대신 골든 6장에 의존) |
| 실패 시 원인 지목 | "원이 3개가 아니라 N개" | "이미지가 다름" |
| 플랫폼 편차 | 없음 | 있음 (07-ui-v2 리스크: Windows↔Linux 1px) |
| CI에서 돌아감 | 예 | 아니오 (`--exclude-tags golden`) |

**결론: 간이 래퍼를 쓴다.** 상위 문서가 걱정한 "추상화가 과하면"은 `GridPainter`가 받는 타입을 바꿔야 할 때의
이야기인데, `Canvas`는 `noSuchMethod` 포워딩으로 구현 없이 `implements` 할 수 있어 프로덕션 추상화가 필요 없다.

```dart
class _CountingCanvas implements Canvas {
  int circles = 0;
  @override
  void drawCircle(Offset c, double radius, Paint paint) => circles++;
  @override
  dynamic noSuchMethod(Invocation invocation) => null;
}
```

`result: null`로 그려야 한다 — 층 8의 정답 점도 `drawCircle`이라 제출 결과가 있으면 개수가 섞인다.
텍스트는 `TextPainter`가 `drawParagraph`를 부르고 `noSuchMethod`가 삼키므로 예외 없이 끝난다.

## 막히면

- **`tester.state<PuzzleGridViewState>`가 타입을 못 찾음** → 07-03-02에서 상태 클래스를 공개로 두기로 했다. `_PuzzleGridViewState`로 남아 있으면 그쪽을 먼저 고친다.
- **`pump(fast)` 뒤에도 `pop`이 비지 않음** → 컨트롤러가 정확히 `fast`에 끝나려면 시작 프레임(`pump()`)이 먼저 한 번 있어야 한다. 시나리오의 `pump()` → `pump(fast)` 순서를 지킨다.
- **`disableAnimations`가 안 먹음** → `MediaQuery`를 `MaterialApp` **안쪽**(`home` 아래)에 둬야 `GameMotion.of`가 읽는다. `MaterialApp` 바깥에 두면 앱이 자기 `MediaQuery`를 새로 만든다.
- **테스트에서 글자가 사각형으로 보임** → 정상이다(테스트 폰트). 이 파일은 픽셀을 보지 않는다.
- **`_CountingCanvas`가 `Canvas`를 implements 못 함** → `noSuchMethod`를 선언한 클래스에는 누락 멤버 포워더가 자동 생성된다. 그래도 막히면 이 한 종만 07-08 골든으로 미루고 나머지 14종을 유지한다.
- **`GameColors.of(context)`가 null이라 위젯 테스트가 죽음** → `mount`에 `theme: buildLightTheme()`를 빠뜨린 것이다. 기본 `ThemeData`에는 확장이 없다.
