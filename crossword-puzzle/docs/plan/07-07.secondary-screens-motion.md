## 작업

### 1. 화면 전환 E-09

`fade_through_route.dart`에 `PageTransitionsBuilder` 구현:
- 들어오는 화면: 알파 0→1(구간 0.3~1.0) + 스케일 0.98→1.0, `curveEmphasized`.
- 나가는 화면: 알파 1→0(구간 0~0.3).
- 지속 시간은 `MaterialPageRoute` 기본(300ms)이 아니라 **`GameMotion.base`**를 따라야 한다. `PageTransitionsBuilder`는 `Duration`을 직접 정하지 않으므로, 라우트 생성 지점(`Navigator.push(MaterialPageRoute(...))` 4곳(`home_page.dart:179`, `puzzle_page.dart:168`·`:194`, `settings_page.dart:64`))을 `GameRoute<T>(builder)`(= `PageRouteBuilder` 상속, `transitionDuration: GameMotion.of(context).base`)로 바꾼다. `main.dart`의 `routes:` 맵은 `onGenerateRoute`로 바꿔 같은 라우트 클래스를 쓴다.
- 감소 모션이면 `transitionDuration == Duration.zero`라 자동으로 즉시 전환.
- `PageTransitionsTheme(builders: {TargetPlatform.android: ..., iOS: ..., windows/linux/macOS: ...})`에 같은 빌더를 전 플랫폼 등록(웹·데스크톱 실행 시 일관성).

### 2. 로딩·오류 E-11

`BootstrapLoadingPage`: 상단에 `LinearProgressIndicator(minHeight: 2)`(테마가 색 지정), 중앙에 앱 이름(title 스케일) + `'사전 데이터를 준비하는 중입니다…'`(body, inkMuted). 원형 스피너 제거. 배경 `surface`라 스플래시(`#FFFFFF`/`#121212`)와 이어진다.
`BootstrapErrorPage`: UI-GUIDE 4절 "빈 상태·오류" — 아이콘 없이 heading `'앱을 시작할 수 없습니다.'` + body 오류 메시지 + caption `'앱을 삭제 후 재설치해 주세요.'`. 문구 유지(`shell_test` "실패: 예외 시 에러 화면 + 메시지").
`PuzzlePage` 로딩 상태(퍼즐 생성 중)도 같은 선형 표시로. `HomePage` 로딩도 동일. `CircularProgressIndicator`는 `lib/ui`에서 전부 제거한다 — 5곳이다(`bootstrap_pages.dart:19`, `home_page.dart:74`, `puzzle_page.dart:93`, `license_page.dart:32`, `settings_page.dart:336`). 벤치마크 화면에는 없다(이미 `LinearProgressIndicator`).

### 3. 설정 화면

구획과 항목(문구는 기존 유지, 순서만 정리):

| 구획 | 항목 | 위젯 |
|---|---|---|
| 화면 | 테마: 시스템 / 라이트 / 다크 | `SegmentedButton<ThemeMode>` (pill, 07-02 테마) → `settings.setThemeMode` |
| 화면 | 효과음 | `SwitchListTile` `'효과음'`, 기본 꺼짐 → `settings.setSoundEnabled` |
| 힌트 | 뜻풀이 / 연상어 (기존 `RadioListTile` 2개, 문구 유지) | 기존 |
| 단어 데이터 | 버전·단어 수·빌드 시각·마지막 갱신·지금 갱신·Wi-Fi에서만 갱신 (기존 순서 그대로) | 기존 위젯, 스타일만 |
| 정보 | `'출처 및 라이선스'`(INV-06b), 오픈소스 라이선스, 앱 버전 (기존) | 기존 |

`_SectionHeader`는 `lib/ui/common/section_header.dart`로 빼고 label 스케일 + `inkMuted`. `ListTile`은 유지해도 되지만 `dense`, 구분선은 `line` 1px.

`SettingsModel`에 `bool soundEnabled = false`, 키 `soundEnabled`, `setSoundEnabled()`.

### 4. 효과음 S-01

`puzzle_page.dart`의 셀 탭 처리에서 H-01 옆에:
```dart
if (context.read<SettingsModel>().soundEnabled) SystemSound.play(SystemSoundType.click);
```
외부 패키지 없음(INV-11). Android에서 `click`은 시스템 터치음 설정을 따른다 — 시스템 터치음이 꺼진 기기에서는 안 들릴 수 있음을 설정 항목 `subtitle`에 한 줄로 적는다(`'기기의 터치음 설정을 따릅니다'`).

### 5. 라이선스 화면

`SelectableText`에 body 스케일 + `ink`, 패딩 16, 최대 폭 560. 그 외 변경 없음(N-08).

### 6. 벤치마크 화면

`Colors.*` 없음은 07-01이 처리했다. 여기서는 `GameColors` 참조로 바꾸고 텍스트 스케일만 맞춘다. 구조·문구는 그대로(임시 화면, 03-05).

### 7. 스낵바 위치

`HomePage`·`SettingsPage`의 `ScaffoldMessenger.showSnackBar` 호출은 그대로 두고 07-02 `snackBarTheme`이 모양을 준다. `floating` 동작이 하단 버튼과 겹치면 `margin` 조정.

## 막히면

- **`PageTransitionsBuilder`로 지속 시간 제어가 안 됨** → 위 설계대로 라우트 클래스에서 `transitionDuration`을 정한다. 테마의 빌더는 "모양", 라우트는 "시간".
- **`onGenerateRoute` 전환 후 `shell_test` 라우트 테스트 실패** → 테스트가 `routes` 맵 키를 직접 읽는다면, `buildRoutes()` 함수는 남겨 두고 `onGenerateRoute`가 그 맵을 참조한다.
- **`SegmentedButton` 스타일이 Material 기본** → `segmentedButtonTheme`을 07-02 `app_theme.dart`에 추가(pill, 선택 = `ink` 배경 `surface` 글자).
- **`SystemSound.play` 테스트에서 채널이 안 잡힘** → `SystemChannels.platform` 메서드명 `SystemSound.play`, 인자 `SystemSoundType.click`.
- **웹에서 `SystemSound`가 예외** → try/catch 없이도 no-op이다. 예외면 `kIsWeb` 분기.
