## 작업

### 1. `SettingsModel.themeMode`

```dart
const _keyThemeMode = 'themeMode';   // 값은 ThemeMode.name ('system' | 'light' | 'dark')

class SettingsModel extends ChangeNotifier {
  ThemeMode themeMode = ThemeMode.system;
  // …

  Future<void> load() async {
    // … 기존 읽기 뒤에
    final savedTheme = prefs.getString(_keyThemeMode);
    themeMode = ThemeMode.values.firstWhere(
      (m) => m.name == savedTheme,
      orElse: () => ThemeMode.system,
    );
    loading = false;
    notifyListeners();
  }

  Future<void> setThemeMode(ThemeMode mode) async {
    if (mode == themeMode) return;
    themeMode = mode;
    notifyListeners();
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString(_keyThemeMode, mode.name);
  }
}
```

`ThemeMode`는 `package:flutter/material.dart`에 있다. 이 파일은 지금 `foundation.dart`만 import하므로 import를 바꾼다.

### 2. `main.dart` 연결

`MultiProvider`의 자식을 `Consumer<SettingsModel>`로 감싸 `themeMode`만 전달한다.

```dart
child: Consumer<SettingsModel>(
  builder: (_, settings, __) => MaterialApp(
    title: _title,
    theme: buildLightTheme(),
    darkTheme: buildDarkTheme(),
    themeMode: settings.themeMode,
    initialRoute: '/',
    routes: buildRoutes(),
  ),
),
```

부트스트랩 로딩·에러 분기의 `MaterialApp` 2개는 아직 `SettingsModel`이 없는 트리라 `themeMode`를 넣지 않는다(시스템 기본).

### 4. 대비 계산 함수 (테스트 파일 안에 그대로 둔다)

```dart
import 'dart:math';
import 'dart:ui' show Color;

double _lum(Color c) {
  double ch(double s) =>
      s <= 0.03928 ? s / 12.92 : pow((s + 0.055) / 1.055, 2.4).toDouble();
  return 0.2126 * ch(c.r) + 0.7152 * ch(c.g) + 0.0722 * ch(c.b);
}

double contrast(Color a, Color b) {
  final l1 = _lum(a), l2 = _lum(b);
  return (max(l1, l2) + 0.05) / (min(l1, l2) + 0.05);
}
```

`Color.r`/`.g`/`.b`는 이미 0.0~1.0이라 **255로 나누지 않는다.**

검사할 8쌍(UI-GUIDE 2.3 그대로). 테스트 안에서는 `(이름, 전경, 배경, 최소)` 레코드 목록으로 두고 라이트·다크 두 `GameColors`에 같은 목록을 돌린다.

| 전경 / 배경 | 최소 |
|---|---|
| `ink` / `surface` | 7.0 |
| `inkMuted` / `surface` | 4.5 |
| `inkMuted` / `surfaceAlt` | 4.5 |
| `cellInk` / `cellFill` | 7.0 |
| `cellInk` / `accentSoft` | 4.5 |
| `cellInkOnAccent` / `accent` | 4.5 |
| `surface` / `ink` | 7.0 |
| `inkMuted` / `cellFill` | 3.0 |

현재 토큰 값으로 16개(8쌍 × 2테마)가 전부 통과한다. 여유가 가장 적은 곳은 **라이트 `inkMuted`/`surfaceAlt` = 4.67**(기준 4.5)이다. 이 두 색을 건드리는 변경은 이 테스트가 먼저 잡는다.

## 막히면

- **`c.red`/`c.green`/`c.blue`를 쓰라는 예제(부모 문서 포함)** → 이 저장소의 Flutter 3.47 / Dart 3.13.3(`pubspec.yaml` `sdk: ^3.13.3`)에서 셋 다 `@Deprecated`다. `flutter analyze`는 info도 실패로 세므로 그대로 쓰면 DoD의 "analyze 0"이 깨진다. 위 골격대로 `.r`/`.g`/`.b`(0.0~1.0 double)를 쓴다. `Color.value`도 같은 이유로 쓰지 않는다.
- **대비 쌍이 실패한다** → 값부터 바꾸지 말고 계산 함수를 의심한다(255로 나눴는지, `pow` 지수가 2.4인지). 진짜 미달이면 UI-GUIDE 2.2 해당 열과 `tokens.dart`를 **같은 커밋에서** 고친다.
- **`expect(ext, same(GameColors.light))` 실패** → `GameColors`에 `==`가 없다. `ext!.ink`, `ext.accent`처럼 필드로 비교해도 된다.
- **9번에서 `SettingsModel().load()`가 pump 전에 안 끝난다** → `JGameApp`이 `create: (_) => SettingsModel()..load()`로 만든다. `await tester.pumpAndSettle()` 뒤에 읽고, 저장값은 pump **전에** `SharedPreferences.setMockInitialValues({'themeMode': 'dark'})`로 세운다.
- **`MediaQueryData(disableAnimations: true)`가 무시된다** → `MaterialApp`이 자체 `MediaQuery`를 다시 씌운 것이다. `MediaQuery`를 `MaterialApp` **안쪽**(`home:` 아래)에 두거나, `tester.platformDispatcher.accessibilityFeaturesTestValue`를 쓰지 말고 위젯 트리로 감싼다.
