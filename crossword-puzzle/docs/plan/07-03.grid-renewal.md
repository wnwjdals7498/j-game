`GridPainter`를 NYT 격자로 바꾼다. **검정 1px 격자선, 노랑 커서 셀, 하늘색 선택 단어, 코어 셀 원형 마크**, 그리고 셀 채움 팝(E-01)·선택 이동(E-02)·커서 등장(E-03) 세 가지 모션. 탭 → 셀 변환, `shouldRepaint` 규율, 정답 미노출, 모양 구분 원칙은 그대로다.

## `GridPainter` 시그니처

```dart
class GridPainter extends CustomPainter {
  final Puzzle puzzle;
  final Map<(int, int), String> answers;
  final PlacedWord? selected;
  final (int, int)? focusedCell;
  final SubmitResult? result;
  final GameColors colors;          // ColorScheme → GameColors
  final double cell;
  /// E-02: 선택 하이라이트의 현재 사각형(격자 좌표 px). null이면 selected.cells만 칠한다.
  final Rect? selectionRect;
  /// E-03: 커서 셀 알파 0..1
  final double cursorOpacity;
  /// E-01: 셀별 팝 진행 0..1. 없는 셀은 1(정지 상태)로 취급.
  final Map<(int, int), double> pop;

  @override
  bool shouldRepaint(GridPainter old) =>
      old.puzzle != puzzle || old.selected != selected || old.focusedCell != focusedCell ||
      old.result != result || old.selectionRect != selectionRect ||
      old.cursorOpacity != cursorOpacity || old.cell != cell ||
      !mapEquals(old.answers, answers) || !mapEquals(old.pop, pop);
}
```

E-01 스케일: `scale = 0.7 + 0.3 * curvePop.transform(p)` — 곡선은 위젯이 이미 적용해 `pop`에 넣으므로 페인터는 `0.7 + 0.3 * p`만 한다(페인터는 시간을 모른다). `canvas.save(); translate(center); scale(s); translate(-center); drawText; restore()`.

## `PuzzleGridView` (StatefulWidget)

컨트롤러 3개, 전부 `GameMotion.of(context)` 토큰만 쓴다(INV-12).

| 컨트롤러 | 트리거(`didUpdateWidget`) | 지속 | 결과 |
|---|---|---|---|
| `_pop` (여러 셀 동시) | `answers`에서 값이 **비어 있다가 채워진** 셀 집합 | `fast` / `curvePop` | 그 셀들의 `pop[cell] = value`. 끝나면 맵에서 제거 |
| `_selection` | `selected`가 바뀜(둘 다 non-null일 때만) | `fast` / `curveStandard` | `selectionRect = Rect.lerp(prevBounds, newBounds, t)`. 끝나면 null로 (정지 시엔 `selected.cells` 정확 채움) |
| `_cursor` | `focusedCell`이 바뀜 | `instant` | `cursorOpacity 0→1` |

규칙:
- 지속 시간이 `Duration.zero`(감소 모션)면 컨트롤러를 시작하지 않고 **최종 상태를 즉시** 반영한다(`pop` 비움, `selectionRect = null`, `cursorOpacity = 1`).
- 값이 바뀌지 않은 프레임에서는 `shouldRepaint`가 false여야 한다. `pop` 맵은 애니메이션 중에만 non-empty다.
- 셀 채움이 **지워지는** 경우(백스페이스)는 팝을 하지 않는다.
- 첫 빌드(`initState`)에서는 어떤 애니메이션도 돌지 않는다(다시 풀기로 `answers`가 비워질 때도 마찬가지).
- `cellForOffset`과 `onTapDown` 처리는 그대로.

레이아웃 계산(`side = maxWidth.clamp(0, maxHeight)`)은 유지한다. 격자 외곽 2px 선이 잘리지 않게 `CustomPaint` 바깥에 `Padding(1)`을 두거나 페인터가 안쪽으로 1px 들여 그린다.

## 테스트 `test/ui/grid_view_test.dart`

기존 7종은 이름 그대로 유지한다(INV-08). `ColorScheme` 대신 `GameColors.light`를 넘기는 부분만 고친다. 추가:

| 테스트 | 기대 |
|---|---|
| 커서 셀 변경 시 repaint | `focusedCell` 다르면 `shouldRepaint` true |
| `pop` 변경 시 repaint | 맵 내용 다르면 true, 같은 내용 새 인스턴스면 false |
| `selectionRect` 변경 시 repaint | true |
| E-01 시작: 빈 셀 → 채움 | `answers` 갱신 후 `pump()` 1프레임: 위젯 상태의 `pop`에 그 셀 존재, 값 < 1 |
| E-01 종료 | `pump(motion.fast)` 후 `pop` 비어 있음 |
| E-01 미발동: 지우기 | 채움 → 빈칸으로 바꿔도 `pop` 비어 있음 |
| E-02 보간 | `selected` A→B 교체 후 `pump(fast/2)`: `selectionRect`가 A·B 바운딩의 사이값. `pump(fast)` 후 null |
| 감소 모션 | `MediaQueryData(disableAnimations: true)` 아래에서 채움 직후 `pop` 비어 있고 `cursorOpacity == 1` |
| 코어 원 그리기 | `GridPainter.paint`를 `MockCanvas` 없이 검증하기 어렵다 → 대신 `paint`를 `PictureRecorder`로 실행해 예외 없이 끝나는지 + 코어 셀 수만큼 `drawCircle`이 호출되는지는 **간이 Canvas 래퍼**(`Canvas`를 상속하지 않고 `paint`가 받는 인터페이스를 좁혀 `_GridCanvas`로 추상화)로 카운트한다. 추상화가 과하면 이 항목은 07-08 골든으로 미룬다 |

위젯 상태의 `pop`·`selectionRect`·`cursorOpacity`는 테스트에서 읽어야 하므로 `@visibleForTesting` getter로 노출한다.

## 막히면

- **`Rect.lerp` 중간 사각형이 검은 칸까지 덮음** → 층 2를 그릴 때 각 셀별로 `rect.overlaps(cellRect) && !blocked`인 셀만 채운다. "보간 사각형과 겹치는 비검은 셀 채움"이 정의다. 그래도 어색하면 E-02를 **알파 크로스페이드**(이전 단어 셀 페이드아웃 + 새 단어 셀 페이드인)로 바꾸고 UI-GUIDE E-02 설명을 고친다.
- **팝 중 텍스트가 셀 밖으로 나감** → `curvePop`(`easeOutBack`) 오버슈트가 1.1까지 간다. `scale = 0.7 + 0.3 * p`에서 p가 1.1이면 1.03 — 셀 55% 크기 글자라 여유가 있다. 잘리면 `canvas.clipRect(cellRect)`.
- **입력할 때마다 전체가 다시 그려져 버벅임** → 애니메이션 프레임마다 재그리기는 정상이다(`fast` 150ms 동안만). 정지 후에도 계속 그려지면 `pop` 맵을 비우는 리스너가 빠졌다.
- **`didUpdateWidget`에서 이전 `answers`와 비교가 안 됨** → `PuzzleModel.setWordInput`이 새 맵을 만든다(04-02 규약, 테스트 "answers 새 맵"). `oldWidget.answers`와 `widget.answers`를 셀 단위로 비교하면 된다.
- **커서 셀이 선택 단어 밖** → `focusedCell`은 항상 `selected.cells` 안이어야 한다(`PuzzleModel.selectCell`). 아니면 모델 버그다. 그려도 되지만 우선 로그로 확인.
- **다크에서 코어 원이 안 보임** → `cellCoreMark` `#8A8A8A`는 `cellFill #1E1E1E` 위에서 대비 3.5 정도다. 굵기를 1.5로 올리되 색은 바꾸지 않는다.
