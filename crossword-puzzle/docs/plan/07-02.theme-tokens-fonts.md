### 1. `tokens.dart`

```dart
@immutable
class GameColors extends ThemeExtension<GameColors> {
  final Color surface, surfaceAlt, ink, inkMuted, line, accent, accentSoft,
      success, danger, gridLine, cellFill, cellBlocked, cellCoreMark, cellInk, cellInkOnAccent;
  const GameColors({required this.surface, /* … 전부 required */});

  static const light = GameColors(
    surface: Color(0xFFFFFFFF), surfaceAlt: Color(0xFFF5F5F3), ink: Color(0xFF121212),
    inkMuted: Color(0xFF6E6E6E), line: Color(0xFFDEDEDE), accent: Color(0xFFFFDA00),
    accentSoft: Color(0xFFA7D8FF), success: Color(0xFF1B7F3B), danger: Color(0xFFC62828),
    gridLine: Color(0xFF121212), cellFill: Color(0xFFFFFFFF), cellBlocked: Color(0xFF121212),
    cellCoreMark: Color(0xFF8A8A8A), cellInk: Color(0xFF121212), cellInkOnAccent: Color(0xFF121212),
  );
  static const dark = GameColors(/* UI-GUIDE 2.2 다크 열 */);

  static GameColors of(BuildContext context) => Theme.of(context).extension<GameColors>()!;

  @override GameColors copyWith({...}) => ...;
  @override GameColors lerp(GameColors? other, double t) => ...;  // 테마 전환 애니메이션용, Color.lerp 전 필드
}

abstract final class GameSpace { static const xs = 4.0, s = 8.0, m = 12.0, l = 16.0, xl = 24.0, xxl = 32.0; }
abstract final class GameRadius { static const cell = 0.0, panel = 12.0, pill = 999.0; }
abstract final class GameType {
  static const family = 'Pretendard';
  static const display = TextStyle(fontFamily: family, fontSize: 34, fontWeight: FontWeight.w700, height: 1.1);
  // title, heading, body, label(letterSpacing: 0.4), caption — UI-GUIDE 2.4 표 그대로
  static TextStyle cellSyllable(double cell) => TextStyle(fontFamily: family, fontSize: cell * 0.55, fontWeight: FontWeight.w600, height: 1.0);
  static TextStyle cellNumber(double cell) => TextStyle(fontFamily: family, fontSize: cell * 0.22, fontWeight: FontWeight.w600, height: 1.0);
}
```

`Color(0x…)` 리터럴은 **이 파일에만** 존재한다(INV-05의 `exclude: lib/ui/theme/`).

### 2. `motion.dart`

```dart
@immutable
class GameMotion extends ThemeExtension<GameMotion> {
  final Duration instant, fast, base, slow, celebrate;
  final Curve curveStandard, curveEmphasized, curvePop;
  const GameMotion({...});

  static const standard = GameMotion(
    instant: Duration(milliseconds: 80), fast: Duration(milliseconds: 150),
    base: Duration(milliseconds: 240), slow: Duration(milliseconds: 400),
    celebrate: Duration(milliseconds: 900),
    curveStandard: Curves.easeOutCubic, curveEmphasized: Curves.easeInOutCubicEmphasized,
    curvePop: Curves.easeOutBack,
  );
  static const none = GameMotion(instant: Duration.zero, /* 전부 zero, 곡선은 linear */);

  /// 감소 모션이면 [none]. 화면 코드는 반드시 이걸 통해서만 Duration을 얻는다 (INV-12).
  static GameMotion of(BuildContext context) =>
      MediaQuery.disableAnimationsOf(context)
          ? none
          : Theme.of(context).extension<GameMotion>() ?? standard;
}
```

`Duration(milliseconds:` 리터럴도 **이 파일에만** 존재한다(INV-12).

### 3. `app_theme.dart`

```dart
ThemeData buildLightTheme() => _build(GameColors.light, Brightness.light);
ThemeData buildDarkTheme()  => _build(GameColors.dark,  Brightness.dark);

ThemeData _build(GameColors c, Brightness b) {
  final scheme = ColorScheme(
    brightness: b,
    primary: c.ink, onPrimary: c.surface,
    secondary: c.accentSoft, onSecondary: c.ink,
    secondaryContainer: c.accentSoft, onSecondaryContainer: c.cellInk,
    tertiary: c.accent, onTertiary: c.cellInkOnAccent,
    error: c.danger, onError: c.surface,
    surface: c.surface, onSurface: c.ink,
    onSurfaceVariant: c.inkMuted, outline: c.line, outlineVariant: c.line,
    surfaceContainerHighest: c.surfaceAlt, surfaceContainerHigh: c.surfaceAlt,
    // 나머지 필수 필드는 위 값들 중 가장 가까운 것으로 채운다
  );
  return ThemeData(
    useMaterial3: true, colorScheme: scheme, fontFamily: GameType.family,
    scaffoldBackgroundColor: c.surface,
    textTheme: TextTheme(displaySmall: GameType.display, titleLarge: GameType.title,
        titleMedium: GameType.heading, bodyLarge: GameType.body, bodyMedium: GameType.body,
        labelLarge: GameType.label, bodySmall: GameType.caption).apply(bodyColor: c.ink, displayColor: c.ink),
    appBarTheme: AppBarTheme(backgroundColor: c.surface, foregroundColor: c.ink, elevation: 0,
        scrolledUnderElevation: 0, centerTitle: false, titleTextStyle: GameType.title.copyWith(color: c.ink)),
    filledButtonTheme: /* 높이 52, pill, ink 배경, surface 글자 700 — UI-GUIDE 2.5 버튼 규격 */,
    outlinedButtonTheme: /* 높이 52, pill, line 1.5 테두리, ink 글자 600 */,
    dividerTheme: DividerThemeData(color: c.line, thickness: 1, space: 1),
    snackBarTheme: SnackBarThemeData(backgroundColor: c.ink, contentTextStyle: GameType.body.copyWith(color: c.surface),
        shape: const StadiumBorder(), behavior: SnackBarBehavior.floating),
    bottomSheetTheme: BottomSheetThemeData(backgroundColor: c.surface, shape: RoundedRectangleBorder(
        borderRadius: BorderRadius.vertical(top: Radius.circular(GameRadius.panel)))),
    inputDecorationTheme: /* 밑줄 없음, 채움 없음, 텍스트 title 스케일 — 07-04가 힌트 바 안에 넣는다 */,
    progressIndicatorTheme: ProgressIndicatorThemeData(color: c.ink, linearMinHeight: 2),
    extensions: [c, GameMotion.standard],
  );
}
```

### 4. 폰트 번들

1. Pretendard 공식 릴리스에서 static OTF 3종을 받아 `app/assets/fonts/`에 둔다(Regular, SemiBold, Bold).
2. `pubspec.yaml`:
   ```yaml
   fonts:
     - family: Pretendard
       fonts:
         - asset: assets/fonts/Pretendard-Regular.otf
           weight: 400
         - asset: assets/fonts/Pretendard-SemiBold.otf
           weight: 600
         - asset: assets/fonts/Pretendard-Bold.otf
           weight: 700
   ```
3. `docs/LICENSES.md`에 "글꼴 — Pretendard (SIL Open Font License 1.1)" 절을 추가하고 OFL 전문 링크와 저작권 고지를 넣는다. `app/assets/LICENSES.md`도 같은 내용으로 맞춘다 — `_sync_licenses()`는 `python -m tools build`의 `build_sqlite` 단계 안에서만 돌고, 그 단계는 git이 추적하는 9.8MB `app/assets/words.sqlite`를 다시 만든다. 폰트 커밋에 DB 바이너리 diff를 딸려 보내지 않으려면 이 커밋에서는 파일을 직접 복사하고 `Compare-Object`로 동일성을 확인한다. 04-06 테스트 "4개 자료명이 전부 보임 + assets/LICENSES.md와 동일한 문구"는 `docs/`를 보지 않고 `app/assets/LICENSES.md`와 화면 문구만 비교하므로, **`docs/`만 고치면 테스트는 통과한 채 두 파일이 조용히 갈라진다.** 두 파일 동일성은 검증 절의 `Compare-Object`로 확인한다.
4. 용량이 5MB를 넘으면 07-ui-v2 리스크대로 Noto Sans KR 400/700 두 종으로 교체하고 `GameType.family`만 바꾼다.

### 7. 화면 코드 최소 수정

이 문서에서 화면은 **컴파일이 유지되는 범위만** 손댄다: `GridPainter`가 받는 `ColorScheme colors`는 그대로 둔다(07-03이 교체). 07-01에서 `colorScheme.tertiary`로 바꿔 둔 별 색은 새 스킴에서 `accent`(노랑)가 되어 의도와 맞는다.

## 테스트 `test/ui/theme_test.dart`

| 테스트 | 기대 |
|---|---|
| 두 테마에 `GameColors` 존재 (INV-13) | `buildLightTheme().extension<GameColors>()`·다크 둘 다 non-null, 값이 `GameColors.light`/`dark`와 동일 |
| 두 테마에 `GameMotion` 존재 (INV-13) | non-null, `standard`와 동일 |
| 대비 계약 8쌍 × 2테마 (INV-14) | UI-GUIDE 2.3 표. 테스트 파일 안에 WCAG 상대 휘도·대비 계산 함수를 직접 구현(외부 패키지 없음). 실패 메시지에 쌍 이름·실측 비율 포함 |
| `ColorScheme` 매핑 | `primary == ink`, `onPrimary == surface`, `error == danger`, `tertiary == accent` |
| 폰트 패밀리 | `theme.textTheme.bodyLarge!.fontFamily == 'Pretendard'` |
| 감소 모션 | `MediaQuery(data: MediaQueryData(disableAnimations: true))` 아래에서 `GameMotion.of(context).fast == Duration.zero` |
| 정상 모션 | `disableAnimations: false` → `fast == 150ms` |
| `SettingsModel.themeMode` 저장 | `SharedPreferences.setMockInitialValues` → `setThemeMode(dark)` → 새 모델 `load()` 후 `dark` |
| `MaterialApp` 연결 | `themeMode`가 `SettingsModel` 값을 따른다 (`tester.widget<MaterialApp>`) |

대비 계산 참고식(테스트 파일에 그대로 둔다):

```dart
double _lum(Color c) {
  double ch(int v) { final s = v / 255; return s <= 0.03928 ? s / 12.92 : pow((s + 0.055) / 1.055, 2.4).toDouble(); }
  return 0.2126 * ch(c.red) + 0.7152 * ch(c.green) + 0.0722 * ch(c.blue);
}
double contrast(Color a, Color b) { final l1 = _lum(a), l2 = _lum(b); return (max(l1, l2) + 0.05) / (min(l1, l2) + 0.05); }
```

## 막히면

- **`ColorScheme` 생성자가 요구하는 필드가 많음** → `ColorScheme.fromSeed(seedColor: c.ink, brightness: b).copyWith(...)`로 시작해 UI-GUIDE 매핑 필드만 덮어쓴다. 단 `copyWith` 뒤 `primary`·`surface`·`error` 등이 정확히 토큰 값인지 테스트로 확인한다.
- **다크에서 `accentSoft` 위 글자 대비가 4.5 미만** → 값을 바꾸지 말고 먼저 계산 함수를 의심한다(`Color.red` 등이 0~255인지). 진짜 미달이면 UI-GUIDE 2.2 다크 열을 고치고(예: `#2B5C8A` → `#255079`) 표와 코드를 같은 커밋에서 바꾼다.
- **위젯 테스트에서 폰트가 안 보임(글자가 사각형)** → 정상. 테스트 환경은 Ahem 폰트를 쓴다. 골든이 필요한 07-08에서 `FontLoader`로 해결한다.
- **기존 테스트가 `Colors.indigo` 계열 색을 기대** → 그런 테스트는 없어야 한다. 있으면 토큰 참조로 바꾼다.
- **`flutter_native_splash`의 `color: "#FFFFFF"`·`color_dark: "#121212"`** → 새 `surface` 값과 이미 같다. 건드리지 않는다.
