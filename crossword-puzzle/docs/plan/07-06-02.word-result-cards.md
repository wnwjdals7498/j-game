```dart
class WordResultCard extends StatelessWidget {
  final WordResult wordResult;
  final int? number;
  final Hint? hint;
  final Animation<double> animation;   // E-07 구간 애니메이션. 항상 부모가 준다
  const WordResultCard({super.key, required this.wordResult, required this.number,
      required this.hint, required this.animation});

  @override
  Widget build(BuildContext context) {
    final c = GameColors.of(context);
    final (icon, color) = switch (wordResult.outcome) {
      WordOutcome.correct => (Icons.check_circle, c.success),
      WordOutcome.wrong => (Icons.cancel, c.danger),
      WordOutcome.blank => (Icons.radio_button_unchecked, c.inkMuted),
    };
    return FadeTransition(
      opacity: animation,
      child: AnimatedBuilder(
        animation: animation,
        builder: (_, child) => Transform.translate(
            offset: Offset(0, _riseDp * (1 - animation.value)), child: child),
        child: Padding(
          padding: const EdgeInsets.symmetric(
              horizontal: GameSpace.l, vertical: GameSpace.m),
          child: Row(crossAxisAlignment: CrossAxisAlignment.start, children: [
            Icon(icon, color: color, size: _iconSize),
            const SizedBox(width: GameSpace.m),
            // 제목 Text.rich(라벨 GameType.label · 표제어 GameType.heading · 입력 inkMuted),
            // 뜻풀이 GameType.body/ink, 유의어 GameType.caption/inkMuted 를
            // 담은 Expanded(Column). TextSpan 구조는 기존 `_WordRow` 그대로.
          ]),
        ),
      ),
    );
  }
}
```

`_riseDp = 8`(UI-GUIDE 3.3 E-07 "8dp 상승"), `_iconSize = 20`. 둘 다 이 파일의 `const`다.

### 3. `ResultPage` → `StatefulWidget` + E-07 컨트롤러 1개

행마다 컨트롤러를 만들지 않는다. **페이지가 컨트롤러 하나**(길이 `motion.slow`)를 갖고 행은 구간만 잘라 쓴다.

```dart
class _ResultPageState extends State<ResultPage> with SingleTickerProviderStateMixin {
  late final AnimationController _rows = AnimationController(vsync: this);
  bool _started = false;

  @override
  void didChangeDependencies() {          // GameMotion.of는 context가 필요해 initState에서 못 쓴다
    super.didChangeDependencies();
    final motion = GameMotion.of(context);
    _rows.duration = motion.slow;
    if (!_started && widget.result != null) { _started = true; _rows.forward(); }
  }

  @override
  void dispose() { _rows.dispose(); super.dispose(); }
}
```

`ResultPage`의 생성자·props는 그대로다. `submit_test.dart`가 `PuzzleModel` 없이 pump하는 계약이 유지된다.

### 4. 행 구간 계산

UI-GUIDE 3.3 E-07: 행당 `fast`, 행 간격 40ms, 총 `slow`(400ms) 상한.

```dart
const double _gapCapMs = 40;   // UI-GUIDE 3.3 E-07 "행마다 40ms 간격"

Animation<double> _rowAnimation(GameMotion motion, int i, int rows) {
  final slowMs = motion.slow.inMilliseconds.toDouble();
  if (slowMs == 0) return kAlwaysCompleteAnimation;   // 감소 모션: 아래 나눗셈이 전부 0/0
  final fastMs = motion.fast.inMilliseconds.toDouble();
  final gap = min(_gapCapMs, (slowMs - fastMs) / max(rows - 1, 1));
  final begin = (i * gap) / slowMs;
  final end = ((i * gap) + fastMs) / slowMs;
  return CurvedAnimation(
      parent: _rows,
      curve: Interval(begin.clamp(0, 1), end.clamp(0, 1), curve: motion.curveStandard));
}
```

| 행 수 | gap | 마지막 행 구간 | 총 길이 |
|---|---|---|---|
| 1 | 40ms | 0 ~ 0.375 | 150ms |
| 3 | 40ms | 0.200 ~ 0.575 | 230ms |
| 7 | 40ms | 0.600 ~ 0.975 | 390ms |
| 12 | 22.7ms | 0.625 ~ 1.000 | **400ms** |

**감소 모션 함정**: `motion.slow`가 `Duration.zero`면 `gap`도 `begin`도 `end`도 0이 되어 `Interval(0, 0).transform(1)`이 `0/0 = NaN`을 낸다. 위 코드처럼 `kAlwaysCompleteAnimation`으로 빠져나가야 한다. 컨트롤러도 `duration: Duration.zero`라 `forward()`가 즉시 끝난다.

## 막히면

- **행 opacity가 `NaN`** → 감소 모션에서 `Interval(0, 0)`을 만들었다. 4절의 `slowMs == 0` 분기를 넣는다.
- **`pumpAndSettle` 타임아웃** → 컨트롤러를 `repeat()`했다. E-07은 `forward()` 한 번이다(UI-GUIDE 1절 "반복 애니메이션 없음").
- **`find.textContaining('입력: 바나다')`가 못 찾음** → `Text.rich`를 `RichText`로 바꿨다. 되돌린다.
- **정렬 테스트의 y좌표가 뒤집힘** → `pumpAndSettle()` 없이 읽어 8dp 상승 중이었다. 6절대로 `pumpAndSettle()`을 앞에 둔다.
- **행마다 컨트롤러를 만들고 싶어짐** → 하지 않는다. 12행이면 12개 티커가 돈다. 구간(`Interval`)만 나눈다.
