## 작업

### 1. `GameMotion` — UI-GUIDE 3.1 그대로

| 토큰 | 값 | 용도(3.1) |
|---|---|---|
| `instant` | 80ms | 커서 셀 이동, 버튼 눌림 |
| `fast` | 150ms | 선택 하이라이트 이동, 배지 교체 |
| `base` | 240ms | 화면 전환, 힌트 크로스페이드, 버튼 색 전환 |
| `slow` | 400ms | 결과 행 순차 등장 총 길이 |
| `celebrate` | 900ms | 점수 카운트업, 레벨 해제 연출 |
| `curveStandard` | `Curves.easeOutCubic` | 대부분 |
| `curveEmphasized` | `Curves.easeInOutCubicEmphasized` | 화면 전환 |
| `curvePop` | `Curves.easeOutBack` | 셀 채움 팝 |

```dart
// lib/ui/theme/motion.dart
//
// UI-GUIDE.md 3.1·3.2. `Duration(milliseconds: …)` 리터럴은 이 파일에만 있다(INV-12).
import 'package:flutter/material.dart';

@immutable
class GameMotion extends ThemeExtension<GameMotion> {
  final Duration instant, fast, base, slow, celebrate;
  final Curve curveStandard, curveEmphasized, curvePop;

  const GameMotion({
    required this.instant, required this.fast, required this.base,
    required this.slow, required this.celebrate,
    required this.curveStandard, required this.curveEmphasized, required this.curvePop,
  });

  static const standard = GameMotion(
    instant: Duration(milliseconds: 80),
    fast: Duration(milliseconds: 150),
    base: Duration(milliseconds: 240),
    slow: Duration(milliseconds: 400),
    celebrate: Duration(milliseconds: 900),
    curveStandard: Curves.easeOutCubic,
    curveEmphasized: Curves.easeInOutCubicEmphasized,
    curvePop: Curves.easeOutBack,
  );

  /// 감소 모션용. 시간은 전부 0, 곡선은 `Curves.linear`
  /// (시간이 0이면 곡선은 결과에 영향이 없지만, 곡선만 쓰는 호출부가
  /// null을 받지 않도록 값을 채워 둔다).
  static const none = GameMotion(
    instant: Duration.zero, fast: Duration.zero, base: Duration.zero,
    slow: Duration.zero, celebrate: Duration.zero,
    curveStandard: Curves.linear, curveEmphasized: Curves.linear, curvePop: Curves.linear,
  );

  /// 화면 코드는 **반드시** 이 함수로만 Duration을 얻는다 (UI-GUIDE 3.2, INV-12).
  static GameMotion of(BuildContext context) =>
      MediaQuery.disableAnimationsOf(context)
          ? none
          : Theme.of(context).extension<GameMotion>() ?? standard;

  @override
  GameMotion copyWith({Duration? instant, /* … 8개 전부 nullable */}) => GameMotion(...);

  @override
  GameMotion lerp(GameMotion? other, double t) => t < 0.5 ? this : (other ?? this);
}
```

`lerp`는 시간·곡선을 섞으면 의미가 없으므로 **중간에서 끊어 바꾼다.** 색(`GameColors`)과 달리 보간하지 않는다.

`Theme.of(context).extension<GameMotion>()`이 null인 경우(테마에 확장을 안 넣은 `MaterialApp`, 예: `shell_test`의 에러·로딩 화면)를 위해 `?? standard` 폴백을 남긴다.

### 2. INV-12 규칙 추가

`tool/invariants/rules.dart`의 `const rules` 목록 끝(INV-11 다음)에 한 줄을 넣는다.

```dart
  Rule('INV-12', '모션 토큰 강제', Kind.mustNotContain,
      paths: ['lib/ui'], exclude: ['lib/ui/theme/'], needles: ['Duration(milliseconds']),
```

UI-GUIDE 7절 표의 INV-12 행("`lib/ui/**`(단 `theme/**` 제외)에 `Duration(milliseconds` 리터럴 없음", 도입 07-02)과 1:1이다. 표는 이미 이 내용을 담고 있으므로 **UI-GUIDE는 수정하지 않는다.**

지금 저장소의 `lib/ui/**`에는 `Duration(milliseconds`가 하나도 없다. 규칙을 넣은 직후 곧바로 PASS여야 한다.

### 3. 아직 연결하지 않는다

`GameMotion`을 `ThemeData.extensions`에 넣는 것은 07-02-03이다. 이 커밋에서도 화면 코드는 그대로다.

## 막히면

- **`MediaQuery.disableAnimationsOf`가 없다** → Flutter 3.10 이전 API다. 이 저장소는 3.47이므로 존재한다. 그래도 못 찾으면 `MediaQuery.of(context).disableAnimations`로 쓴다(리빌드 범위만 넓어진다).
- **INV-12가 `motion.dart`를 잡는다** → `exclude`가 `lib/ui/theme/`(끝 슬래시 포함)인지, 실행기가 접두 비교를 경로 구분자 `/`로 정규화하는지 확인한다(Windows `\` 그대로면 안 맞는다).
- **`ThemeExtension.lerp`가 곡선을 요구** → `Curve`는 `lerp` 대상이 아니다. 위처럼 `t < 0.5` 스위치로 통째 교체하면 된다.
- **테스트에서 `GameMotion.of`가 `null!` 예외** → `Theme.of(context).extension<GameMotion>()`이 null인 트리다. `?? standard` 폴백이 빠졌는지 본다.
