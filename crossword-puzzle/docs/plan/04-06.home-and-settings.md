## 홈 화면

```
┌─────────────────────────────┐
│ 단어 연상 퀴즈          ⚙    │
├─────────────────────────────┤
│  누적 정답률  68%            │
│  푼 단어  1,234개            │
├─────────────────────────────┤
│  1  첫걸음      ★ +6         │
│  2  둘레길      ★ +4         │
│  3  갈림길      ─            │   ← 해제됐으나 미클리어
│  4  어스름      🔒           │   ← 잠금
│  ...                        │
└─────────────────────────────┘
```

| 요소 | 내용 | 출처 |
|---|---|---|
| 누적 통계 | 정답률, 푼 단어 수 | `StatRepository.summary()` (03-04) |
| 레벨 목록 | `levels`(01-09/03-06) 전체 | |
| 클리어 표시 | `bestScore(id) >= clearScore` → ★ + 점수 | `StatRepository.bestScore` |
| 잠금 | 이전 레벨 미클리어 | 03-06 해제 규칙 |
| 레벨 1 | **항상 해제** | |

탭 → 퍼즐 화면(`/play`)으로 새 seed와 함께 이동. 잠긴 레벨은 탭해도 무반응 + 스낵바 안내.

```dart
class HomeModel extends ChangeNotifier {
  final AppScope scope;
  List<LevelStatus> statuses = [];
  ({int correct, int wrong, int words})? summary;

  Future<void> load() async {
    summary = await scope.stats.summary();
    final out = <LevelStatus>[];
    var prevCleared = true;                  // 레벨 1은 항상 해제
    for (final spec in levels) {
      final best = await scope.stats.bestScore(spec.id);
      final cleared = best != null && best >= spec.clearScore;
      out.add(LevelStatus(spec, unlocked: prevCleared,
                          cleared: cleared, bestScore: best));
      prevCleared = cleared;
    }
    statuses = out;
    notifyListeners();
  }
}
```

**레벨마다 DB 조회 1회** → 12회. 홈 진입마다 도는 건 낭비다.
`bestScore` 를 한 번에 가져오는 쿼리로 바꾼다:

```sql
SELECT level_id, MAX(first_score) AS best FROM puzzle_log GROUP BY level_id
```

### 설정 저장

## 출처 및 라이선스 화면 — **필수**

> 설정·정보 화면에 4개 자료 출처와 라이선스 문구(`docs/LICENSES.md`와 동일) 노출 (DoD 4번)

### 내용의 출처

`meta.license_notice`(02-09)에 들어 있다. DB가 갱신되면 문구도 따라 바뀐다.

**긴 전문은 앱에 번들한다.** `docs/LICENSES.md` 를 `app/assets/LICENSES.md` 로 복사해
asset으로 읽어 표시한다. `meta.license_notice` 는 요약이다.

```dart
Future<String> loadLicenseText() =>
    rootBundle.loadString('assets/LICENSES.md');
```

`pubspec.yaml` 의 `assets:` 에 추가한다.

**복사를 자동화한다** — 두 파일이 갈라지면 의무 위반이다.

```python
# tools/sync_licenses.py 또는 build_sqlite.py 안에서
shutil.copy(ROOT / "docs" / "LICENSES.md", APP_ASSETS / "LICENSES.md")
```

### 표시 요건

CC BY-SA 2.0 KR 표기 의무:

| 항목 | 필수 |
|---|---|
| 저작자(국립국어원) | ✓ |
| 저작물 제목(한국어기초사전 등) | ✓ |
| 라이선스 이름과 링크 | ✓ |
| 변경 사실 | ✓ (표제어 필터링, 뜻풀이 축약, 난이도 부여) |
| 파생물도 동일 라이선스 | ✓ |

공공누리 1유형(빈도조사, 학습용 어휘)은 출처 표시만 하면 된다.

**마크다운 렌더링**: `flutter_markdown` 을 쓰거나, 간단히 `SelectableText` 로 원문을 보여준다.
1차는 `SelectableText` 로 충분하다. 의존성이 하나 준다.

링크는 탭 가능해야 하므로 `url_launcher` 가 필요하다. 링크를 텍스트로만 두고
복사 가능하게 하면(`SelectableText`) 의존성 없이 의무를 충족한다. **1차는 그렇게 한다.**

## 막히면

- **`LICENSES.md` 가 두 곳에서 갈라짐** → 복사를 `python -m tools build` 에 넣어 강제한다. CI(06-06)에 두 파일 비교 검사를 추가해도 좋다.
- **레벨 해제가 꼬임** → `prevCleared` 초기값이 `true`(레벨 1 해제)인지 확인. 중간 레벨을 건너뛰고 클리어하는 경로가 없어야 한다.
- **홈 진입이 느림** → 레벨마다 쿼리를 도는 N+1이다. 위 `GROUP BY` 쿼리로 바꾼다.
- **라이선스 문구를 어떻게 써야 할지 모르겠음** → 00-01에서 각 사이트가 요구한 **표기 원문을 그대로** 쓴다. 창작하지 않는다.
- **`flutter_markdown` 을 쓰고 싶음** → 써도 되지만 의존성이 는다. 1차는 `SelectableText` 로 충분하다.
