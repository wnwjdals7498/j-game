## 목표

앱의 모든 화면 이동을 E-09 페이드 스루 하나로 통일한다. **모양은 `PageTransitionsTheme`이, 시간은 `GameRoute`가** 정한다 — `PageTransitionsBuilder`는 지속 시간을 정할 수 없기 때문이다.
이 문서가 끝나면 `lib/`에 `MaterialPageRoute(`가 0건이고 전환 시간이 `GameMotion.base`(240ms), 감소 모션에서 0이다.

## 작업

### 1. `fade_through_route.dart` — 모양과 시간

`lib/ui/theme/` 안이므로 구간·스케일 상수를 여기 둬도 INV-05·INV-12에 걸리지 않는다. `0.3`(페이드 구간)·`0.98`(2% 스케일)은 UI-GUIDE 3.3 E-09 행과 상위 문서가 정한 값이고 새 값이 아니다.

```dart
class FadeThroughPageTransitionsBuilder extends PageTransitionsBuilder {
  const FadeThroughPageTransitionsBuilder();

  @override
  Widget buildTransitions<T>(PageRoute<T>? route, BuildContext context,
      Animation<double> animation, Animation<double> secondaryAnimation, Widget child) {
    return FadeTransition(                      // 나가는 화면: 0~0.3 구간에 1→0
      opacity: Tween<double>(begin: 1, end: 0).animate(
        CurvedAnimation(parent: secondaryAnimation, curve: const Interval(0.0, 0.3))),
      child: FadeTransition(                    // 들어오는 화면: 0.3~1.0 구간에 0→1
        opacity: CurvedAnimation(parent: animation, curve: const Interval(0.3, 1.0)),
        child: ScaleTransition(                 // + 2% 스케일, curveEmphasized
          scale: Tween<double>(begin: 0.98, end: 1.0).animate(CurvedAnimation(
              parent: animation, curve: GameMotion.of(context).curveEmphasized)),
          child: child)),
    );
  }
}

class GameRoute<T> extends PageRouteBuilder<T> {
  GameRoute({required WidgetBuilder builder, super.settings})
      : super(pageBuilder: (context, _, __) => builder(context));

  /// `navigator`는 `install()` 직전에 채워지고 `transitionDuration`은 그 뒤에
  /// 읽힌다. 라우트를 만드는 `onGenerateRoute`에는 context가 없으므로 늦게
  /// 읽는다 — 그래야 감소 모션이 `Duration.zero`로 내려온다.
  @override
  Duration get transitionDuration {
    final nav = navigator;
    return nav == null ? GameMotion.standard.base : GameMotion.of(nav.context).base;
  }
  @override
  Duration get reverseTransitionDuration => transitionDuration;
  @override
  Widget buildTransitions(BuildContext context, Animation<double> a,
          Animation<double> b, Widget child) =>
      const FadeThroughPageTransitionsBuilder()
          .buildTransitions<T>(this, context, a, b, child);
}
```

### 2. `app_theme.dart`에 등록

`_build()`의 `ThemeData(...)`에 `pageTransitionsTheme: const PageTransitionsTheme(builders: {...})` 한 항목을 더하고, `TargetPlatform`의 `android`·`iOS`·`windows`·`linux`·`macOS`·`fuchsia` 6개 전부를 `FadeThroughPageTransitionsBuilder()`로 채운다(웹·데스크톱에서도 같은 전환). `const` 컬렉션에는 `for`를 못 쓰므로 6줄을 손으로 적는다.

### 3. `main.dart` — `routes:` → `onGenerateRoute`

`buildRoutes()`는 **지우지 않는다.** `shell_test`가 이 맵을 본다.

```dart
/// `buildRoutes()`의 빌더를 E-09 지속 시간을 갖는 [GameRoute]로 감싼다.
Route<dynamic>? onGenerateGameRoute(RouteSettings settings) {
  final builder = buildRoutes()[settings.name];
  return builder == null ? null : GameRoute<void>(builder: builder, settings: settings);
}
```

`MaterialApp`에서 `routes: buildRoutes(),`를 지우고 `onGenerateRoute: onGenerateGameRoute,`로 바꾼다. `initialRoute: '/'`는 그대로다.
`routes:`를 남겨두면 `WidgetsApp`이 그 맵을 먼저 보고 `MaterialPageRoute`를 만들어 `onGenerateRoute`가 아예 안 불린다 — 둘을 같이 두면 안 된다.

## 막히면

- **`transitionDuration`에서 `navigator`가 null** → `install()` 전에 읽힌 것이다. `GameMotion.standard.base` 폴백이 덮는다. "시간은 라우트가, 모양은 테마가" 분리를 깨면 감소 모션이 죽으므로 되돌리지 않는다.
- **감소 모션 테스트에서 시간이 안 줄어듦** → `MaterialApp`이 `MediaQuery.fromView`로 자기 `MediaQuery`를 새로 만들어 바깥에서 감싼 것은 안 먹는다. `tester.binding.platformDispatcher.accessibilityFeaturesTestValue`를 쓰고 `addTearDown`으로 `clearAccessibilityFeaturesTestValue()` 한다. 그래도 안 되면 `MaterialApp(builder:)` 안에서 `MediaQuery`를 덮는다 — `builder`는 `Navigator`의 조상이다.
- **`onGenerateRoute`로 바꾼 뒤 `initialRoute`가 안 뜸** → `buildRoutes()`에 `'/'` 키가 있는지 확인한다(`null`을 돌려주면 검은 화면).
- **`Select-String -Recurse`가 없다는 오류** → 그런 파라미터는 없다. 검증 절처럼 `Get-ChildItem -Recurse … | Select-String`으로 파이프한다.
