## 목표

결과 화면을 **"점수 한 번 크게, 축하 한 번 짧게, 복기는 차분하게"**로 만든다. 헤더에 점수가 카운트업되고 정답 링이 채워진다. 첫 제출로 레벨이 열렸을 때만 헤더 위에 사각 조각이 1회 떨어진다. 단어 목록은 순서대로 떠오른다.

`ResultPage`는 지금처럼 **순수 표시 위젯**으로 남는다(`submit_test.dart`가 `PuzzleModel` 없이 pump한다). 애니메이션 상태는 위젯 내부 컨트롤러다.

## 작업

### 1. `ScoreHeader` (E-06)

```dart
class ScoreHeader extends StatelessWidget {
  final int score, correct, total; final bool justUnlocked; final int? unlockedLevelId; final bool isFirstSubmit;
  // TweenAnimationBuilder<double>(tween: 0→1, duration: motion.celebrate, curve: motion.curveStandard)
  //   점수 텍스트: (score * t).round() — 음수 점수도 0에서 score로 (‘-3’은 0 → -3)
  //   링: CustomPaint(_RingPainter(progress: (correct/total) * t))
}
```

점수 문자열 형식은 현재와 같이 `'+12'`/`'-3'`(0이면 `'0'`; 현재 코드 `'${score >= 0 ? '+' : ''}$score'`가 0을 `'+0'`으로 찍는다면 그대로 유지 — 테스트가 그 문구를 찾을 수 있다). `'5 / 7 정답'` 문구도 현재 형식 유지(`'${result.correctCount} / ${result.total} 정답'`). 두 문구는 `submit_test`가 찾을 가능성이 높으므로 **애니메이션 종료 후** 정확히 그 문자열이어야 하고, 테스트는 `pumpAndSettle()` 뒤에 확인한다. `total == 0`이면 링 진행 0.

### 2. `WordResultCard` (E-07)

`ListTile`을 카드형 행으로. 아이콘·색은 현재 매핑 유지(INV-04b). 정렬(번호순)은 현재 로직 유지. E-07: 각 행을 `AnimatedOpacity` + `AnimatedSlide`가 아니라 **단일 `AnimationController`(길이 `motion.slow`)**를 페이지가 갖고, 행 i는 `Interval(i*gap, i*gap + fast/slow)`로 구간을 나눈다. `gap = min(40ms, (slow - fast) / max(rows-1, 1))` → 행이 많아도 총 400ms. 감소 모션이면 컨트롤러 `value = 1`로 시작.

### 3. `UnlockBurst` (E-08)

`justUnlocked`일 때만 헤더 `Stack` 위에 얹는다. 자체 `CustomPainter`:
- 조각 24개, 크기 6×10 사각형, 색은 `ink`/`accent`/`accentSoft`를 8개씩.
- 시드 고정 `Random(42)`로 초기 x(0~폭), 낙하 속도, 회전 속도, 지연(0~0.2)을 만든다 → **결정적**(골든·테스트 가능).
- 진행 t(0→1, `motion.celebrate`, `curveStandard`)에서 y = -20 + t × (헤더 높이 + 40), 알파는 t > 0.7부터 0으로.
- 끝나면 위젯이 스스로 `SizedBox.shrink()`로 바뀐다(`shouldRepaint`는 t 변경 시만).
- **1회만.** `ResultPage`가 다시 빌드돼도 재생하지 않는다(컨트롤러 `forward()`는 `initState`에서 한 번).

해제 문구 `'레벨 N이 열렸습니다'`는 현재 형식 유지, `accent` 배경 알약 배지 + `cellInkOnAccent` 글자(label) — 다크에서 `ink`(#F2F2F2)를 `accent`(#E5C400) 위에 올리면 대비가 무너진다. UI-GUIDE 2.3이 검증하는 쌍도 `cellInkOnAccent / accent`다.

### 4. 버튼

보조 `'다시 풀기'` / 기본 `'다음 레벨'`(마지막이면 `'홈으로'`). 현재 `OutlinedButton`/`FilledButton` 유지 — 07-02 테마가 모양을 준다.

## 막히면

- **`TweenAnimationBuilder`가 첫 프레임에 이미 종료값** → `pump()`만으로는 진행 안 됨이 정상. 테스트는 `pump(Duration)`을 명시한다. 반대로 위젯이 처음부터 종료값이면 `tween`의 `begin`이 `end`와 같다.
- **`pumpAndSettle` 타임아웃** → 반복 애니메이션이 있다. UI-GUIDE 1절 "반복 애니메이션 없음". `UnlockBurst`가 종료 후 컨트롤러를 `dispose`·`stop` 하는지 확인.
- **골든에서 E-08 조각 위치가 매번 다름** → `Random(42)` 시드를 안 썼다. `Random()` 금지.
- **점수 카운트업이 정수 반올림 때문에 마지막에 튐** → `(score * curve(t)).round()`에서 t=1이면 정확히 score. 곡선이 1을 넘는 `easeOutBack`을 쓰지 않는다(E-06은 `curveStandard`).
- **`Stack` 위 `UnlockBurst`가 터치를 가로챔** → `IgnorePointer`로 감싼다.
