## 해석

전 레벨 실패율 100.00%다. **이건 알고리즘 회귀가 아니다.** `tools/fixtures/` 16단어
표본은 티어당 단어가 1~4개뿐이라(`docs/reports/02-db-report.md` 참고), 레벨 1(코어
티어2×2 + 채움 티어1 최소 2개)조차 서로 다른 표제어로 할당량을 채울 조합이 거의
없다 — `test/data/word_repository_test.dart`의 "1단계 생성기 연동" 케이스가 같은
이유로 스킵되는 것과 동일한 구조적 한계다. 평균 시도/되감기/질의가 전부 0.0인 것도
`coreCandidates` 단계에서 즉시 후보 부족으로 실패해 `Filler`까지 못 가기 때문이다.

이 실행으로 확인한 것은 딱 하나, **배선**이다: `tool/measure_real.dart` →
`DriftWordRepository` → `AppDatabase`(drift) → 임시 복사본 SQLite → `MeasureRunner`
→ `docs/reports/03-real-failure.md` 렌더까지 예외 없이 끝까지 돈다. `origin=fixtures`
자동 판정도 정확히 걸려 DoD 게이트(`exit(1)`)를 스스로 건너뛰었다.

**실패율·p50/p95 숫자로 03-05/03-06 DoD를 판정하지 않는다.** 00-01 승인 후 실데이터로
`app/assets/words.sqlite`가 재빌드되면 `dart run tool/measure_real.dart`를 다시 돌려
이 리포트를 교체한다.
