# drone-simulator

> 상태: 계획 단계. Unity 프로젝트 구현·검증 전.

`j-game` 안의 독립적인 Windows용 Unity 드론 조종 시뮬레이터다. Xbox 컨트롤러를 기본 입력으로 사용하고, 컨트롤러가 없으면 키보드·마우스로 조작한다. 처음 배우기 쉬운 게임형 조작감을 목표로 한다.

## 계획한 기능

- 상승·하강, 전후·좌우 이동, 회전과 카메라 조작
- 지상 인물이 드론을 바라보는 시점과 드론을 따라가는 3인칭 시점. 레이스 중 버튼으로 전환
- 충돌 처리, 재시작, 코스와 체크포인트
- 이륙 후 체크포인트를 순서대로 통과하고 착륙하면 완료. 완료 시간으로 해당 PC의 로컬 순위를 산정하고 충돌에 시간 페널티 적용

온라인 순위표는 만들지 않는다. 입력 매핑, 코스 수, 페널티 시간, 체크포인트 위반 처리, 에셋 조달과 배포 방식은 아직 정하지 않았다.

[단계별 계획](docs/plan.md)을 따라 구현 상태가 바뀌면 이 README를 갱신한다.
