# Unity 드론 조종 시뮬레이터 계획

## 목표와 경계

Windows에서 Xbox 컨트롤러 또는 키보드·마우스로 드론을 조종하고, 두 시점을 전환하며 로컬 레이스 기록을 남긴다. 정밀 비행 훈련보다 처음 배우기 쉬운 게임형 조작감을 목표로 한다. 온라인 순위표는 범위에서 제외한다.

## 단계

1. Unity 버전, 입력 장치 지원 범위, 에셋 이용 조건과 Windows 실행 환경을 확인한다.
2. 상승·하강, 전후·좌우 이동, 회전, 카메라 조작의 최소 프로토타입을 만든다. Xbox 입력과 키보드·마우스 대체 입력을 검증한다.
3. 지상 시점과 드론을 따라가는 3인칭 시점을 구현하고 레이스 중 전환을 검증한다.
4. 충돌 처리·재시작, 이륙·체크포인트·착륙 구간을 만든다. 순서 위반 처리와 코스 수는 이 단계 전에 결정한다.
5. 레이스 완료 시간을 계산하고 충돌 시간 페널티를 적용한다. 순위는 해당 PC에 로컬로 저장한다.
6. 조작 테스트를 바탕으로 물리값과 보정 방식을 조정한다. Xbox와 대체 입력, 두 시점, 기록 저장·재실행을 검증한다.

## 완료 확인

- Xbox 컨트롤러와 키보드·마우스로 필수 조작을 수행할 수 있다.
- 레이스 중 두 시점을 전환하고 지정된 체크포인트를 순서대로 통과해 착륙할 수 있다.
- 충돌 페널티가 완료 시간에 반영되고 로컬 순위가 재실행 뒤에도 유지된다.

## 이후 결정

입력 매핑, 컨트롤러 지원 범위, 코스 수·난이도, 페널티 시간, 체크포인트 위반 처리, 물리값, 에셋과 배포 방식은 해당 단계 전에 결정한다.
