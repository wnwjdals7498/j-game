## 결정: 상태 관리

> ChangeNotifier + Provider 또는 Riverpod 중 하나. 화면 4개 규모라 어느 쪽이든 무방. **결정 후 이 문서에 기록.**

**권고: `ChangeNotifier` + `provider`.**

- 화면 4개, 상태 객체 3개 규모다. Riverpod의 코드 생성·프로바이더 계층이 과하다.
- Flutter 기본 개념(`ChangeNotifier`, `InheritedWidget`)만 알면 읽힌다.
- DB·리포지토리는 앱 시작 시 1회 생성해 트리 루트에 주입하면 끝이다.

**결정 확정 후 이 문서 상단에 한 줄로 못 박는다.** 뒤에서 흔들리면 04-02~04-06이 전부 꼬인다.

```yaml
dependencies:
  provider: ^6.1.0
```

## 상태 객체

```
app/lib/ui/state/
├─ app_scope.dart        DB·리포지토리 보관 (ChangeNotifier 아님. 그냥 주입)
├─ settings_model.dart   힌트 모드, Wi-Fi 전용 갱신 등
├─ home_model.dart       레벨 목록 + 해제 상태 + 누적 통계
└─ puzzle_model.dart     퍼즐 1판의 전체 상태 ← 04-02~04-05의 중심
```

### `app_scope.dart`

```dart
/// 앱 전역 의존성. main에서 1회 만들어 트리 루트에 Provider로 넣는다.
class AppScope {
  final AppDatabase db;
  final WordRepository words;
  final StatRepository stats;
  final GridGenerator generator;

  const AppScope({
    required this.db,
    required this.words,
    required this.stats,
    required this.generator,
  });
}
```

### `puzzle_model.dart` — 뼈대만 (내용은 04-02~04-05)

```dart
class PuzzleModel extends ChangeNotifier {
  final AppScope scope;
  final LevelSpec spec;

  Puzzle? puzzle;
  bool loading = true;
  Object? error;

  /// 격자 셀 → 유저 입력 음절. 단일 진실 (01-08 Answers와 같은 타입)
  final Map<(int, int), String> answers = {};

  /// 현재 선택된 단어. null이면 미선택
  PlacedWord? selected;

  bool submitted = false;
  SubmitResult? result;

  PuzzleModel(this.scope, this.spec);

  Future<void> load(int seed) async {
    loading = true;
    error = null;
    notifyListeners();
    try {
      puzzle = await scope.generator.generate(spec, seed);
    } catch (e) {
      error = e;
    } finally {
      loading = false;
      notifyListeners();
    }
  }
}
```

**`answers` 가 셀 좌표 맵인 이유**는 01-08에 적혀 있다. 교차 셀에서 마지막 입력이 이기려면
격자 셀이 단일 진실이어야 한다. 단어별 입력 버퍼를 따로 두지 않는다.

## `main.dart`

```dart
Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();

  final db = await DbBootstrap.open();          // 03-02
  final scope = AppScope(
    db: db,
    words: DriftWordRepository(db),
    stats: StatRepository(db),
    generator: GridGenerator(DriftWordRepository(db)),
  );

  runApp(MultiProvider(
    providers: [
      Provider.value(value: scope),
      ChangeNotifierProvider(create: (_) => SettingsModel()..load()),
    ],
    child: const JGameApp(),
  ));
}
```

### 시작 화면 · 실패 처리

`DbBootstrap.open()` 이 10MB 복사를 하므로 첫 실행은 수 초 걸린다.
`runApp` 전에 `await` 하면 **흰 화면**이 보인다. 두 방법:

1. 네이티브 스플래시 화면을 길게 (06-01에서 설정)
2. `runApp` 을 먼저 하고 `FutureBuilder` 로 로딩 화면 표시

**2번을 쓴다.** 로딩 진행과 실패를 사용자에게 보여줄 수 있다.

```dart
class JGameApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) => MaterialApp(
        title: '단어 연상 퀴즈',
        theme: ThemeData(useMaterial3: true, colorSchemeSeed: Colors.indigo),
        home: FutureBuilder<AppScope>(
          future: _bootstrap,
          builder: (c, s) {
            if (s.hasError) return BootstrapErrorPage(error: s.error!);
            if (!s.hasData) return const BootstrapLoadingPage();
            return const HomePage();
          },
        ),
        routes: { ... },
      );
}
```

`BootstrapErrorPage` 는 `SchemaMismatch`, `EmptyDatabase`(03-02)를 사람이 읽을 수 있는
메시지로 보여준다. "앱을 삭제 후 재설치해 주세요" 수준이면 충분하다.

`app/test/ui/shell_test.dart`

| 테스트 | 기대 |
|---|---|
| 부트스트랩 로딩 | Future 미완료 시 로딩 화면 |
| 부트스트랩 실패 | 예외 시 에러 화면 + 메시지 |
| 부트스트랩 성공 | 홈 화면 표시 |
| 라우트 등록 | 4개 라우트가 전부 정의됨 |
| `PuzzleModel.load` 성공 | `puzzle != null`, `loading == false` |
| `PuzzleModel.load` 실패 | `GenerationFailed` → `error != null`, 크래시 없음 |
| `notifyListeners` | 로드 전후로 리스너 호출 |

`AppScope` 를 가짜 구현(`InMemoryWordRepository` + 인메모리 DB)으로 주입해 위젯 테스트를 돌린다.
실 DB를 쓰면 테스트가 느리고 환경에 의존한다.

## 막히면

- **`DbBootstrap.open()` 이 위젯 테스트에서 실패** → 테스트에서는 `AppScope` 를 직접 주입하고 부트스트랩을 건너뛴다. 부트스트랩 자체는 03-02에서 테스트했다.
- **Provider 주입이 화면에서 안 보임** → `MultiProvider` 가 `MaterialApp` **바깥**에 있어야 라우트로 이동한 화면에서도 보인다.
- **첫 실행이 너무 느림** → 10MB 복사다. 로딩 화면에 진행 표시를 넣는다. 실제로 줄이려면 DB 용량을 줄여야 한다(02-09).
- **Riverpod을 쓰고 싶음** → 써도 된다. 단 **여기서 결정하고 이 문서에 기록**한 뒤 04-02 이후 전부 같은 방식으로 간다. 중간에 바꾸지 않는다.
