# 00-06. 검증 빌드 · 첫 커밋

담당: **MIXED** (빌드는 AGENT, 실기기·브라우저 눈 확인은 HUMAN)
선행: 00-02, 00-03, 00-04, 00-05 · 다음: 1단계(01-01) / 2단계(02-01) 병행 착수
상위: [00-env-setup.md](00-env-setup.md) F절

## 목표

"이 PC에서 앱이 기기와 브라우저에서 돈다"를 **실제 실행으로** 증명하고 첫 커밋을 남긴다.
여기까지 되면 이후 단계는 전부 이 PC 안에서 끝난다.

## 작업

### 1. 기기 확인

```powershell
flutter devices
```

기대: 안드로이드 기기(또는 에뮬레이터) 1개 + `Chrome` 이 목록에 있음.

### 2. 안드로이드 실행 — HUMAN 눈 확인 필요

```powershell
flutter run -d <기기ID>
```

기대: 기기에 기본 카운터 앱이 뜨고 `+` 버튼으로 숫자가 증가한다.
**첫 빌드는 Gradle 의존성 다운로드로 10분 이상 걸릴 수 있다. 정상이다.**
확인 후 터미널에서 `q` 로 종료.

### 3. 디버그 APK 빌드

```powershell
flutter build apk --debug
Test-Path app/build/app/outputs/flutter-apk/app-debug.apk
```

기대: 두 번째 명령이 `True`.

### 4. 웹 실행 — HUMAN 눈 확인 필요

```powershell
flutter run -d chrome
```

기대: Chrome에 같은 카운터 앱이 뜨고 동작한다. 확인 후 `q`.

### 5. Dart 테스트

`flutter create` 가 만든 `app/test/widget_test.dart` 를 그대로 둔다.

```powershell
flutter test
```

기대: 통과.

### 6. Python 테스트

```powershell
tools\.venv\Scripts\python.exe -m pytest tools -q
```

기대: `1 passed`

### 7. 첫 커밋

커밋 전 비밀·대용량이 안 들어가는지 확인한다:

```powershell
git add -A
git status --short
```

`tools/.venv`, `tools/raw`, `tools/build`, `app/build`, `*.keystore` 가 스테이징에 **없어야** 한다.
하나라도 보이면 커밋하지 말고 `.gitignore`(00-05 4번)를 고친 뒤 `git rm -r --cached <경로>` 로 뺀다.

커밋 메시지:

```
chore: 프로젝트 골격 및 개발 환경 구축

- Flutter 앱 스켈레톤 (domain/data/ui 계층 분리)
- Python ETL venv 및 tools 기본 구조
- 기획 문서 (DESIGN, REVIEW, PLAN, plan/*)
- .gitignore: 원본 데이터·빌드 산출물·서명 키 제외

Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>
```

## DoD (= 0단계 전체 DoD)

- [x] `flutter doctor` 경고 0 (Android toolchain 기준. Visual Studio 경고는 android/web 타깃 무관이라 무시)
- [x] 안드로이드 기기/에뮬레이터에 디버그 APK 설치·실행됨 (Pixel_10 에뮬레이터, 카운터 탭 증가 사람이 직접 확인)
- [x] 같은 코드가 Chrome에서 실행됨 (web-server + 헤드리스 브라우저로 렌더링·탭 증가 확인, 콘솔 에러 0)
- [x] `flutter test`, `python -m pytest tools` 둘 다 통과
- [x] 데이터 이용 신청 4건 접수 이상 (00-01) — 4건 모두 원본 파일 수령 완료, `tools/raw/`
- [x] 첫 커밋 완료, 저장소에 비밀·대용량 없음

비고: `android/app/build.gradle.kts`의 `ndkVersion = flutter.ndkVersion`을 제거했으나 Flutter Gradle
플러그인이 내부적으로 기본값(28.2.13676358)을 강제 적용해 동작에 차이 없음. 최초 빌드 시 해당 NDK가
없어 Gradle이 `sdkmanager.bat`로 자동 설치를 시도했는데 신규 Android CLI 래퍼 버그로 크래시(exit
0xC0000409, "ndk;28.2.13676358"를 세미콜론 기준으로 잘못 분리) → `android.exe sdk install
"ndk;28.2.13676358"`로 수동 설치(2.2GB)해서 우회함.

## 막히면

- **Gradle `Unsupported class file major version`** → JDK 불일치. 00-03의 `flutter config --jdk-dir` 재확인.
- **Gradle 의존성 다운로드 실패** → 회사망 프록시. `%USERPROFILE%\.gradle\gradle.properties` 에 프록시 설정 추가.
- **`flutter run -d chrome` 흰 화면** → `flutter clean` 후 재시도.
- **커밋에 `app/build/` 포함됨** → `flutter create` 가 만든 `app/.gitignore` 확인. 없으면 루트 `.gitignore` 에 `app/build/` 추가.
