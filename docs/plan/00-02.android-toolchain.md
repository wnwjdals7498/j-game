# 00-02. 안드로이드 툴체인

담당: **HUMAN** (설치 프로그램 GUI, 라이선스 동의, 기기 USB 연결이 필요)
선행: 없음 (00-01과 병행) · 다음: 00-03
상위: [00-env-setup.md](00-env-setup.md) B절

## 현재 상태 (2026-09-16 점검, REVIEW.md 3절)

- 없음: Android Studio, Android SDK, adb, JDK
- 있음: JRE 21 — **JDK가 아니다. Gradle 빌드 불가.**

## 작업

### 1. 디스크 확인

Android Studio + SDK + Flutter 합쳐 **10GB 이상**. 설치 드라이브 여유 확인.

### 2. Android Studio 설치

- https://developer.android.com/studio 에서 Windows 설치본.
- 설치 마법사 "Standard" 선택 → Android SDK, Platform-Tools(adb), 에뮬레이터, **동봉 JDK(jbr)** 가 함께 설치된다.
- 설치 경로를 기록해 둔다 (기본: `C:\Program Files\Android\Android Studio`).

### 3. SDK Manager

Android Studio → More Actions → SDK Manager:

- **SDK Platforms**: 최신 안정 API 레벨 1개 (체크)
- **SDK Tools**: `Android SDK Build-Tools`, `Android SDK Command-line Tools (latest)`, `Android SDK Platform-Tools`, `Android Emulator` (전부 체크)

`Command-line Tools` 를 빠뜨리면 `flutter doctor --android-licenses` 가 실패한다. 반드시 체크.

### 4. 환경변수

시스템 환경변수에 추가 (경로는 SDK Manager 상단에 표시된 실제 경로로):

```
ANDROID_HOME = C:\Users\<사용자>\AppData\Local\Android\Sdk
PATH        += %ANDROID_HOME%\platform-tools
```

설정 후 **새 터미널**을 열어야 반영된다.

### 5. 테스트 기기 (둘 중 하나, 실기기 권장)

**실기기 (권장 — 3단계 성능 측정에 필요)**
1. 설정 → 휴대전화 정보 → 빌드번호 7회 탭 → 개발자 옵션 활성화
2. 개발자 옵션 → **USB 디버깅** 켜기
3. USB로 PC 연결 → 기기에 뜨는 "USB 디버깅 허용" 승인

**에뮬레이터**
- Android Studio → Device Manager → Create Device → 적당한 폰 프로필 + 최신 시스템 이미지

## 검증

새 터미널(PowerShell)에서:

```powershell
adb version
adb devices
```

기대: `adb version` 이 버전 출력. `adb devices` 목록에 기기 1개가 `device` 상태로 표시.
`unauthorized` 면 기기 화면의 USB 디버깅 허용 팝업을 승인한다.

```powershell
echo $env:ANDROID_HOME
```
기대: SDK 경로 출력 (빈 값이면 4번 재확인 + 터미널 재시작).

## 산출물

- Android Studio 설치됨
- `ANDROID_HOME` 설정, `adb` 가 PATH에 있음
- 기기 1개가 `adb devices` 에 잡힘
- 동봉 JDK 경로 확보: `<Android Studio 경로>\jbr` — 00-03에서 사용

## 막히면

- **기기가 `adb devices` 에 안 뜸** → 제조사 USB 드라이버 설치 (삼성은 Samsung USB Driver). 케이블이 충전 전용이면 데이터 케이블로 교체.
- **`adb` 명령 없음** → PATH 반영 안 됨. 터미널 재시작. 그래도 안 되면 절대경로 `%ANDROID_HOME%\platform-tools\adb.exe` 로 확인.
- **회사 네트워크/프록시** → SDK 다운로드가 막힐 수 있다. Android Studio 프록시 설정(Appearance & Behavior → System Settings → HTTP Proxy)에 입력.
