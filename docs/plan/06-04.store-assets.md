### 스크린샷 찍기

```powershell
adb shell screencap -p /sdcard/shot.png
adb pull /sdcard/shot.png ./store/screenshots/01-puzzle.png
```

찍을 화면:

1. **퍼즐 화면** (격자에 글자가 채워진 상태 + 힌트 표시) ← 가장 중요
2. 결과 화면 (정답/오답이 섞인 상태)
3. 홈 화면 (레벨 목록)
4. 설정 화면 또는 힌트 모드 비교

**주의**: 스크린샷에 개발용 데이터나 디버그 UI(03-05 벤치마크 화면)가 보이면 안 된다.
릴리스 빌드로 찍는다.

### 피처 그래픽

1024×500에 앱 이름 + 격자 이미지. 텍스트는 중앙에 크게 (작은 썸네일로도 표시된다).

## C. 개인정보 처리방침 — 필수

> 수집 데이터 없음(통계는 기기 내부만, 네트워크는 DB 다운로드만).
> 한 페이지 정적 문서로 GitHub Pages 등에 게시.

Play는 **공개 URL**을 요구한다. 앱 안 화면으로는 안 된다.

`docs/privacy.md` 를 만들고 GitHub Pages로 게시한다:

```markdown
# 개인정보 처리방침

최종 수정일: YYYY-MM-DD

## 수집하는 개인정보

본 앱은 개인정보를 **수집하지 않습니다.**

## 기기에 저장되는 정보

학습 기록(단어별 정답·오답 횟수, 푼 퍼즐 목록)이 기기 내부에만 저장됩니다.
이 정보는 외부로 전송되지 않으며, 앱을 삭제하면 함께 삭제됩니다.

## 네트워크 사용

약 6개월 주기로 단어 데이터를 내려받기 위해 GitHub(github.com)에 접속합니다.
이때 전송되는 개인정보는 없습니다.

## 제3자 제공

없습니다.

## 광고 · 분석 도구

사용하지 않습니다.

## 문의

<이메일 주소>
```

GitHub Pages 설정:

```
저장소 Settings → Pages → Source: Deploy from a branch → main / docs
→ https://<계정>.github.io/<저장소>/privacy
```

**URL이 실제로 열리는지 확인한 뒤** Play Console에 넣는다.

## D. Play Console 양식

### 데이터 보안 (Data safety) — 필수

| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유합니까? | **아니요** |
| 데이터가 전송 중 암호화됩니까? | 해당 없음 (수집 없음) |
| 사용자가 데이터 삭제를 요청할 수 있습니까? | 해당 없음 |

"수집 없음"으로 작성하면 대부분의 문항이 생략된다.
**거짓 신고는 앱 정지 사유**다. 광고 SDK나 분석 도구를 나중에 넣으면 이 양식을 갱신해야 한다.

### 콘텐츠 등급 설문

폭력·성적 내용·약물 등 전부 "없음". 결과는 전체 이용가가 나온다.

**주의**: 사전에서 온 단어라 비속어·성적 표현이 섞일 수 있다(02-10).
`blocklist.txt` 로 걸렀는지 확인하고, 자신이 없으면 등급 설문에서 보수적으로 답한다.

### 그 외 필수 항목

- [ ] 앱 카테고리: 게임 → 단어 게임 (또는 교육)
- [ ] 태그
- [ ] 연락처 이메일
- [ ] 대상 연령층
- [ ] 광고 포함 여부: **아니요**
- [ ] 정부 앱 여부: 아니요
- [ ] COVID-19 앱 여부: 아니요

## G. 공개 출시 일정 리스크

> Play Console 신규 개발자 계정은 등록 후 **14일 이상 20명 비공개 테스트** 요건이 있을 수 있다
> (정책 변동). 배포 일정에 반영.

2023년 이후 개인 개발자 계정에 적용되는 요건이다. **정책이 바뀔 수 있으니 Play Console의
현재 안내를 직접 확인한다.**

해당된다면:

1. 비공개 테스트 트랙 생성
2. 테스터 20명 모집 (이메일 또는 Google 그룹)
3. 14일 이상 연속 테스트 유지
4. 이후 "프로덕션 출시 신청" 이 열린다

**내부 테스트는 이 요건에 포함되지 않을 수 있다.** 비공개 테스트가 필요한지 확인한다.

## 막히면

- **개인정보 처리방침 URL이 404** → GitHub Pages 반영에 몇 분 걸린다. `docs/` 폴더에 `.nojekyll` 이 필요할 수도 있다. `privacy.md` 대신 `privacy.html` 로 두면 확실하다.
- **데이터 보안 양식이 계속 반려** → `shared_preferences`, `http` 같은 패키지가 데이터를 수집하지 않는지 확인. Flutter 기본 패키지들은 수집하지 않는다.
- **스크린샷이 거부됨** → 규격(최소 320px, 비율) 확인. 프레임·목업을 씌운 이미지는 허용되지만 실제 화면이 보여야 한다.
- **비속어 단어가 스크린샷에 나옴** → 02-10의 `blocklist.txt` 를 보강하고 DB를 재빌드한다.
- **등록 절차가 계속 늘어남** → 정책이 자주 바뀐다. Play Console이 요구하는 것을 그때그때 채운다. 이 문서는 2026년 기준 안내이므로 **실제 콘솔 화면이 우선**이다.
