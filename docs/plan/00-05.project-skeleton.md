## 컨텍스트

시작 전 읽기: [../DESIGN.md](../DESIGN.md) 3절 (디렉터리 구조와 `domain/` 격리 원칙)

## 먼저 확정해야 하는 값

`--org` 에 쓸 **역도메인**. 이후 `applicationId` 가 되고 스토어 등록 후 **변경 불가**(06-01).
정해지지 않았으면 **여기서 멈추고 사람에게 묻는다.** 임시값으로 진행하지 않는다.

예시 형태: `com.example`, `io.github.<계정>` → 최종 `applicationId` = `<org>.jgame`

## 작업

### 1. Flutter 프로젝트 생성

```powershell
flutter create app --platforms android,web --org <역도메인> --project-name jgame
```

### 2. 디렉터리 추가

```
app/lib/
├─ domain/          .gitkeep
├─ data/            .gitkeep
├─ ui/              .gitkeep
└─ main.dart        (flutter create가 만든 것 유지)
app/assets/         .gitkeep   ← 2단계 words.sqlite 자리
app/test/domain/    .gitkeep
```

`app/lib/domain/` 은 **플랫폼 import 금지** 구역이다. `app/lib/domain/README.md` 에 규칙을 남긴다:

> # domain
>
> 순수 Dart. `dart:io`, `package:flutter/*`, drift 등 플랫폼/DB import 금지.
> `WordRepository` 인터페이스만 받아서 동작한다. 검증 방법은 01-01 참조.

### 3. `app/pubspec.yaml`

에셋 선언 추가:

```yaml
flutter:
  uses-material-design: true
  assets:
    - assets/
```

의존성은 **주석으로만** 기록한다. 실제 추가는 해당 단계에서:

```yaml
dependencies:
  flutter:
    sdk: flutter
  # 3단계에서 추가: drift, drift_flutter, sqlite3_flutter_libs, path_provider
  # 5단계에서 추가: http, crypto
  # 4단계에서 결정 후 추가: provider 또는 flutter_riverpod

dev_dependencies:
  flutter_test:
    sdk: flutter
  flutter_lints: ^5.0.0
  test: ^1.25.0
  # 3단계에서 추가: drift_dev, build_runner
```

### 4. 저장소 루트 `.gitignore`

`flutter create` 가 만든 `app/.gitignore` 는 그대로 두고, **저장소 루트**에 새로 만든다:

```gitignore
# Python / ETL
tools/.venv/
tools/raw/
tools/build/
__pycache__/
*.pyc
.pytest_cache/

# 서명 비밀 (6단계)
*.keystore
*.jks
key.properties
app/android/key.properties

# OS / 에디터
.DS_Store
Thumbs.db
.idea/
*.iml
```

### 5. 브랜치 정리

현재 `master`, 프로젝트 기본 브랜치는 `main` (REVIEW.md 3절).

```powershell
git branch -M main
```

## 검증

```powershell
flutter pub get
dart analyze
git status --short
git branch --show-current
```

(`flutter pub get`, `dart analyze` 는 `app/` 에서 실행)

기대:

- `flutter pub get` 성공
- `dart analyze` → `No issues found!`
- `git branch --show-current` → `main`
- `git status --short` 에 `tools/.venv`, `tools/raw`, `tools/build`, `app/build` 가 **안 보임**

## 막히면

- **역도메인 미정** → 멈추고 사람에게 묻는다. 나중에 바꾸려면 `android/app/build.gradle`, `AndroidManifest.xml`, 패키지 디렉터리를 전부 고쳐야 한다.
- **`flutter create` 가 web을 안 만듦** → `flutter config --enable-web` 후 `app/` 안에서 `flutter create --platforms web .` 재실행.
- **`git branch -M main` 거부** → 커밋 0개에서도 동작해야 한다. 안 되면 00-06의 첫 커밋 이후 다시 시도.
