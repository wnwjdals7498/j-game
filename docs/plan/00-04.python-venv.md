## 주의 (REVIEW.md 2절)

이 PC에서 `python3` 는 **3.6.8** 을 가리킨다. **절대 사용 금지.**
쓸 것: `python` (3.13.13) 또는 `py -3.13`.

## 작업

### 1. 파이썬 버전 확인

```powershell
py -3.13 --version
```

기대: `Python 3.13.x`. 다르면 멈추고 사람에게 보고.

### 2. venv 생성

```powershell
py -3.13 -m venv tools/.venv
```

### 3. 파일 생성

**`tools/requirements.txt`**

```
pytest
```

표준 라이브러리(`xml.etree`, `sqlite3`, `csv`, `json`, `unicodedata`)로 시작한다.
`lxml` 은 2단계에서 대용량 XML 파싱이 느릴 때만 추가한다 (02-04 참조).

**`tools/README.md`** — 아래 내용으로 작성

> # tools — 오프라인 ETL (앱에 포함되지 않음)
>
> 사전 원본을 가공해 `words.sqlite` 를 만든다. 개발 PC에서만 실행한다.
>
> ## 실행
>
> ```powershell
> tools\.venv\Scripts\Activate.ps1
> pip install -r tools/requirements.txt
> python -m tools build      # raw -> tools/build/words.sqlite
> python -m tools report     # docs/reports/02-db-report.md 생성
> python -m tools check      # 산출물 검증
> ```
>
> Python 3.13 필수. 이 PC의 `python3` 는 3.6.8이므로 사용 금지.
>
> ## 원본 자료
>
> `tools/raw/` 에 둔다. 커밋하지 않는다(용량·라이선스).
> 자료 목록과 라이선스는 `docs/LICENSES.md` 참조.
>
> ## 실제 파일 구조 조사 결과
>
> (02-01에서 채운다)

**`tools/tests/__init__.py`** — 빈 파일

**`tools/tests/test_smoke.py`**

```python
def test_stdlib_available():
    import sqlite3
    import xml.etree.ElementTree as ET

    assert sqlite3.sqlite_version_info >= (3, 35)
    assert ET is not None
```

### 4. 설치

```powershell
tools\.venv\Scripts\python.exe -m pip install --upgrade pip
tools\.venv\Scripts\python.exe -m pip install -r tools/requirements.txt
```

## 검증

```powershell
tools\.venv\Scripts\python.exe --version
tools\.venv\Scripts\python.exe -c "import sqlite3; print(sqlite3.sqlite_version)"
tools\.venv\Scripts\python.exe -m pytest tools -q
```

기대:

- `Python 3.13.x`
- sqlite 버전 출력 (3.50.x 예상)
- `1 passed`

## 막히면

- **`py -3.13` 없음** → `py -0` 로 설치된 런처 목록 확인. 3.13이 없으면 사람에게 설치 요청 후 대기.
- **`Activate.ps1` 실행 정책 오류** → 활성화 없이 `tools\.venv\Scripts\python.exe` 절대경로로 실행하면 된다. 실행 정책은 건드리지 않는다.
- **pip 설치가 프록시로 막힘** → 사람에게 보고. `pytest` 없이도 이후 문서는 진행 가능하나 DoD는 미충족으로 남긴다.
