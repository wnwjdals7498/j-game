## `tools/release_db.py` 완성

05-01에서 뼈대를 만들었다. 여기서 **실제로 한 번 실행**해 검증한다 (DoD 4번).

추가할 것:

### 이전 릴리스 확인

```python
def latest_released_version(repo: str) -> int | None:
    """gh로 최신 db-v* 태그를 조회."""
    try:
        out = subprocess.run(
            ["gh", "release", "list", "--repo", repo, "--limit", "20",
             "--json", "tagName"],
            capture_output=True, text=True, check=True).stdout
        tags = [r["tagName"] for r in json.loads(out)]
        vs = [int(t[4:]) for t in tags if t.startswith("db-v") and t[4:].isdigit()]
        return max(vs) if vs else None
    except Exception:
        return None
```

`db_version` 이 이전과 같거나 낮으면 **업로드를 거부**한다:

```python
prev = latest_released_version(REPO)
if prev is not None and manifest["db_version"] <= prev:
    sys.exit(f"db_version {manifest['db_version']} <= 최신 릴리스 {prev}. "
             f"tools/config.py의 DB_VERSION을 올리세요.")
```

### 드라이런

```powershell
python tools/release_db.py --db tools/build/words.sqlite --out tools/build/release
```

`--upload` 없이 실행하면 manifest만 만든다. **항상 드라이런을 먼저** 하고 내용을 확인한다.

```powershell
Get-Content tools/build/release/manifest.json
```

확인: `db_version`, `url`, `sha256`, `size_bytes` 가 그럴듯한가.

### 업로드

```powershell
python tools/release_db.py --db tools/build/words.sqlite --out tools/build/release --upload
```

`gh release create` 가 실행된다. **되돌리려면** `gh release delete db-v<N> --yes`.

## 막히면

- **`gh release list` 가 빈 목록** → 첫 릴리스다. `prev is None` 이면 검사를 건너뛴다.
- **`gh` 인증 실패** → `gh auth login`. 토큰 권한에 `repo` 가 필요하다.
- **DB 전용 저장소를 아직 안 만듦** → 05-01에서 분리하기로 했다면 지금 만든다. `REPO` 상수를 그 저장소로 맞춘다.
- **실수로 잘못된 DB를 릴리스함** → `gh release delete db-v<N> --yes` 로 지운다. 이미 앱이 받았으면 `db_version` 을 올려 올바른 DB를 새로 릴리스한다. **같은 버전으로 덮어쓰지 않는다** — 앱이 "이미 최신" 이라 판단해 안 받는다.
- **절차가 5줄보다 길어짐** → 그래도 괜찮다. 중요한 건 **반년 뒤에 그대로 따라 할 수 있는가** 다. 명령어를 복사 가능한 형태로 두는 게 핵심이다.
